## 調べ方

ビルドに入るシーン（17）と `Resources/`、ProjectSettings が指している物、Hansさんのステージを起点に、次の2つをたどった。

- アセット … シーン・プレハブ・マテリアルなどの中の GUID
- スクリプト … プレハブ・シーンに付いている物と、再生開始時に自分で生まれる物（`RuntimeInitializeOnLoadMethod`）から、クラス名で

道具は `調査の道具/使われていないファイルを探す.py`（読むだけで、何も消さない）。

```
"D:\999_Tools\Anaconda3\python.exe" -I "使われていないファイルを探す.py" "D:/010_GitHub/StarSweepers-Main" --with-hans
```

`--with-hans` は Hansさんのステージ（ビルドには入っていない）も起点にする。`--drop-old` は、昔のマップ（`SpaceJunkMap01`〜`04`）をやめた場合を調べる。

**限界**：ファイルの中身から参照をたどる調べ方なので、**名前の文字列で実行時に読み込む物は拾いきれない**ことがある。
消す前に、その GUID とファイル名を `git grep` で探し直すこと。消したあとは、自動テストと試合の自動進行で確かめること。
