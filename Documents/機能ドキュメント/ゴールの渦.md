## この機能は何か

**ゴールの床に、黒い渦がいつも回っている。物資が渦に入ると、小さくなりながら回って渦の真ん中へ吸い込まれ、消えた瞬間に得点になる。**

- 前は「物資がゴールの中に1秒いたら、その場でパッと消えて得点」だった。それを「渦に吸い込まれて消えたら得点」に替えた。
- 渦は黒。外側のふちだけ、**そのゴールのチームの色**でうっすら光る（ロビーの練習用ゴールは、ゴールの床と同じ水色）。
- 渦には**円柱の形の判定**がある。物資の真ん中がこの円柱に入ると、吸い込みが始まる。
- 渦は**ゴールの床いっぱいの円**（床の短い辺の 9 割）。床の四角い角は渦の外になるが、角で止まった物資も**渦のほうへ引き寄せられて**、やがて吸い込まれる。だから「ゴールに入れれば点」は前と変わらない。
- **吸い込まれている途中の物資は、誰も引っ張り出せない**（フックが当たらない。ボットも狙わない）。渦に入った時点で確定する。
- 吸い込みは約1秒（前の「1秒いたら得点」と同じテンポ）。
- 得点が入った瞬間の光る演出（`ゴールの得点の演出.md`）は、**吸い込み終わって消えた瞬間に**出る。

## 遊ぶ人から見た動き

| 操作・場面 | 結果 |
| --- | --- |
| 試合でゴールを見る | 床に黒い渦がゆっくり回っている（上から見て左回り）。ふちはチームの色。光の粒が、ふちから真ん中へ流れ込む |
| 物資を自分のチームのゴールの渦に投げ入れる | 物資が渦のまわりを回りながら真ん中へ寄り、だんだん小さくなって、最後に床の下へ沈むように消える。消えた瞬間に点が入り、ゴールのまわりが光る |
| 物資がゴールの角（渦の外）に止まる | 渦のほうへ滑っていき、渦に入ったら吸い込まれる |
| 吸い込まれている物資にフックを撃つ | 当たらない（引っ張り出せない） |
| 物資を引っ掛けたまま、ゴールの中へ持ち込む | 引っ掛けている間は吸い込まれない（前と同じく、引きずり込みでは点にならない）。手を離すと吸い込まれる |
| 3チームの試合で、閉ざされたゴール | 渦は出ない。物資を入れても何も起きない（前と同じ） |
| ラウンドの始まり（輸送機が飛んでくる演出） | 飛んでいる間は渦は出ない。着地すると、渦が真ん中から広がって出てくる |
| ロビーの練習用ゴールに物資を入れる | 水色のふちの渦に吸い込まれて消える（得点は無い） |
| 検証シーン `Test/GoalVortexTest.unity` を再生する | 左の床のゴール（青）と右の輸送機のゴール（赤）に、上から箱が順番に落ちてきて、渦に吸い込まれる。ときどき角に落ちて、引き寄せられる |

## 設定できる値（インスペクターの項目）

**渦（プレハブ `Prefabs/Effect/SpaceJunkGoalVortex.prefab` を直せば、全ステージとロビーに効く）**

| 項目名 | 意味 | 実装したときの初期値（目安。調整で変わる） |
| --- | --- | --- |
| Vortex Material | 渦の見た目（`Art/Materials/GoalVortex`） | `GoalVortex` |
| Fill | 渦の半径＝ゴールの床の短い辺の半分×これ（1 で床いっぱい）。**判定の円柱も同じ大きさ** | 0.9 |
| Lift | 渦を床から浮かせる高さ（m） | 0.03 |
| Appear Seconds | 輸送機が着地してから、渦が出きるまでの秒数 | 0.6 |
| Brightness | ふちの光の明るさ | 1 |
| Absorb Seconds | 渦に入ってから、真ん中で消えて得点になるまでの秒数 | 1 |
| Spin Turns | 吸い込まれる間に、渦のまわりを何周するか | 1.25 |
| Self Spin Degrees | 吸い込まれる間に、物資自身が何度回るか | 540 |
| End Scale | 消える直前の大きさ（元の何倍か） | 0.05 |
| Sink Depth | 消える直前に、床の下へ沈む深さ（m） | 0.4 |
| Pull Acceleration | 渦の外にいる物資を、渦のほうへ引き寄せる強さ | 9 |
| Depth Below Floor | 判定の円柱が、床より下へ何 m まで伸びるか | 0.5 |

**渦の見た目（マテリアル `GoalVortex.mat`）**：Arms（渦の腕の数）・Twist（腕の巻き具合）・Speed（回る速さ）・Darkness（黒さ）・Rim Width（ふちの光の太さ）・Specks（流れ込む光の粒の濃さ）。
Color・Vortex Time・Appear・Brightness は**スクリプトが毎回入れる**ので、マテリアルで変えても効かない。

**決まり**：

- **ふちの色はチームの色**（`SpaceJunkTeams.TeamColor`）。ロビーの練習用ゴールは、そのゴールの Default Color。渦の側で色を決める項目は無い。
- 渦は**同じシーンのゴールだけ**に出る。進行役のプレハブの子から外して別のシーンに置くと、そのシーンのゴールにしか出ない。
- 渦の回る向き（上から見て左回り）と、吸い込まれる物資が回る向きは、そろえてある。シェーダーかスクリプトの片方だけで向きを変えないこと。

## オンラインでの動き

- **吸い込みを始める・得点を数えるのはホストだけ**（前と同じ）。参加者のPCでは何も数えない。
- ホストは、物資が渦の円柱に入ったら吸い込みを始め、参加者のPCへ「この物資の吸い込みが、ホストの時計のこの時刻に始まった」と知らせる（`FishingNetSupply.BeginAbsorbClientRpc`）。
- **位置と回転**は、ホストが動かした物を、これまでどおり通信（NetworkTransform）で全員に配る。
- **大きさ**は通信で配られない作りなので、参加者のPCが、知らされた時刻と全員で合わせた時計（`ServerTime`）から自分で小さくする。だから、どのPCでも同じ速さで小さくなる。
- 吸い込み終わったら、ホストが点を数えて物資を消す（前と同じ消し方で、全員の画面から消える）。得点の光る演出も、前と同じ知らせで全員に出る。
- 吸い込み中は、どのPCでも物資の当たり判定を切り、「消えた扱い」にする。だから参加者のフックも当たらない。

## 仕組み（分かる人向け）

> スクリプトの詳しい説明は `スクリプトの説明/Game/Effect/SpaceJunkGoalVortex.md`。

1. ホストの `SpaceJunkGoal.OnTriggerStay` → `TryCollect`：素材で、引っ掛けられていなければ `SpaceJunkGoalVortex.ServerFeed(ゴール, 物資, Collect)`。
2. `ServerFeed`：物資の持ち主がホストに戻っていて、物資の重心が渦の円柱（半径・床から下 0.5m〜ゴールの判定の上の端）の中なら `SpaceJunkVortexAbsorb.Begin` で吸い込みを始め、参加者へ知らせる。外なら、渦の真ん中のほうへ水平に引き寄せる（1つの物理の更新で1回）。
3. `SpaceJunkVortexAbsorb`：物資の当たり判定を切り、`HookableObject.SetAbsorbing(true)`（`IsVanished` が true になる）。ホストは物理を止めて、半径を縮めながら回し、沈めて、大きさを小さくする。参加者は大きさだけ小さくする。
4. 時間が来たら（ホスト）：大きさを戻してから `Collect`（`SpaceJunkRound.ServerCollect` → 数えたら `FlashClientRpc` → `HookableObject.Vanish`）。戻した大きさは、同じフレームで消えるので見えない。
5. 渦の円柱の大きさ：ゴールの得点の演出と同じ測り方（`SpaceJunkGoalScoreEffect.TryGetGoalArea`）で床の四角を測り、短い辺の半分×Fill。足もとは、ゴールの真ん中の真下にある床（輸送機なら荷台）の上面を光線で調べる。ロビーの練習用ゴールは判定の箱の大きさ。
6. 描き方：`Graphics.RenderMesh` でシーンに物を作らずに描く（全体カメラが測るステージの大きさに入らない）。始まりの演出でゴールの見た目が隠れている間は描かない。

## 確かめたこと

すべて画面なしの Unity（6000.3.14f1）で確かめた（2026/11/17）。

- **検証シーン**を20秒再生：箱を21個吸い込み、吸い込み終わり19回＝得点の光る演出19回（残り2個は吸い込み中か落ちている途中）。角（渦の外）に落ちた箱も、引き寄せられて吸い込まれた。吸い込み中の画像で、進み 0.19 → 0.54 → 0.89 で大きさ 0.56 → 0.39 → 0.13 倍、真ん中へ寄って最後は床の下へ沈むのを確認。
- **自動テスト**（`SpaceJunkGoalVortexTests`）：①床のゴール（5m×4m）で、渦の半径が 1.8m・足もとが色を塗る床の上面になる ②**1つの Unity の中でホストと参加者をつなぎ**、本物の物資のプレハブ（`SpaceJunkPlate`）で、渦に入った物資が**参加者のPCでも「吸い込み中」になり・当たり判定が切れ・半分より小さくなってから消える**こと、ホストで真ん中へ寄ること、ゴールの角に置いた物資が引き寄せられて吸い込まれること。どちらも成功。
- **全部の自動テスト** 156 件：155 件成功、1 件（`SweeperHeavyBotTests.Bot_ThrowsSupplyTowardGoal`。ボットが後ろへ投げるかのテストで、渦も本物のゴールも使わない）が失敗。そのテストだけ流し直すと 2 件とも成功したので、**たまたま失敗する物**で、今回の変更とは関係ない。
- **本物の試合**（タイトル → ホスト → ロビー → ボット3人）：
  - ロビーの練習用ゴールに、水色のふちの渦が出る（半径 1.35m）。
  - **電車マップ2**（輸送機のゴール。荷台の高さ 0.30m・0.34m、半径 1.38m）で60秒：吸い込みを始めた 21 回・吸い込み終わり 21 回・得点の知らせ 21 回・得点のログ 21 行が一致。ラウンドイベントのボーナス（+10点）も、吸い込み終わりで入った。
  - **シンプル**（床のゴール。半径 1.8m）で60秒：吸い込み始め 25 回・吸い込み終わり 24 回（1 個は吸い込み中に時間切れ）・得点の知らせ 24 回・得点のログ 24 行が一致。
  - 全体カメラの画像で、両チームのゴールに渦が見える。ラウンドの始まりで、ゴールの見た目が隠れている間は渦も隠れる。
  - ゲームのコードからの Exception は出なかった（Unity エディタ自身の検索機能の Exception が起動時に1件出たが、ゲームとは関係ない。前からある）。
- 最初の画像では、渦の黒さが足りず床の色が透け、ふちの光も太く明るすぎたので、黒さを上げ（腕の間も 0.84 以上）、ふちを細く・控えめにした。

## できていないこと・既知の問題

- **人が遊んでの見え方・遊びやすさ（渦の大きさ・吸い込みの長さ・黒さ）は未確認。** 値は一旦作ってみたもの。
- **別のPC（参加者）での見え方は、実際の2台では確かめていない。** 1つの Unity の中でホストと参加者をつなぐ自動テストで、参加者の画面でも小さくなって消えることは確かめた。
- 参加者のPCでは、位置は通信の遅れぶん（ほんの少し）遅れて動き、大きさは自分の時計で小さくなるので、通信がとても遅いと、小さくなるのと位置がわずかにずれることがある。
- 吸い込み中の物資は「消えた扱い」なので、物資を出す係（スポナー）は、消える約1秒前から次の物資を出してよいと数える（マップの物資が一瞬1つ多くなりうる）。
- 吸い込み中の物資が、ほかの理由（爆弾の爆発など）で消されたときは、得点にならない。
- 角の引き寄せは、物資と床の摩擦に勝つ強さにしてある。重いデブリ（引きずって運ぶ物）の引き寄せと吸い込みは、試合では見ていない（ボーナスの数え方は、吸い込み中も「まだある」と数えるように直してある）。
- 渦は、ゴールの床の上に描いた模様。床の下へ本当に穴が開いているわけではない（物資は最後に床の下へ少し沈みながら消える）。
