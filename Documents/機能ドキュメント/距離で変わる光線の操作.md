## この機能は何か

新しい体（Sweeper プレイヤー）の光線の、**もう1つの操作方法**。**ロビーコンソールのプレイヤー挙動「3 引っ張る・4 投げる」を B にすると、この操作になる**（A＝いつもの。ホストが全員ぶん決める。2026/11/18・小野田さん。前はポーズ画面の設定「光線の操作」で、そのPCの人だけが切り替えていた）。詳しくは `プレイヤー挙動のパターン.md`。

光線が当たると、物資が**一定の速さ**（初期値 6m/秒）で、**光線の形にそって**プレイヤーへ寄ってくる（いつもの「距離に関係なく 1.5 秒で着く」ではない）。向きを変えて光線がしなっていると、物資は曲がった光線をたどって回り込みながら来る。**引き寄せの途中でボタンを押した瞬間の、プレイヤーと物資の距離**で、次の2つが決まる。

- **前へ投げる・引っ張る・クリティカルプルのどれになるか**
- **その強さ**（0〜1。いつもの飛ぶ速さに、この強さを掛ける）

「引っ張る」は、いつもの「途中で押すと頭を越えて後ろへ飛ぶ」動き（光線を引っ張る動作）。「前へ投げる」は、いつもの「押さずに最後まで来たときに前へ投げる」動き。
どちらも**いつもの飛ぶ向きと速さ（ベクトル）をそのまま使い、強さを掛けるだけ**。

### 距離と強さ（大槻さんの指定。2026/11/17）

距離は **ビームの長さの上限（Max Reach。初期値 12m）を 100% とした割合**（大槻さんの指定）。
物資に当たった距離や、撃つ前に溜めた長さには関係なく、**いつも 12m で割る**。

| 距離 | 動き | 強さ | 上限が 12m なら |
| --- | --- | --- | --- |
| 0〜20% | **前へ投げる** | 大 → 小（体のそばで 1、20% で 0） | 0〜2.4m |
| 20〜29% | **引っ張る** | **どこで押しても 0.5**（Middle Pull Strength） | 2.4〜3.48m |
| 29〜32% | **クリティカルプル**（今までと同じ。強さは掛けない） | ― | 3.48〜3.84m |
| 32〜100% | **引っ張る** | 100% で 0.2（Far Pull Min Strength）→ クリティカルに近づくほど強く、32% で 1 | 3.84〜12m |

- 指定は「投げ 0〜20・引っ張り 20〜28・クリティカルプル 29〜31・引っ張り 32〜100」。間が空かないよう、28〜29 は引っ張り、31〜32 はクリティカルプルに入れた（区切りはインスペクターで変えられる）。
- 強さは、区切りの間をまっすぐ増える・減る。前へ投げるの「0」は、いちばん弱いときの強さ（Throw Min Strength）で、インスペクターで上げられる（初期値は 0）。
- 体のすぐそばの物資は、当たってすぐ押しても前へ投げることしかできない（大槻さんに確認済み。この動きで合っている）。

## 遊ぶ人から見た動き

| 操作 | 結果 |
| --- | --- |
| ロビーコンソールで「3 引っ張る」（または「4 投げる」）を B にする（ホスト） | 部屋の全員（ボットを除く）がこの操作になる。**次にホストをしたときも残る** |
| 溜めている間 | **狙いの矢印の帯が、ゾーンごとに色分けされる**（オレンジ＝前へ投げる、青＝引っ張る、黄色＝クリティカルプル）。いつもの操作のときは、今までどおりチームの色1色 |
| 狙って撃ち、物資に当たる | 物資が**一定の速さ**で寄ってくる（遠い物ほど着くまで長くかかる。9m 先なら約 1.3 秒、4m 先なら約 0.4 秒） |
| 寄ってくる途中で向きを変える | 光線がしなり、**物資はその曲線にそって**手元へ進む（光線の上を滑ってくるように動く） |
| 引き寄せの途中で押す | 押した瞬間の距離で、上の表のどれかになる |
| クリティカルの距離に物資が来る少し前 | **今までと同じ合図**（縮んでくる輪・金色のフチ）が出る。輪が物資のふちに重なった瞬間が、クリティカルの距離に入った瞬間 |
| 押さずに手前（Stop Distance。1.4m）まで来る | 今までどおり前へ投げる（強さは掛けない） |
| 重い物（特殊デブリ）に当たる | いつもと同じ（引きずるだけ） |

- 物資は時間とともに近づいてくるので、**押すタイミングで「引っ張る」「クリティカル」「前へ投げる」を選ぶ**ことになる。
- 速さ（ベクトル）に強さを掛けるので、**飛ぶ距離はおおよそ強さの2乗**で短くなる（横の速さも、上がる高さ＝飛んでいる時間も短くなるため）。強さ 0.5 なら、いつもの約 1/4 の距離。
- **クリティカルの距離は 3%（0.36m）しかない。** 物資は秒速 6m で来るので、押せるのは**約 0.06 秒**（いつものクリティカルの受付は 0.2 秒）。どこから引き寄せても同じ。難しすぎれば Critical Near / Critical Far を広げるか、Distance Reel Speed を下げる。
- **ボットはパターンに関係なく、いつもの操作（A）で動く**（ボットの頭は、いつもの操作のタイミングしか知らないため）。
- パターンは**ホストが決めて、部屋の全員に効く**（2026/11/18 から。前はポーズ画面の設定で、そのPCの人だけに効いていた）。

### 試し方

1. `feature/whip-beam`（または、これをマージしたブランチ）に切り替えて Unity を開く
2. `MainLoop/StarSweepersTitle.unity` から遊ぶ（プラクティスでよい）
3. ロビーの右側の小窓「ロビーコンソール」で、「3 引っ張る」を B にする（ホストのとき）
4. 物資を撃って、寄ってくる途中のいろいろな距離で押し比べる

## 設定できる値（インスペクターの項目）

`SweeperReel` の「距離で変わる操作」の見出しの下。**設定が「距離で変わる」のときだけ効く。** どれも、ビームの長さの上限（Shooter の Max Reach）に対する割合。**0.2 が 20%**。

| 項目名 | 意味 | 実装したときの初期値（目安。調整で変わる） |
| --- | --- | --- |
| Throw Zone End | ここより近ければ前へ投げる（体のそばで強さ 1 → ここで 0） | 0.2 |
| Critical Near | クリティカルプルを取れる距離の近いほうの端。Throw Zone End からここまでは、引っ張る強さが 0 → 1 | 0.29 |
| Critical Far | クリティカルプルを取れる距離の遠いほうの端。ここから 100% までは、引っ張る強さが 1 → 0。Critical Near と同じにするとクリティカルなし | 0.32 |
| Throw Min Strength | **前へ投げる強さの最小値**（0〜1）。いちばん弱い所（Throw Zone End）で押したときの強さ。体のそばでは 1 | 0 |
| Distance Reel Speed | **物資が寄ってくる速さ**（m/秒）。この操作では Reel Seconds（何秒で着くか）は使わない | 6 |
| Middle Pull Strength | **投げとクリティカルの間の引っ張る強さ**（0〜1）。この間はどこで押しても同じ | 0.5 |
| Far Pull Min Strength | **クリティカルより遠い引っ張りの、いちばん弱い所（100%）の強さ**（0〜1）。クリティカルに近づくほど強くなり、Critical Far で 1 | 0.2 |

### 狙いの帯の色（`SweeperAimArea`。プレハブの子 `AimArea` に付いている）

| 項目名 | 意味 | 実装したときの初期値（目安。調整で変わる） |
| --- | --- | --- |
| Throw Zone Color | 前へ投げるゾーンの色 | オレンジ |
| Pull Zone Color | 引っ張るゾーンの色 | 青 |
| Critical Zone Color | クリティカルプルのゾーンの色 | 黄色 |

濃さは今までどおり Alpha で変わる。境目は上の Sweeper Reel の値から自動で決まる。

### 区切りの変え方

1. Unity の Project ウィンドウで `Assets/Prefabs/Player/SpaceJunkSweeperPlayer.prefab` をダブルクリックして開く（**試合で人が使う体はこれ**。`SweeperPlayer.prefab` は自動テスト用）
2. Hierarchy でいちばん上（体の根元）を選び、Inspector の `Sweeper Reel` の「距離で変わる操作」の項目を変える（区切りは 0.2 が 20%。最小の強さは 0.3 なら、いつもの速さの 3 割）
3. プレハブを保存する（**プレハブを変えたことになるので、ほかの人と同時に触らないこと**）

強さ 1 のときの飛び方・クリティカルの飛び方とエフェクトは、いつもの値のまま（Forward Speed / Forward Lift、Back Distance / Back Arc Height、Critical Back Distance / Critical Arc Height、合図とエフェクトの項目）。
**Critical Start / Critical Length（時間の受付）は、この操作では使わない。**

## 仕組み（分かる人向け）

- 光線が当たると `SweeperReel.Begin` で「人の体（`PlayerInputSource.UsesVirtual` でない）で、設定が距離で変わる、重い物でない」かを覚える。
- 押されると `Press` → `PressByDistance`。距離は、プレイヤーの中心から物資の中心までの真上から見た距離を、ビームの長さの上限（`SweeperShooter.MaxReach`。光線もプレイヤーの中心から測っている）で割った割合。
  - Critical Near 以上・Critical Far 未満（`InCriticalBand`。`InCriticalWindow` もこの操作ではこれを返す）なら、いつもの `ThrowBack(true)`（強さを掛けない）。
  - Throw Zone End より近ければ `ThrowForward(強さ)`、それ以外は `ThrowBack(false, 強さ)`。どちらも、いつもどおり計算した速さ（ベクトル）に強さを掛けてから飛ばす。
- **寄ってくる動き**：引き寄せの1ステップごとに、光線の形（`SweeperShooter.GetBeamPath`。見た目と同じ2次ベジェの曲線を9点で）を物資の側から手元へ「速さ × 時間」だけたどり、そのぶん物資をずらす（`TryStepAlongBeam`）。Stop Distance より手前には来ない。割合（前へ投げる・引っ張る・クリティカル）は、プレイヤーと物資のまっすぐの距離で決める。手前に着いたら（`ArrivedAtStop`）前へ投げる。壁に引っかかって着けないときも、着くはずの時間を 1 秒過ぎたら前へ投げる。
- **合図の時間**：物資は一定の速さで寄ってくる。なので当たった瞬間（オンラインならホストに認められた瞬間）の距離から、物資がクリティカルの距離を通る時間（距離の差 ÷ 速さ）を計算し、いつもの合図（受付の Cue Lead 秒前から）をその時間に合わせて出す（`EstimateCriticalWindow`）。初めからクリティカルの距離より近いときは合図を出さない。
- **オンライン**：飛ばす速さをホストへ渡すのは、いつもの処理をそのまま使っている（強さを掛けた速さが渡る）。
- 結果の文字（`LastResult`）は「前（強さ 0.33）」「後ろ（強さ 0.37）」「クリティカル」のようになる。

## できていないこと・既知の問題

- **人が遊んでの確認はまだ**（自動テストで確かめただけ）。オンラインでの確認もまだ。
- **クリティカルの距離が狭く、遠くから引くと押せる時間が約 0.07 秒しかない**（上の「遊ぶ人から見た動き」）。
- **合図は時間の見積もり、クリティカルかどうかは本当の距離で決める。** 壁に引っかかる・引きずる速さの上限に当たるなどで物資が遅れると、合図と本当にクリティカルになる瞬間がずれる。
- **オンラインのほかの人の画面の合図は、いつもの時間（Critical Start）で出る**（合図の知らせには時間が入っていないため）。本人の画面は正しい。
- 最小の強さが 0 のままだと、20% 付近・100% 付近で押したとき、ほとんど飛ばずにその場に落ちる。弱すぎれば Throw Min Strength・Far Pull Min Strength を上げる。
- 狙いの帯の色でゾーンは分かるが、**強さ（同じゾーンの中の強い・弱い）は見た目に出ない**。
- **オンラインのほかの人の画面では、帯は今までどおりチームの色1色**（設定はそれぞれのPCにあり、通信で送っていないため）。
- 引っ張るゾーンの青は、青チームの色と近い。分かりにくければ Pull Zone Color を変える。
