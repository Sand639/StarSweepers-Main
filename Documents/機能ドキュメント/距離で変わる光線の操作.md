## この機能は何か

新しい体（Sweeper プレイヤー）の光線の、**もう1つの操作方法**。ポーズ画面の設定で「いつもの」と切り替えられる。

光線が物資に当たったとき、**プレイヤーと物資の距離**で次の2つが決まる。

- **投げるか、引っ張るか**（近ければ投げる、遠ければ引っ張る）
- **その強さ**（どれだけ遠くへ投げるか・どれだけ引き寄せるか）

大槻さんの図（2026/11/17）をそのまま数字にした。

```
プレイヤー                                              届くいちばん遠い所
 |■■■■■■■■＼                                                  |
 |  投げる強さ  ＼                                               |
 |               ＼／■■■■■■■■■■■■■■■■■■■■■■■■＼               |
 |                ／  引っ張る強さ                    ＼          |
 0%              32%  43%                                       100%
```

- **投げる強さ**：体のすぐそばがいちばん強く、届く長さの **32%** でゼロになる（まっすぐ弱くなる）
- **引っ張る強さ**：32% でゼロ → **43%** でいちばん強い → 届くいちばん遠い所でゼロ（どちらもまっすぐ）

## 遊ぶ人から見た動き

| 操作 | 結果 |
| --- | --- |
| ポーズ画面（Esc）→「設定」→「光線の操作：いつもの」を押す | 「光線の操作：距離で変わる」になる（もう一度押すと戻る）。**次に遊ぶときも残る** |
| 狙って撃つ（RT／左クリック）までは | いつもと同じ（長押しで届く長さが伸び、離すと光線が伸びる） |
| 光線が**近く**の物資に当たる（届く長さの 32% より手前。初期値なら約 3.8m より手前） | **すぐ頭を越えて後ろへ投げる。** 近いほど遠くへ飛ぶ |
| 光線が**遠く**の物資に当たる | **投げずに、決まった距離だけ引き寄せて、その場に置く。** 43%（約 5.2m）あたりで当たるといちばん長く引き寄せ、届くぎりぎりだと少ししか動かない |
| 引き寄せている途中で押す | その場に置いて離す |
| 重い物（特殊デブリ）に当たる | いつもと同じ（引きずるだけ） |

- **クリティカルプルと「押さなければ前へ投げる」は無い。**
- 遠くの物資は「引っ張って近づける → 近くなったらもう一度撃って投げる」の2段階になる。強く投げたいときは、物資のそばまで歩いてから撃つ。
- **ボットはこの設定に関係なく、いつもの操作で動く。**
- 設定は**そのPCで遊ぶ人だけ**に効く（オンラインでも、ほかの人の操作は変わらない）。1台のPCで複数人遊ぶときは、その全員に効く。

### 試し方

1. このブランチ（`feature/beam-distance-strength`）に切り替えて Unity を開く
2. `MainLoop/TitleScene.unity` から遊ぶ（プラクティスでよい）
3. Esc でポーズ画面 →「設定」→「光線の操作」を「距離で変わる」にする
4. 近くの物資・遠くの物資を撃ち比べる

## 設定できる値（インスペクターの項目）

`SweeperReel` の「距離で変わる操作」の見出しの下。**設定が「距離で変わる」のときだけ効く。**

| 項目名 | 意味 | 実装したときの初期値（目安。調整で変わる） |
| --- | --- | --- |
| Throw Zone End | 届く長さ（Shooter の Max Reach）のうち、この割合より近くで当たったら投げる | 0.32 |
| Pull Peak | 引っ張る強さがいちばん強くなる所（届く長さの割合）。Throw Zone End より遠くする | 0.43 |
| Distance Throw Min / Max | 投げるとき、後ろのどこに落とすか（m）。Min は投げられるぎりぎりの遠さで当たったとき、Max は体のすぐそばで当たったとき | 3 / 11 |
| Distance Pull Min / Max | 引っ張るとき、1回で引き寄せる距離（m）。Min は強さがいちばん弱いとき、Max はいちばん強いとき（Pull Peak） | 0.5 / 5 |
| Distance Pull Speed | 引っ張るときの速さ（m/秒） | 8 |

- 放物線の高さは、強さに合わせて Back Arc Height（弱い）〜 Critical Arc Height（強い）の間で決まる（新しい項目は足していない）。
- **注意**：落とす距離は空気の抵抗を入れずに計算しているので、宇宙ごみの物資（Linear Damping 0.4）は**書いた距離より手前に落ちる**（いつもの「後ろへ投げる」と同じ。`プレイヤーの本実装.md` の「仕組み」）。自動テストでは、2m 先で当たった箱（落とす距離 約 6.8m のはず）が体の約 3m 後ろで止まった。

## 仕組み（分かる人向け）

- 光線が当たると `SweeperShooter` が `SweeperReel.Begin` を呼ぶ。そこで「人の体（`PlayerInputSource.UsesVirtual` でない）で、設定が距離で変わる、重い物でない」なら `DecideDistanceAction` で決める。
- 距離は**プレイヤーの中心から物資の中心まで、真上から見た距離**。それを `SweeperShooter.MaxReach` で割った割合で見る。
- **投げる**：次の `Update` で、いつもの後ろへの投げ（`ThrowBack`）を、落とす距離と放物線の高さを指定して呼ぶ。物資はまだ引いていないので、向きは体の真後ろになる。
- **引っ張る**：重い物を引きずるのと同じ処理（`DragBy`）で、決まった速さ・決まった距離だけ手前へ寄せる（Stop Distance より手前には来ない）。引き終わったら、その場に置いて離す（`DropInPlace`）。向きを変えたときの回り込みも効く。
- **オンライン**：いつもと同じく、ホストに「引っ掛けたい」と頼み、**認められた瞬間の距離で決め直す**。投げる速さ・置いた位置をホストへ渡すのも、いつもの処理をそのまま使っている。
- クリティカルの受付（`InCriticalWindow`）は、この操作の間はいつも false。

## できていないこと・既知の問題

- **人が遊んでの確認はまだ**（自動テストで、近くは投げる・遠くは引っ張るを確かめただけ）。オンラインでの確認もまだ。
- 図の「投げる」の向きは**後ろ（頭を越える）**だと考えて作った（いつもの操作で、ゴールへ入れるのが後ろへの投げのため）。前へ押し出す向きのほうがよければ、`SweeperReel` の `Update` の `ThrowBack` を変える。
- 投げ・引っ張りの強さが分かる見た目（矢印の帯の色を変える など）は無い。どちらになるかは当ててみるまで分からない。
- 強さの形（まっすぐ増える・減る）や 32%・43% の位置は、図から目で読み取った値。
