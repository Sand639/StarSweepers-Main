## この機能は何か

**Hans さんのステージ `HansStage01_Ver01` を、そのままの見た目で遊べるようにしたステージ。**
西と東に台地があり、真ん中を橋がつないでいる。電車マップ1（`STAGE_Train`）と同じ向きの形なので、
電車マップ1と同じく**列車が橋を南北に横切る**ようにした。

> **2026/11/12 の午後に、ステージ全体を真ん中を中心に90度回して横向きにした**（大槻さんの依頼「縦になっちゃってるから横にしてほしい」）。
> Hans さんのシーンでは台地が北と南（カメラから見て縦長）だったので、複製したあとで、床・橋・縁・輸送機・ゴール・素材の出る範囲・列車・爆弾・特殊デブリを
> まとめて回した（並び方はそのまま。向きだけ変えた）。試合のカメラ・光・画面は回していない。

- 床・橋・縁・輸送機・星空など、**見た目と並び方は Hans さんのシーンのまま**（消していない。ステージ全体を90度回しただけ）
- 足したのは、遊ぶための部品（当たり判定・ゴール・素材の出る範囲・試合の進行役・カメラ・列車など）だけ
- **元の `HansStages/HansStage01_Ver01.unity` は変えていない。** Unity の機能（`AssetDatabase.CopyAsset`）で複製してから、複製のほうに足した

## 遊ぶ人から見た動き

| 場所・起きること | 結果 |
| --- | --- |
| 東の輸送機（x=+9） | 青チームのゴール（2チームのとき）。始まりの演出では、この輸送機がプレイヤーを乗せて飛んでくる |
| 西の輸送機（x=-9） | 赤チームのゴール |
| 西と東の台地 | 素材が降ってくる（輸送機のマスには出ない）。爆弾が2つずつ置いてある |
| 橋の真ん中のマス（角の印があるマス） | 特殊デブリが置いてある |
| 橋の斜線のマス（2か所） | **10秒ごとに列車が南北に横切る**（2本同時に来る。向きは1本ずつ逆）。当たると飛ばされる |
| 台地や橋から落ちる | ほかのステージと同じ（高さ -8m より下で出てくる場所に戻る） |

- まわりは、全ステージ共通の見えない壁（バリア。`ステージを囲むバリア.md`）で囲まれる。橋の横からは落ちる
- Hans さんのシーンにあった**大きさ見本のキャラクター（`SK_Character`）と、Hans さんのカメラは、隠してある**（消していない。Hierarchy でチェックを入れれば戻る）。試合では、ほかのステージと同じ全体／自陣の切り替え付きのカメラ（`SpaceJunkStageCamera`）を使う

## 足した物

| 足した物 | 中身 |
| --- | --- |
| 当たり判定 | 床 `SM_Platform`・`SM_Half_Platform`（19枚）に箱の当たり判定。橋 `SM_Bridge`（3枚）は厚みの無い板なので、上面を板に合わせた厚み 0.25m の箱（継ぎ目と、床との 0.125m のすき間を埋めるため前後に少し長くした）。輸送機は形どおりの当たり判定＋乗る面の箱（ガラスマップと同じ） |
| ゴール `Goals` | `GoalArea_East`（番号 0）・`GoalArea_West`（番号 1）（回す前の名前は North・South）。電車マップ1のゴールを移して、輸送機の上（3m 四方・高さ 5m）に合わせた。色を塗る床と始まりの演出で飛ぶ物は、輸送機 |

| 電車マップ1から移した物 | `System`（進行役 `SpaceJunkRound`・プレイ中の画面・フックのゲージ・スポナー）、得点バー `TeamScoreBarUI`、カメラ `Main Camera`（`SpaceJunkStageCamera`）、列車 `Train (1)`・`Train (2)`、爆弾 `BombPoints`、特殊デブリ `SpecialDebrisPoint`。プレハブのつながりと値はそのまま。置き場所だけこのステージに合わせた |

## 仕組み（分かる人向け）

- 道具（上の「作った道具」）が、`CopyAsset` で複製 → `STAGE_Train` を加算で開いて部品を `SceneManager.MoveGameObjectToScene` で移す → 当たり判定とゴールを足す → ステージ全体を Y 軸で 90 度回す（`RotateHorizontal`。試合の部品・光・試合のカメラは回さない）→ 保存、の順に行う
- 通信で使う番号（NetworkObject の `GlobalObjectIdHash`）は、保存とビルドの一覧への登録のあとに開き直して付け直した（電車マップ1と同じ番号のままにしないため）。進行役 4233976141・北のゴール 4272468694・南のゴール 264663702（電車マップ1は 488310813・3795620020・744441725）

## できていないこと・既知の問題

- **人が遊んでの確認と、オンライン（2台以上）での確認はまだ**
- **試合のたびに、ボットの地図の警告が出る**（輸送機のモデルが読み取り不可の設定のため。ボットは動く。ガラスマップと同じ。`リスクリスト.md`）
- Hans さんのシーンから持ってきた星空の回転（`SkyboxController`）は、**スクリプトのファイル名と中のクラス名が違うため、もともと動いていない**（部品が「見つからない」状態。`キャラクターの見た目の切り替え.md`・`星空の背景の回転.md`）。Hans さんの制作物なので直していない。試合中の背景は、ほかのステージと同じ星空（`宇宙ごみのマップの星空の背景.md`）が出る
- 列車を入れるかどうかは、名前（電車マップ）と、橋に斜線のマスがあることから AI が決めた。要らなければ `Train (1)`・`Train (2)` のチェックを外せばよい
- Hans さんが元のステージを直しても、このステージには自動では入らない（上の道具で作り直す。作り直すと、このシーンを手で直した分は消える）
- Hans さんの制作物のルール（`README.md` の「Hansさんが制作したものの変更について」）：モデルと元のシーンは変えていないが、**Hans さんのステージを遊べるステージにしたことは、Hans さんにも伝えておくとよい**
