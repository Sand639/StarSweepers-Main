## この機能は何か

今のロビー（`SpaceJunkLobby`）を、**Hans さんの完成した3Dモデルで組み直した新しいロビー**。
大槻さんの設計図（`ロビー.svg`）どおりに、床・縁・角の柱・輸送機（練習用のゴール）を置き、今のロビーにある物（通信の係・端末・チームエリア・出現場所・ベルトコンベアなど）を、そのまま新しい場所へ移した。

**ゲームのタイトルから入るロビーは、まだ今のロビーのまま。** 新しいロビーに切り替えるのは、配置が全部そろってから（下の「できていないこと」）。

今のロビーと同じ（置き場所だけが変わった）。

| 物 | 新しい場所（設計図のマス。左上が 0,0。1マス＝3m） |

| チームエリア（赤・青） | 一番上の段の 3 列目（赤）・5 列目（青）。**大きさは1マス（3m×3m）**（今のロビーは 8m×5m） |
| 設定端末 | 上から 2 段目の真ん中 |
| リスポーンボタンの端末 | 設定端末の左下 |
| 名前を変える端末 | 設定端末の右下（設計図のオレンジ「LobbyScreen」の場所。**仮**。下の「できていないこと」） |
| 練習用のゴール（輸送機） | 3 段目の 2 列目。入口は東（右）向き |
| 練習用の物資が出る所 | ゴールから 8m 東（今のロビーと同じ距離。**設計図には無いので仮**） |
| ベルトコンベア | 東側の U 字（東の端から入って西へ → 北へ → 東の端から落ちる。向きは今のロビーと同じ） |

## 仕組み（分かる人向け）

`SVGからロビーを作る.cs.txt` が、次の順で作る。

1. 今のロビー（`SpaceJunkLobby.unity`）の中身を `Lobby.unity` に写す（`Lobby.unity` の .meta はそのままなので、シーンの番号は変わらない。通信の番号は保存したときに付け直される）
2. 平らな地面（Ground）を消し、設計図の青・赤・水色のマスに床（`SM_Platform`）を敷く。チームエリアは床の上に置き、1マスの大きさにする
3. 練習用のゴールの囲い（壁・床の板）を消して、輸送機（`SM_Transporter`）を置く。ガラスマップと同じ作り（乗る面に箱の当たり判定、ゴールの判定は 3m×5m×3m）。**輸送機はゴールの子にしない**（子にすると `SpaceJunkLobbyGoal` が輸送機の色を塗り替えるため）
4. 端末・物資の出る所・コンベア 3 本・コンベアに物資を出す係を、設計図の場所へ動かす
5. 外周に縁（`SM_Edge`）と、四隅に角の柱（`SM_Corner`）を置く（ガラスマップと同じ高さ・向き。当たり判定なしの飾り）。**上の段のコンベアが物資を東の端から落とす所だけ、縁を置かない**

⚠ **道具を動かすたびに、今のロビーを写し直す。** `Lobby.unity` を手で直し始めたら、この道具は使わないこと（手の変更が消える）。

## できていないこと・既知の問題

- **ゲームではまだ使っていない。** 使うには、ロビーのシーンの名前（タイトルからロビーへ移るところと、試合の係の `lobbySceneName`）を `Lobby` に変え、`File > Build Profiles` のシーン一覧に入れる
- **ベルトコンベアは仮の見た目**（今のロビーの `ConveyorBelt` を並べ直しただけ）。Hans さんのコンベアのモデルが届いたら差し替える
- **設計図のオレンジ「LobbyScreen」**：今のロビーの `LobbyScreen` は画面に重ねて出す UI（場所を持たない）なので、そのまま。その場所には、設計図に無い**名前を変える端末を仮に置いた**（大槻さんに確認中）
- **練習用の物資が出る所**は設計図に無いので、ゴールから 8m 東に仮に置いた
- 人が再生しての確認はまだ（画面なしの Unity で、真上・斜め・ゴール・コンベアの画像を撮って並びを確かめ、スクリプトの欠けが無いこと・つながりが切れていないことを確かめた）
