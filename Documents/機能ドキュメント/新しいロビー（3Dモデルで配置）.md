## この機能は何か

前のロビー（`SpaceJunkLobby`）を、**Hans さんの完成した3Dモデルで組み直した新しいロビー**。
大槻さんの設計図（`ロビー.svg`）どおりに、床・縁・角の柱・輸送機（練習用のゴール）・ベルトコンベアのモデルを置き、前のロビーにある物（通信の係・端末・チームエリア・出現場所など）を、そのまま新しい場所へ移した。

**タイトルからホストになる・部屋に入ると、このロビーに入る。** 試合が終わって戻るのもここ。前のロビー（`SpaceJunkLobby.unity`）はファイルだけ残してあり、使っていない。

## 設定できる値（インスペクターの項目）

前のロビーと同じ部品なので、値も前のロビーのまま（端末・チームエリア・コンベアなどの値は、それぞれの機能ドキュメント）。
コンベアだけ、**Show Built In Visual を OFF**、幅をモデルに合わせて 2.5m、上面の高さをモデルの上面（0.19m）にしてある。

## 仕組み（分かる人向け）

`SVGからロビーを作る.cs.txt` が、次の順で作る。

1. 前のロビー（`SpaceJunkLobby.unity`）の中身を `Lobby.unity` に写す（`Lobby.unity` の .meta はそのままなので、シーンの番号は変わらない。通信の番号は保存したときに付け直される）
2. 平らな地面（Ground）を消し、輸送機以外のマス（床・チームエリア・コンベア）に床（`SM_Platform`）を敷く。チームエリアは床の上に置き、1マスの大きさにする
3. 練習用のゴールの囲い（壁・床の板）を消して、輸送機（`SM_Transporter`）を置く。ガラスマップと同じ作り（乗る面に箱の当たり判定、ゴールの判定は 3m×5m×3m）。**輸送機はゴールの子にしない**（子にすると `SpaceJunkLobbyGoal` が輸送機の色を塗り替えるため）
4. 端末・物資の出る所・コンベアに物資を出す係を、設計図の場所へ動かす
5. コンベア：運ぶ働きは前のロビーの `ConveyorBelt` 3 本（縦1本・横2本）を並べ直し、仮の見た目を切る。見た目は床の上にモデルを置く（下の表）
6. 外周に縁（`SM_Edge`）と、四隅に角の柱（`SM_Corner`）を置く（ガラスマップと同じ高さ・向き。当たり判定なしの飾り）。**上の段のコンベアが物資を東の端から落とす所だけ、縁を置かない**

### コンベアのモデルの向き

モデルは**向き 0 で東から西へ流れる**作り（まっすぐの部品は長さ3m×幅2.5m、曲がる部品は2.75m四方、高さはどれも0.19m）。Turn_R は東から入って北へ出る右曲がり、Turn_L は東から入って南へ出る左曲がり。

| マス（設計図） | 部品 | 向き |
| --- | --- | --- |
| 下の段・東の端 | `SM_Coveyor_Rail_Start` | 0（西へ） |
| 下の段・その西（角） | `SM_Conveyor_Turn_R` | 0（西へ → 北へ） |
| 真ん中の段 | `SM_Coveyor_Rail_Mid` | 90（北へ） |
| 上の段・西（角） | `SM_Conveyor_Turn_R` | 90（北へ → 東へ） |
| 上の段・東の端 | `SM_Coveyor_Rail_End` | 180（東へ） |

曲がる部品は、外側の線がまっすぐの部品の端に合うよう、内側の角へ 0.125m ずらして置く。

⚠ **道具を動かすたびに、前のロビーを写し直す。** `Lobby.unity` を手で直し始めたら、この道具は使わないこと（手の変更が消える）。

## できていないこと・既知の問題

- **人が遊んでの確認はまだ。** 画面なしの Unity で、タイトル → ホスト → 新しいロビー（プレイヤーが出現場所に立つ・ロビーの画面が出る・物資がコンベアを西 → 北 → 東と流れて東の端から落ちる）→ 試合開始でマップへ移る、までを確かめた（エラー 0 件、自動テスト 130 件成功）
- **コンベアのモデルは止まった絵**（帯が流れて見えない）。流れて見せるなら、モデルの模様を動かす仕組みが要る
- `SM_Coveyor_Rail_End` の東の端には**ふたの形**があるが、当たり判定は無いので物資はそのまま落ちる（前のロビーと同じ動き）。止めたいなら、ふたに当たり判定を足す
- **ロビーのカメラは前のロビー（40m×20m）用の位置のまま**なので、新しいロビー（21m×15m）は画面の中で小さめに映る
- **練習用の物資が出る所**は設計図に無いので、ゴールから 8m 東に仮に置いた
- 古い資料には `SpaceJunkLobby` と書かれている所が多い。今のロビーは `Lobby`（`AIの申し送り.md` の「次のAIへの伝言」）
