## この機能は何か

だれかが光線で物資を**引っ張っている最中**に、その物資がほかの人にぶつかると、
ぶつかった人が**吹き飛ばされて、しばらく何もできなくなる**。

さらに、引っ張っている物が**爆弾**で、それが人にぶつかったら、**その場ですぐ爆発する**。
だれにもぶつからなければ、今までどおり**つかんだ瞬間から数える時限式**の爆弾のまま。

## 遊ぶ人から見た動き

| 起きること | 結果 |
| --- | --- |
| 引っ張られている物資が自分にぶつかる | 物資から離れる向きに、少し浮きながら吹き飛ぶ |
| 吹き飛んだあと（Stun Seconds の間） | **動けない・光線を溜められない／伸ばせない**。体が赤く点滅し、頭の上に印が出る（爆弾のスタンと同じ見た目） |
| そのとき自分も物資を引っ張っていた | **投げずにその場で離す**（持っていた物を落とす） |
| 引っ張られている**爆弾**が人にぶつかる | ぶつかった人が吹き飛んで動けなくなり、**爆弾はその場ですぐ爆発する**（爆風の効果は今までどおり） |
| 爆弾がだれにもぶつからない | 今までどおり、つかんだ瞬間から数えて爆発する |
| 引っ張っている本人 | 自分が引っ張っている物には当たらない |
| 投げたあと飛んでいる物 | **当たらない**（「引っ張っている最中」だけ） |
| 重い物（特殊デブリ）を引きずっている最中 | これも「引っ張っている最中」なので当たる |
| スタンが解けた直後（Rehit Grace の間） | 同じ物に続けて当たらないよう、少しだけ当たらない |
| 引っ張られている**電気のデブリ（回路基板）**がぶつかる | 吹き飛ばしはほぼ無く、**ふつうより長く動けない**。体に電気が走る（`電気のデブリ.md`） |

## 設定できる値（インスペクターの項目）

部品はプレハブに付いていない（起動時に付く）。**値を変えたいときは、プレハブ `SpaceJunkSweeperPlayer` に `SweeperPulledHit` を付けてから変える**（付いていれば、起動時に新しく付けない）。

| 項目名 | 意味 | 実装したときの初期値（目安。調整で変わる） |
| --- | --- | --- |
| Stun Seconds | ぶつかった人が何もできなくなる秒数 | 1.5 |
| Knockback Speed | 横に吹き飛ばす速さ（m/秒） | 9 |
| Knockback Lift | 上に飛ばす速さ（m/秒）。0 で横だけ | 4 |
| Rehit Grace | スタンが解けてから、また当たるようになるまでの秒数 | 0.5 |
| Hit By Teammates | ON：味方が引っ張っている物にも当たる。OFF：相手チームの物だけ | ON |
| Bombs Explode On Hit | ON：引っ張られている爆弾が人にぶつかったら、すぐ爆発する | ON |
| Contact Padding | 体の当たり判定を何 m 広げて「触れた」を見るか | 0.2 |

## 仕組み（分かる人向け）

- **ぶつかられた側の体**が、毎回の物理の更新（FixedUpdate）で、自分の体のまわり（CharacterController の形を Contact Padding だけ広げた円柱）に
  `HookableObject` が重なっていないかを調べる。重なっていて、それを**ほかの人が引っ張っている**なら当たり。
- 「引っ張っている人」は、まずこのPCで動いている `SweeperReel`（`IsActive` で、ホストの返事待ちでない）の `Item` から探す。
  見つからなければ、オンラインの物資の持ち主の番号（`FishingNetSupply.HookedByPlayerIndex`）を見る。
- 当たったら、`SweeperShooter.CancelShot()`（巻き取り中なら投げずに離す。オンラインではホストへ離したことを知らせる）→
  `MeteorStrikeEvent.ApplyPlayerImpact`（`FishingPlayerController.Launch` で吹き飛ばし＋`PlayerStun.Stun`）。
  スタン中の移動禁止は `SweeperMover`・`FishingPlayerController`、光線の禁止は `SweeperShooter` が今までどおり `PlayerStun.IsStunned` を見て行う。
- **オンライン**：判定は、ぶつかられた人のPCが**自分の体についてだけ**行う（爆弾の被害と同じ考え方）。ボットはホストのPCで判定する。
  オンラインのほかの人の体は CharacterController が止めてあるので判定しない。
- **爆弾の即爆発**：1人用は `ExplosiveObject.ExplodeNow()` を直接呼ぶ。オンラインは `FishingNetBomb.RequestDetonate()` → ホストが
  「まだ火がついている」ことを確かめて火を消し、全員へ `ExplodeNow()` を配る（何人かが同時に頼んでも1回だけ）。
  `ExplodeNow()` はもう消えている爆弾では何もしないので、時限で爆発したのと重なっても二重に爆発しない。

## 2026/11/24 に足したこと

### ぶつかった速さで強さを変える

ぶつかった物の速さ（`HookableObject.MeasuredSpeed`。位置の変化から測るので、オンラインのほかの人が動かしている物でも分かる）で、
スタンの秒数と吹き飛ばしを変える。いつもの引き寄せは「距離に関係なく決まった時間で着く」ので、**遠くでつかんだ物・振り回している物ほど速く、強い**。
近くでつかんだ物はゆっくり来るので、ほとんどスタンしない（「初動はスタンなし」もこれでかなう）。

| 項目名（`SweeperPulledHit`。2026/11/24 からプレハブ `SweeperPlayer.prefab` に付いている） | 意味 | 実装したときの初期値（目安） |
| --- | --- | --- |
| Speed Scaling | ON：速さで強さを変える。OFF：いつもいちばん強い値 | ON |
| Min Stun Speed | これより遅い物（m/秒）にぶつかっても、スタンも吹き飛ばしもしない（**爆弾は速さに関係なく即爆発**） | 1.5 |
| Max Stun Speed | この速さ以上でいちばん強い | 9 |
| Min Stun Seconds / Stun Seconds | いちばん弱いとき／いちばん強いときのスタンの秒数 | 0.6 / 1.8 |
| Min Knockback Speed / Knockback Speed | 横の吹き飛ばし（m/秒） | 4 / 11 |
| Min Knockback Lift / Knockback Lift | 上向きの速さ（m/秒） | 2 / 4.5 |
| Grab Grace Seconds | つかまれてからこの秒数の間は当たらない | 0.25 |

電気のデブリは、今までどおり専用の値（長く痺れる・ほぼ飛ばない）。ただし遅すぎる（Min Stun Speed 未満）ときは当たらない。

### スタンの星（★）と、吹き飛んだ瞬間のエフェクト

| 見た目 | 中身 | 値の場所 |
| --- | --- | --- |
| 頭のまわりを回る星 | スタン中、3つの星が頭のまわりを回る（`SweeperStunStars`。リングと同じシェーダーで描く仮の星）。前からの「頭の上の印（StunMarker）」は、星を使う間は出さない | `PlayerStun` の「頭のまわりを回る星」（Use Stars・Star Count・Star Height・Star Orbit Radius・Star Size・Star Orbit Speed・Star Color・Star Material） |
| 吹き飛んだ瞬間 | 当たった側で星のかけらがはじけ、足元に輪が広がる（`SweeperHitEffects`）。吹き飛ばしの共通の入口 `MeteorStrikeEvent.ApplyPlayerImpact` から出るので、**引っ張った物・隕石**のどちらでも出る。弱い吹き飛ばし（Min Speed 2.5m/秒未満）では出さない | `SweeperHitEffects`（プレハブ `SweeperPlayer.prefab` に付けた） |

デザイナーさんの素材が来たら、星は `PlayerStun` の Stun Marker に入れて Use Stars を OFF に、吹き飛びは `SweeperHitEffects` を差し替える。

### 全員の画面に出す（オンライン）

| 何を | どうやって |
| --- | --- |
| スタン（赤い点滅と星） | 本人のPCでスタンしたら、`SweeperNetSync` の「スタンが解ける時刻」（`stunUntil`。本人が書き、全員が読む）を書く。ほかの人のPCはそれを見て、残りの秒数だけ**見た目だけ**のスタンを出す（`PlayerStun.Stun(秒, false)`） |
| 吹き飛んだ瞬間・電気のビリビリ | 一回きりの出来事なので、クリティカルの光と同じ「ホスト経由で全員へ」の呼び出し（`ImpactServerRpc → ImpactClientRpc`）で配る |
| 両手で持っているか | `SweeperNetSync` の `carrying`。ほかの人のPCで、持っている物にぶつかってもスタンしないようにする |

ボットはホストが持ち主なので、同じ形で全員に出る。爆弾の爆発の見た目は前から全員に出ている。

## スタン後の無敵（2026/11/27）

値はプレハブ `SweeperPlayer.prefab` の `PlayerStun` の「スタン後の無敵」の見出し。

| 項目名 | 意味 | 初期値 |
| --- | --- | --- |
| Invincible Seconds | スタンが解けてから、新しくスタンしない・吹き飛ばされない秒数 | 2 |
| Stack Window | スタンし始めてからこの秒数の間だけ、重ねて食らったら長いほうに延ばす。過ぎたらスタン中は延びない | 0.3 |
| Blink While Invincible | 無敵の間、体を点滅させるか | ON |
| Invincible Color | 無敵の間に点滅する色 | 白 |
| Invincible Blink Per Second | 無敵の間、1秒に何回点滅するか | 10 |

- 守っている場所：`PlayerStun.Stun`（爆弾のスタンもここを通る）、吹き飛ばしの共通の入口 `MeteorStrikeEvent.ApplyPlayerImpact`（無敵の間は飛ばされもしない）、`SweeperPulledHit`（無敵の間は当たり判定をしない）。
- **吹き飛ばすだけの爆弾（`KnockBackExplosiveObject`）は、スタンしないので対象外**（無敵の間も飛ばされる）。
- オンライン：無敵かどうかは本人のPC（ボットはホスト）が決める。ほかの人の画面では、届いたスタンが解けたところから同じ秒数だけ白く点滅させる（見た目だけ）。
- 今までの Rehit Grace（0.5 秒）も残っているが、無敵の 2 秒のほうが長いので、ふつうは無敵が効く。

## できていないこと・既知の問題

- **2026/11/27 の無敵は、コンパイルだけ確認。** 人が遊んで、無敵の長さ（2 秒）と白い点滅の見え方を確かめる。
- **人が遊んでの確認はまだ。** 確かめ方：タイトルからボット入りで試合を始め、ボットの近くを通るように物資を引っ張る／爆弾を引っ張ってボットにぶつける。
- **専用の検証シーンは作っていない。** Unity を開いたままだったため。必要なら `Test/` に作る（体を2つ置き、片方で物資を引く）。
- 判定は `FishingPlayerController`（吹き飛ばしの受け口）が付いた体だけ。**試作用の `SweeperPlayer.prefab`（通信なしの検証シーンの体）には効かない**（吹き飛ばしとスタンの部品が付いていないため）。
- オンラインでは、ぶつかられた人の画面での物資の位置（少し遅れて届く）で判定する。引っ張っている人の画面では「かすっていない」ように見えることがある（爆弾の被害と同じ割り切り）。
- 物資は CharacterController に押し返されるので、ぶつかった物資が人に引っかかって止まると、光線がちぎれる判定（`SweeperReel` のたまった力）が進むことがある。吹き飛んで離れるので、ふつうは問題にならない見込み。
