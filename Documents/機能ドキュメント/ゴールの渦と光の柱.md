## この機能は何か

> **2026/11/17 から、見た目を「渦」と「光の柱」の2種類から選べる**（ゴールの演出のプレハブ `GoalEffect` の **Style** のプルダウン）。物資を吸い込む判定の円柱・渦の外の物資の引き寄せ・吸い込み終わったら得点、の流れは2つで共通。違うのは見た目と、吸い込まれる物資の動きだけ。いまの初期値は「渦」。下の「光の柱」の節も読むこと。
> 同じ日に、名前から SpaceJunk を外した（`SpaceJunkGoalVortex` → `GoalEffect`、`SpaceJunkVortexAbsorb` → `GoalAbsorb`、プレハブ `GoalEffect.prefab`、検証シーン `GoalEffectTest.unity`。このファイルも `ゴールの渦.md` から名前を変えた）。

**ゴールの床に、黒い渦がいつも回っている。物資が渦に入ると、小さくなりながら回って渦の真ん中へ吸い込まれ、消えた瞬間に得点になる。**

- 前は「物資がゴールの中に1秒いたら、その場でパッと消えて得点」だった。それを「渦に吸い込まれて消えたら得点」に替えた。
- 渦は黒。外側のふちだけ、**そのゴールのチームの色**でうっすら光る（ロビーの練習用ゴールは、ゴールの床と同じ水色）。
- **渦は高さのある立体（すり鉢・漏斗の形）**（2026/11/17 に追加）。上が広く、床へ向かって細くなる半透明の壁が立ち、その表面を渦の筋が回りながら下へ流れ込む（排水口に吸い込まれる水のような見た目）。床の黒い渦は、すり鉢の底として残っている。見下ろしのカメラで中が見えるよう、壁は半透明で上ほど薄く、高さは約1.6m（物資を吸い込む円柱より高くはならない）。上のふちはチームの色。
- 吸い込まれる物資は、すり鉢の内側の面に沿って下りていく（すり鉢より低い所から入った物は、その高さから下りる）。小さくなりながら回って真ん中へ、という動きは前と同じ。
- **見た目は黒と灰色だけ・光らせない**（2026/11/17、大槻さんの参考画像2枚と指示「黒と灰色で一回チームの色なしでやってみて。らせん状の帯を参考にしつつ、光らせない感じで。飛び散る粒を黒い物質で置き換えて」による試し）。すり鉢のまわりに、**らせん状の細い帯**が6本巻きつき、帯ごとに違う速さで回る（黒い帯と灰色の帯。帯の両端と幅の両側はかすれて消える）。前の「光の粒」の代わりに、**黒い小さなかけら**（いびつな三角すい）が14個、くるくる回りながららせんを描いて底へ吸い込まれていく。**チームの色は、いまは使っていない**（ふちも灰色）。渦のプレハブの Use Team Color をオンにすれば、ふちと帯の明るい所がチームの色に戻る。
- **床の平らな渦巻き模様（すり鉢の底の2Dの渦）は、いまは描いていない**（2026/11/17、大槻さんの「渦巻きの下にある2Dの渦巻きは消しちゃって大丈夫」）。渦のプレハブの Show Floor Vortex をオンにすれば戻る。見た目だけで、物資を吸い込む判定の円柱は変わらない。
- 渦には**円柱の形の判定**がある。物資の真ん中がこの円柱に入ると、吸い込みが始まる。
- 渦は**ゴールの床いっぱいの円**（床の短い辺の 9 割）。床の四角い角は渦の外になるが、角で止まった物資も**渦のほうへ引き寄せられて**、やがて吸い込まれる。だから「ゴールに入れれば点」は前と変わらない。
- **吸い込まれている途中の物資は、誰も引っ張り出せない**（フックが当たらない。ボットも狙わない）。渦に入った時点で確定する。
- 吸い込みは約1秒（前の「1秒いたら得点」と同じテンポ）。
- 得点が入った瞬間の光る演出（`ゴールの得点の演出.md`）は、**吸い込み終わって消えた瞬間に**出る。

## 光の柱（もう1つの見た目）

大槻さんの参考画像（暗い所に、緑に光る半透明の低い筒。筒の中を光の筋が下から上へ流れ、十字のきらめきが立ちのぼる）をもとに作った。

| 部品 | 見た目 |
| --- | --- |
| 床の光 | ゴールの床が丸く明るく光り、ふちに明るい輪。筒の外へもやのようににじむ |
| 筒 | うすく光る半透明の筒。上へ行くほど消える。縦の光の筋が下から上へ流れる |
| 光の筋 | 筒の中に立つ細長い光（14本）。下から上へ流れる |
| きらめき | 小さな十字の光（22個）。筒の中から上へ立ちのぼり、筒より上まで漂って消える |

- **色はチームの色**（大槻さんの回答）。Pillar Use Team Color をオフにすると Pillar Color（参考画像の緑）になる。
- 渦とちがい、**光らせる**見た目（色を足して明るくする）。
- **物資は、真ん中へ寄りながらゆっくり回って上へ浮かび、小さくなって消える**（大槻さんの回答。消えたら得点）。浮かぶ高さは、筒の高さ＋Rise Above Pillar（高い所から入った物は、そこから 0.6m 上まで）。
- 検証シーン `Test/GoalEffectTest.unity` は、再生すると **10 秒ごとに渦と光の柱が入れ替わる**（検証シーンの TestDriver の Switch Style Seconds。0 なら入れ替えず、プルダウンで選んだまま）。
- 試合で光の柱にするときは、プレハブ `Prefabs/Effect/GoalEffect.prefab` の Style を「光の柱」にする（全ステージとロビーに効く）。

## 遊ぶ人から見た動き

| 操作・場面 | 結果 |
| --- | --- |
| 試合でゴールを見る | 床に黒い渦がゆっくり回り、その上に半透明のすり鉢が立っている（上から見て左回り）。すり鉢の壁を黒い筋が回りながら下へ流れ込む。ふちはチームの色 |
| 物資を自分のチームのゴールの渦に投げ入れる | 物資がすり鉢の内側に沿って、渦のまわりを回りながら真ん中へ下りていき、だんだん小さくなって、最後に床の下へ沈むように消える。消えた瞬間に点が入り、ゴールのまわりが光る |
| 物資がゴールの角（渦の外）に止まる | 渦のほうへ滑っていき、渦に入ったら吸い込まれる |
| 吸い込まれている物資にフックを撃つ | 当たらない（引っ張り出せない） |
| 物資を引っ掛けたまま、ゴールの中へ持ち込む | 引っ掛けている間は吸い込まれない（前と同じく、引きずり込みでは点にならない）。手を離すと吸い込まれる |
| 3チームの試合で、閉ざされたゴール | 渦は出ない。物資を入れても何も起きない（前と同じ） |
| ラウンドの始まり（輸送機が飛んでくる演出） | 飛んでいる間は渦は出ない。着地すると、床の渦が真ん中から広がり、すり鉢が下から伸びて出てくる |
| ロビーの練習用ゴールに物資を入れる | 水色のふちの渦に吸い込まれて消える（得点は無い） |
| 検証シーン `Test/GoalEffectTest.unity` を再生する | 左の床のゴール（青）と右の輸送機のゴール（赤）に、上から箱が順番に落ちてきて、渦に吸い込まれる。ときどき角に落ちて、引き寄せられる |

Color・Vortex Time・Appear・Brightness・Part・Funnel は**スクリプトが毎回入れる**ので、マテリアルで変えても効かない。

**光の柱の見た目（マテリアル `GoalPillar.mat`）**：Wall Glow（筒の光）・Floor Glow（床の光）・Streak Glow（光の筋）・Sparkle Glow / Sparkle Size（きらめきの濃さ・大きさ）・Rise Speed（筋ときらめきがのぼる速さ）・Cover（下の床を暗くする強さ）。

**決まり**：

- **明るい所の色**は、Use Team Color がオンならチームの色（`SpaceJunkTeams.TeamColor`。ロビーの練習用ゴールは、そのゴールの Default Color）、オフなら Neutral Color。**光らせない**ので、どの部品もこの色より暗い色で描く。
- 渦は**同じシーンのゴールだけ**に出る。進行役のプレハブの子から外して別のシーンに置くと、そのシーンのゴールにしか出ない。
- 渦の回る向き（上から見て左回り）と、吸い込まれる物資が回る向きは、そろえてある。シェーダーかスクリプトの片方だけで向きを変えないこと。

## オンラインでの動き

- **吸い込みを始める・得点を数えるのはホストだけ**（前と同じ）。参加者のPCでは何も数えない。
- ホストは、物資が渦の円柱に入ったら吸い込みを始め、参加者のPCへ「この物資の吸い込みが、ホストの時計のこの時刻に始まった」と知らせる（`FishingNetSupply.BeginAbsorbClientRpc`）。
- **位置と回転**は、ホストが動かした物を、これまでどおり通信（NetworkTransform）で全員に配る。
- **大きさ**は通信で配られない作りなので、参加者のPCが、知らされた時刻と全員で合わせた時計（`ServerTime`）から自分で小さくする。だから、どのPCでも同じ速さで小さくなる。
- 吸い込み終わったら、ホストが点を数えて物資を消す（前と同じ消し方で、全員の画面から消える）。得点の光る演出も、前と同じ知らせで全員に出る。
- 吸い込み中は、どのPCでも物資の当たり判定を切り、「消えた扱い」にする。だから参加者のフックも当たらない。

## 仕組み（分かる人向け）

> スクリプトの詳しい説明は `スクリプトの説明/Game/Effect/GoalEffect.md`。

1. ホストの `SpaceJunkGoal.OnTriggerStay` → `TryCollect`：素材で、引っ掛けられていなければ `GoalEffect.ServerFeed(ゴール, 物資, Collect)`。
2. `ServerFeed`：物資の持ち主がホストに戻っていて、物資の重心が渦の円柱（半径・床から下 0.5m〜ゴールの判定の上の端）の中なら `GoalAbsorb.Begin` で吸い込みを始め、参加者へ知らせる。外なら、渦の真ん中のほうへ水平に引き寄せる（1つの物理の更新で1回）。
3. `GoalAbsorb`：物資の当たり判定を切り、`HookableObject.SetAbsorbing(true)`（`IsVanished` が true になる）。ホストは物理を止めて、半径を縮めながら回し、沈めて、大きさを小さくする。参加者は大きさだけ小さくする。
4. 時間が来たら（ホスト）：大きさを戻してから `Collect`（`SpaceJunkRound.ServerCollect` → 数えたら `FlashClientRpc` → `HookableObject.Vanish`）。戻した大きさは、同じフレームで消えるので見えない。
5. 渦の円柱の大きさ：ゴールの得点の演出と同じ測り方（`SpaceJunkGoalScoreEffect.TryGetGoalArea`）で床の四角を測り、短い辺の半分×Fill。足もとは、ゴールの真ん中の真下にある床（輸送機なら荷台）の上面を光線で調べる。ロビーの練習用ゴールは判定の箱の大きさ。
6. すり鉢：上のふちの半径＝渦の半径、高さ＝Funnel Height（円柱の高さまで）、底の半径＝渦の半径×Funnel Bottom。高さ v（0〜1）での半径は 底＋(上−底)×v^Funnel Curve。吸い込まれる物資の高さは、いまの半径でのすり鉢の面の高さ（`FunnelSurfaceY`）＋0.2m と、入ったときの高さの低いほうへ寄せる。
7. 描き方：`Graphics.RenderMesh` でシーンに物を作らずに描く（全体カメラが測るステージの大きさに入らない）。始まりの演出でゴールの見た目が隠れている間は描かない。

## 確かめたこと

## できていないこと・既知の問題

- **人が遊んでの見え方・遊びやすさ（渦の大きさ・吸い込みの長さ・黒さ）は未確認。** 値は一旦作ってみたもの。
- **別のPC（参加者）での見え方は、実際の2台では確かめていない。** 1つの Unity の中でホストと参加者をつなぐ自動テストで、参加者の画面でも小さくなって消えることは確かめた。
- 参加者のPCでは、位置は通信の遅れぶん（ほんの少し）遅れて動き、大きさは自分の時計で小さくなるので、通信がとても遅いと、小さくなるのと位置がわずかにずれることがある。
- 吸い込み中の物資は「消えた扱い」なので、物資を出す係（スポナー）は、消える約1秒前から次の物資を出してよいと数える（マップの物資が一瞬1つ多くなりうる）。
- 吸い込み中の物資が、ほかの理由（爆弾の爆発など）で消されたときは、得点にならない。
- 角の引き寄せは、物資と床の摩擦に勝つ強さにしてある。重いデブリ（引きずって運ぶ物）の引き寄せと吸い込みは、試合では見ていない（ボーナスの数え方は、吸い込み中も「まだある」と数えるように直してある）。
- 渦（床の渦とすり鉢）は描いているだけの見た目で、当たり判定は無い。床の下へ本当に穴が開いているわけではない（物資は最後に床の下へ少し沈みながら消える）。プレイヤーはすり鉢の壁を通り抜けられる。
- すり鉢の壁は半透明で重ねて描くので、見る角度によっては、手前と奥の壁の重なり方が不自然に見えることがある（人の目での確認はまだ）。
