## この機能は何か

ラウンドイベント（デブリセット・高単価デブリ・特殊デブリなど。`宇宙ごみのラウンドイベント.md`）が**始まる5秒前**から、画面を横切る**半透明の赤い帯**と、**「緊急連絡！」の白い大きな文字**を出し、1.5秒後に「**デブリセット発生！**」「**高単価デブリ発生！**」「**高重量デブリ発生！**」のような、そのイベントの文字に切り替えて知らせる（文字はインスペクターで変えられる）。イベントが始まると帯は閉じる。

- 帯はデザイナーさんの素材 `UI_EventBanner_base`（赤い横じまの帯。画像そのものが半透明）
- 置き場所はデザイン案の写真のとおり、**画面の真ん中より下に、横いっぱい**
- 前に出ていた「イベントまで 5・4・3…」の文字の代わり（2026/11/26・大槻さんの依頼。その文字はやめた）
- 帯が閉じるのと同時に、デブリセットの腕やルーレットが出てくる

設計図：大槻さんの写真（試合の画面の下のほうに、赤い半透明の帯と「緊急連絡！」の文字。右上にはデブリセットの枠）。

## 遊ぶ人から見た動き

| いつ | どうなるか |
| --- | --- |
| イベントの前 | 何も出ない |
| イベントの5秒前〜4.8秒前 | 赤い帯が**上下に開いて**出てくる。同時に「緊急連絡！」が**右から滑り込んでくる**（0.3秒） |
| 1.5秒たったとき（3.5秒前） | 文字が「デブリセット発生！」などのイベントの文字に変わり、もう一度右から滑り込んでくる |
| 4.8秒前〜イベントの始まり（文字の切り替えをはさんで） | 帯が**警報のように点滅**しながら残る（1秒に 2.5 回、薄くなったり濃くなったり） |
| イベントが始まってから 0.25 秒 | 帯が上下に閉じ、文字も消える。デブリセットの腕・ルーレットが出始める |

- 時間は**イベントの始まる時刻（全員で同じ時計）から数える**ので、どのPCでも同じ時に出る。途中から見え始めた人には、残りの時間だけ出る。
- **どのイベントになるかは、ラウンドの始まりに先に決めて全員に配っている**（2026/11/26 に、始まる瞬間の抽選から変えた。当たりやすさは前と同じ）。だから始まる前の帯にイベントの名前を出せる。
- 候補に「今回は何も起きない」が入っていて、それが当たったラウンドでは、帯は出ない。
- 一覧に無いイベントのとき（新しく足したイベントで、文字をまだ書いていないとき）は、「緊急連絡！」のまま。
- ラウンドの結果を見せている間は出ない。

### 検証シーンの使い方

`Assets/Scenes/Test/EventBannerUITest.unity` を開いて再生する。

- 再生するとすぐ帯と文字が出て、1.5秒で「デブリセット発生！」に切り替わり、5秒で閉じる。8秒ごとにくり返し、回ごとに「高単価デブリ発生！」「高重量デブリ発生！」…と一覧の順に文字が変わる
- 再生中に `EventBannerUI` の右クリックメニュー（歯車）の「**テスト：今すぐもう一度出す**」で、いつでも最初から見られる

## 設定できる値（インスペクターの項目）

`Assets/Resources/EventBannerUI.prefab` の `EventBannerUI`。

| 項目名 | 意味 | 実装したときの初期値（目安。調整で変わる） |
| --- | --- | --- |
| Message | 最初に出す文字 | 緊急連絡！ |
| Message Seconds | 最初の文字を出す秒数。そのあと、下のイベントごとの文字に切り替わる | 1.5 |
| **Event Messages** | **イベントごとの文字。** 1行ごとに Kind（イベントの種類）と Text（出す文字）。行を足せば、新しいイベントの文字も書ける | DebrisSet＝デブリセット発生！／HighValueDebris＝高単価デブリ発生！／HeavyDebris＝高重量デブリ発生！ |
| Font | 文字のフォント。空ならパソコンに入っている日本語のフォント（**デザイナーさん指定のフォントが来たら入れる**） | 空 |
| Lead Seconds | イベントが始まる何秒前から出すか（前の「イベントまで」の文字と同じ5秒） | 5 |
| Open Seconds / Close Seconds | 帯が開く秒数／イベントが始まってから帯が閉じきるまでの秒数 | 0.2／0.25 |
| Text Slide Seconds / Text Slide Distance | 文字が滑り込んでくる秒数／距離（右から） | 0.3／320 |
| Blink Per Second / Blink Min Alpha | 帯の点滅の速さ（1秒に何回。0＝点滅しない）／いちばん薄いときの濃さ（1＝薄くならない） | 2.5／0.6 |
| Test Mode / Test Interval | ラウンドが無くてもくり返し出す。**本番のプレハブではオフ**（検証シーンだけオン）／間隔（秒） | オフ／8 |

置き場所・大きさは、プレハブの `Banner`（帯）と `Label`（文字）で変えられる。初期値（1920×1080 の画面での値）：帯は横いっぱい（左右の端は 40 ずつ画面の外）・高さは画像のまま 216・画面の真ん中から 280 下。文字は 96 の太字で、帯の真ん中。**帯と文字の高さは両方そろえて動かす**（文字は帯の子ではない。帯が開くときに文字がつぶれないようにするため）。

## 仕組み（分かる人向け）

- **表示するだけ。** イベントが始まってからの秒数は、ホストが決めて全員へ配っている `SpaceJunkRound.SecondsSinceEventStarted` を毎フレーム読む。何も送らない
- ゲームの開始時に `Resources/EventBannerUI.prefab` から1つ作り、シーンをまたいで残す（デブリセットのUI・ルーレットと同じやり方）
- 見た目は「始まってからの秒数」だけで決まる（帯の縦の大きさ・帯の濃さ・文字の横の位置と濃さ）
- 並び順は 30。デブリセットのUI（20）より手前、始まりの演出（85）・ポーズ画面（100）より奥

## できていないこと・既知の問題

- **動いているところ・本物の試合・参加者側の画面・人が遊んでの確認はまだ**（止まった見た目を、画面なしの Unity で画像にして確かめただけ）
- **5秒前から・名前の切り替えに変えたあと、自動テストは流していない**（本人が Unity エディタを開いていたため。コンパイルが通ることと、プレハブの値を書き換えたことだけ）。プレハブの値（Lead Seconds・Test Interval）は、Unity を使わずファイルを直接書き換えた
- 前は仮の画面（`SpaceJunkMatchUI`）が、イベントが始まると4秒間「イベント発生！　〇〇」とイベントの説明の文を出していたが、**このバナーと重複するのでやめた**（2026/11/26・大槻さんの了承）。そのため、**イベントの説明の文はいまは画面に出ない**（名前は画面の上の一行「イベント：〇〇」に出る）
- 文字のフォントは仮（パソコンの日本語フォント）
- 帯の位置は、写真の見た目から読み取った値（画面の真ん中から 280 下）
