## この機能は何か

ラウンドイベント（デブリセット・高単価デブリ・特殊デブリなど。`宇宙ごみのラウンドイベント.md`）が**始まる3秒前**に、画面を横切る**半透明の赤い帯**と**「緊急連絡！」**を出し、2回点滅させてから、**そのイベントの見出しと説明**（デブリセットなら「**特別調達依頼**／指定された資材を集めて、ボーナススコアを獲得しよう！」）に入れ替えて知らせる。見出しと説明はインスペクターで変えられる。

- 帯はデザイナーさんの素材 `UI_EventBanner_base`（赤い横じまの帯。画像そのものが半透明）
- 置き場所はデザイン案の写真のとおり、**画面の真ん中より下に、横いっぱい**
- 前に出ていた「イベントまで 5・4・3…」の文字の代わり（2026/11/26・大槻さんの依頼。その文字はやめた）

設計図：デザイン案「BANNER表示」（3枚の絵と、経過時間ごとの演出の表）。

## 遊ぶ人から見た動き

出始めを 0 秒とする（イベントの始まる3秒前）。

| 経過時間 | どうなるか |
| --- | --- |
| 0.0秒 | 帯と「緊急連絡！」が同時に出る |
| 0.0〜0.2秒 | そのまま |
| 0.2〜0.4秒 | 帯と文字が消える（1回目の点滅） |
| 0.4〜0.6秒 | 戻る |
| 0.6〜0.8秒 | 帯と文字が消える（2回目の点滅） |
| 0.8〜1.0秒 | そのまま |
| 1.0〜1.5秒 | 帯はそのままで、「緊急連絡！」が**右へ**出ていき、同時にイベントの見出しと説明が**画面の左から**入ってくる |
| 1.5〜2.0秒 | 見出しと説明が帯の真ん中で止まって出ている |
| 2.0〜2.5秒 | 帯と見出し・説明がいっしょに薄くなって消える |
| 3.0秒 | イベントが始まる（デブリセットの腕・ルーレットが出始める） |

| イベント | 見出し | 説明 |
| --- | --- | --- |
| デブリセット | 特別調達依頼 | 指定された資材を集めて、ボーナススコアを獲得しよう！ |
| 期間限定高価値デブリ（高単価デブリ） | 市場価格高騰！ | 特定の資材が高値で取引中！今のうちに回収しよう！ |
| 特殊デブリ（高重量デブリ） | 高重量デブリ発生！（**仮**。デザイン案に無かったので前の文字のまま） | なし（**未定**） |

- 時間は**イベントの始まる時刻（全員で同じ時計）から数える**ので、どのPCでも同じ時に出る。途中から見え始めた人には、残りの時間だけ出る。
- **どのイベントになるかは、ラウンドの始まりに先に決めて全員に配っている**（2026/11/26 に、始まる瞬間の抽選から変えた。当たりやすさは前と同じ）。だから始まる前の帯にイベントの名前を出せる。
- 候補に「今回は何も起きない」が入っていて、それが当たったラウンドでは、帯は出ない。
- 一覧に無いイベントのとき（新しく足したイベントで、文字をまだ書いていないとき）は、入れ替わらずに「緊急連絡！」のまま消える。
- ラウンドの結果を見せている間は出ない。

### 検証シーンの使い方

`Assets/Scenes/Test/EventBannerUITest.unity` を開いて再生する。

- 再生するとすぐ帯と「緊急連絡！」が出て、2回点滅し、1秒で「特別調達依頼」に入れ替わり、2.5秒で消える。4秒ごとにくり返し、回ごとに「市場価格高騰！」「高重量デブリ発生！」…と一覧の順に変わる
- 再生中に `EventBannerUI` の右クリックメニュー（歯車）の「**テスト：今すぐもう一度出す**」で、いつでも最初から見られる

## 設定できる値（インスペクターの項目）

`Assets/Resources/EventBannerUI.prefab` の `EventBannerUI`。時刻はどれも「出始めを 0 とした秒」。

| 項目名 | 意味 | 実装したときの初期値（目安。調整で変わる） |
| --- | --- | --- |
| Message | 最初に出す文字 | 緊急連絡！ |
| **Event Messages** | **イベントごとの見出しと説明。** 1行ごとに Kind（イベントの種類）・Title（見出し）・Subtitle（説明。空なら出さない）。行を足せば、新しいイベントの文字も書ける | 上の表のとおり |
| Font | 文字のフォント。空ならパソコンに入っている日本語のフォント（**デザイナーさん指定のフォントが来たら入れる**） | 空 |
| Lead Seconds | イベントが始まる何秒前に出し始めるか | 3 |
| First Blink At / Blink Off Seconds / Blink Interval / Blink Count | 1回目の点滅の時刻／点滅で消えている秒数／点滅の間隔／点滅の回数 | 0.2／0.2／0.4／2 |
| Switch At / Switch Seconds / Switch Distance | 入れ替わりが始まる時刻／かかる秒数／文字が動く距離 | 1／0.5／1200 |
| Fade At / Fade Seconds | 消え始める時刻／消えるまでの秒数 | 2／0.5 |
| Test Mode / Test Interval | ラウンドが無くてもくり返し出す。**本番のプレハブではオフ**（検証シーンだけオン）／間隔（秒） | オフ／4 |

置き場所・大きさは、プレハブの `Banner`（帯）・`Label`（緊急連絡！）・`EventTitle`（見出し）・`EventSubtitle`（説明）で変えられる。初期値（1920×1080 の画面での値）：帯は横いっぱい（左右の端は 40 ずつ画面の外）・高さは画像のまま 216・画面の真ん中から 280 下。「緊急連絡！」は 96 の太字で帯の真ん中、見出しは 88 の太字で帯の真ん中より 22 上、説明は 30 の太字で帯の真ん中より 58 下。**帯を上下に動かすときは、文字も同じだけ動かす**（文字は帯の子ではない）。

## 仕組み（分かる人向け）

- **表示するだけ。** イベントの始まる時刻と種類は、ホストが決めて全員へ配っている `SpaceJunkRound` の値（`SecondsUntilEvent`・`SecondsSinceEventStarted`・`UpcomingEvent`）を毎フレーム読む。何も送らない
- ゲームの開始時に `Resources/EventBannerUI.prefab` から1つ作り、シーンをまたいで残す（デブリセットのUI・ルーレットと同じやり方）
- 見た目は「出始めてからの秒数」と「イベントの種類」だけで決まる（帯と文字の濃さ・文字の横の位置・どの文字を出すか）
- 並び順は 30。デブリセットのUI（20）より手前、始まりの演出（85）・ポーズ画面（100）より奥

## できていないこと・既知の問題

- **作り替えたあと、Unity で一度も動かしていない**（本人が Unity エディタを開いていたため）。コンパイルが通ることと、同じ寸法で描いた画像で文字が帯に収まることだけ確かめた。**プレハブ（見出し・説明の文字の部品と、値）は、Unity を使わずファイルを直接書き換えた**。おかしければ、メニュー `イベントの警告バナーの検証シーンを作る` で作り直せば、ツールの通りの形になる
- 特殊デブリ（高重量デブリ）の見出しと説明は、デザイン案に無かったので仮（見出しは前の「高重量デブリ発生！」、説明は空）
- 前は仮の画面（`SpaceJunkMatchUI`）が、イベントが始まると4秒間「イベント発生！　〇〇」とイベントの説明の文を、イベント中は「イベント：〇〇　残り ○ 秒」の一行を出していたが、**どちらもやめた**（2026/11/26・大槻さんの依頼）。イベントの見出しと説明は、このバナーにだけ出る。**イベントの残り秒数は、いまは画面に出ない**
- 文字のフォントは仮（パソコンの日本語フォント）
- 帯の位置は、写真の見た目から読み取った値（画面の真ん中から 280 下）
