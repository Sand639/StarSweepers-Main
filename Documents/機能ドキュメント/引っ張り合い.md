## この機能は何か

だれかが光線で引っ張っている物資を、**別の人も光線でつかめる**ようにしたもの。つかむと**引っ張り合い**になる。

2本の光線は、それぞれのプレイヤーへ物資を引っ張る。**歩いて下がったり、体を回して振り回したりすると、引っ張る力が強くなる**。
力で負けて物資が自分から離れていくと、その人の光線に「引きたいのに離れていった」分がたまり、**先にたまりきった側の光線が切れる**。
残った人は、そのままいつもの引き寄せに戻る（その位置から引き直す。クリティカルのタイミングも数え直す）。

（小野田さんの理想：「無理やり振り回したりして相手よりも物理的な力が強ければ、相手側が切れる」）

## 遊ぶ人から見た動き

| 操作 | 結果 |
| --- | --- |
| ほかの人が引っ張っている物資に光線を当てる | 引っ張り合いになる（前は光線がすり抜けていた） |
| 引っ張り合いの最中 | 物資は2人の間で、強いほうへ動く。**投げられない**（押しても何も起きない）。ゆっくり歩ける |
| 物資から離れる向きへ歩く | 引く力が強くなる |
| 体を回して光線を振る | 引く力が強くなり、物資が横へも振られる |
| 物資が自分から離れていき続ける | 自分の光線が切れる（ちぎれる見た目） |
| 物資を自分の手前（Stop Distance）まで引き寄せた | 自分の勝ち（相手の光線が切れる） |
| 光線の長さの上限より離れた | 離れた側の光線が切れる |
| 3 秒たっても決まらない | **両方の光線が切れて**、物資はその場に落ちる |
| 引っ張り合いの最中にスタンした・止められた | その人の負け（相手が続きを引く） |
| クリティカルで飛んでいる物・両手で持っている物 | 引っ張り合いにならない（つかめない） |
| 重い物（特殊デブリ） | 初期設定では引っ張り合いにならない（Tug On Heavy で変えられる） |

- 勝った人は、いつもの引き寄せに戻る。そこから押せば後ろへ投げる・手前なら両手で投げる・押さなければ後ろへ引っ張り切る。
- 爆弾でも起きる。導火線はそのまま進むので、引っ張り合いの最中に爆発することもある（爆発したら両方外れる）。

## 設定できる値（インスペクターの項目）

`SweeperReel` の「引っ張り合い」の見出し。**オンラインでは、つかんでいた人の体の値を使う**（ホストが読む）。

| 項目名 | 意味 | 実装したときの初期値（目安。調整で変わる） |
| --- | --- | --- |
| Tug Enabled | 引っ張り合いを起こすか | ON |
| Tug On Heavy | 重い物でも起こすか | OFF |
| Tug With Teammates | 味方どうしでも起こすか | ON |
| Tug Base Pull | いつも自分のほうへ引く力（m/秒²） | 6 |
| Tug Yank Gain | 物資から離れる向きに歩いた速さ 1m/秒 あたり、足す力 | 3 |
| Tug Swing Gain | 体を回して光線の先を振る速さ 1m/秒 あたり、足す力 | 0.6 |
| Tug Max Swing Tip | 振る速さを数える上限（m/秒） | 12 |
| Tug Swing Side | 振り回したとき、物資を横へ振る力の割合 | 0.5 |
| Tug Drag | 物資の速さが落ちていく強さ | 3 |
| Tug Max Speed | 物資が動く速さの上限（m/秒） | 10 |
| Tug Snap Strain | 「引きたいのに離れていった距離」（m）がこれだけたまった側が切れる。小さいほど早く決着 | 1.2 |
| Tug Strain Recovery | 物資が自分のほうへ来ている間、たまった距離が減る速さ（m/秒） | 1.5 |
| Tug Max Seconds | この秒数で決まらなければ両方切れる（0 で時間切れなし） | 3 |
| Tug Max Length Scale | 光線の長さの上限（Max Reach）の何倍まで離れたら切れるか | 1.15 |

**調整のめやす**：

- 決着が早すぎる → Tug Snap Strain を上げる／Tug Max Speed を下げる
- 振り回しが強すぎる → Tug Swing Gain・Tug Max Swing Tip を下げる
- 下がって引くのが弱い → Tug Yank Gain を上げる（巻き取り中の歩く速さ Reel Move Scale も関係する）
- いつも時間切れになる → Tug Base Pull を下げる（差が出やすくなる）か、Tug Max Seconds を伸ばす

## 仕組み（分かる人向け）

- **力**：光線ごとに `toward × (Base Pull + Yank Gain × 離れる速さ + Swing Gain × 光線の先の速さ) ＋ 接線 × Swing Side × Swing Gain × 光線の先の速さ` を足して加速度にし、Drag で減らし、Max Speed で抑える。
  体の速さと回る速さは、体の位置と向きの変化から測る（ホストにも体の位置と向きは届いているので、追加の通信は要らない）。
- **決着**：光線ごとに「物資の速さのうち、自分から離れる成分」をためる（近づいていれば Strain Recovery で減る）。先に Snap Strain を超えた側が負け。
  ほかに、手前（Stop Distance）まで引き寄せた・光線の長さを超えた・時間切れ。
- **上下**：始めたときの高さより上なら重力で落とし、下には沈ませない（物資の重力の設定に関係なく同じ動き）。
- **通信なし**：後から来た体の `SweeperReel.Begin` が、ほかの体の巻き取り（`FindLocalHolder`）を見つけて `SupplyTug` を始める。
  重力は、つかんでいた人が「つかむ前の設定」を引き継ぐ（負けた側は重力を戻さない。最後に離した人が戻す）。
- **オンライン**：後から来た人のPCが `NetSupply.RequestTug` → ホストが条件（つかまれている・引っ張り合い中でない・クリティカルで守られていない・`AllowsTug`）を見て `TugChallenger` に入れ、持ち主を取り戻して `SupplyTug` を動かす。
  2人のPCの `SweeperReel` は `TugChallenger` を見て「引っ張り合い中」になり、物資を動かさない（光線を描くだけ）。
  決着したら、ホストが勝った人を `HookedByPlayerIndex` にして持ち主をその人へ移す。勝った人のPCは持ち主が来るのを待って続きを引く。負けた人のPCは「つかんでいる人」が自分でなくなったのを見て、光線が切れる。
  引っ張り合い中に片方が「離した」を送ってきたら、相手の勝ち。爆風・ゴール・消えたときは決着させずに止める。
- 答え合わせ（`ServerCheckClaim`）は、引っ張り合い中は持ち主の食い違いを直さない（ホストが持っていて当然のため）。

## できていないこと・既知の問題

- **オンラインは人が遊んでの確認がまだ。** 2台で、同じ物資を狙って確かめる（`LANでの複数人プレイ.md`）。
- **力の値は仮。** 遊んで決める。
- 引っ張り合いの最中に「どちらが勝っているか」の表示が無い（光線の色を変える・ゲージを出すなどは未定）。
- ボットは引っ張り合いを狙わない（たまたま同じ物に当たったときだけ起きる）。引っ張り合いになっても特別な動き（下がる・振り回す）はしない。
- オンラインでは、ホストに届いている体の位置で力を計算するので、ほんの少し遅れて効く。
- 通信なしの検証用シーンは作っていない（自動テスト `SupplyTugTests` で確かめた）。
