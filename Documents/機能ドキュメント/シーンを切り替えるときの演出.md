## モニターを通る2つの切り替え（2026/11/27）

- **ロビー → 試合**：直前の画が止まり、左上のモニターから引いて操作盤が現れる。右下に読み込んだステージの最初の画が映り、そこへ寄って画面がいっぱいになったらステージ紹介とカウントダウンへ進む。
- **最終結果 → ロビー**：勝利チームの紹介が終わると操作盤へ引く。左上に保存した結果が現れ、右下のロビーへ寄って操作を再開する。保存した結果がない場合は、その場で見えていた画を使う。
- 引きは約0.8秒、寄りは約0.95秒。途中にシーンの読み込みが入る。ホストは全員の演出完了を待ってから初戦の開始時刻を配る。未応答の場合の待ち時間には上限がある。
- 右下のプレビューは目的地のカメラの画。画面全体に切り替わると、上に重ねる文字や案内も見える。
- 操作盤が見える間は、左上と右下の画面に古いテレビのような細い横線と動く砂嵐を重ねる。読み込みを待つ間も動き続け、画面いっぱいに寄る前に薄れて消える。

**`Assets/Scenes/Test/MonitorTransitionTest.unity`** を開いて再生し、Space またはコントローラーの A を押すと試せる。箱の背景色が変わり、2つの窓で切り替え前と切り替え後の画を見られる。既存のシーン・プレハブの保存内容は変更していない。

## この機能は何か

ロビーから試合のマップへ移るときに、**画面をいったん覆ってから切り替え、マップが読み込まれたら画面を開く**演出。
今までは、ロビーの画面からいきなりマップに切り替わっていた。

共通の演出はインスペクターのプルダウンで選べる。試合の入口と結果からの戻りはモニター、次のラウンドへ移るときは丸い色帯を指定している。

| 種類 | 見え方 |
| --- | --- |
| フェード | 画面全体がだんだん暗くなり、マップでだんだん明るくなる |
| ワイプ | 左から黒い幕が伸びて画面を覆い、マップでは同じ向きのまま右へ抜けていく |
| モニター | 今の画面から引いて操作盤の全体を出し、次の画面へ寄る |
| 丸い色帯 | 右から色帯が入って覆い、左へ抜ける |
| 勝ったチームの色（2026/11/17。ソウホイチョン） | **ラウンドの終わり専用。** 勝ったチームの色の板が、上の得点バーのあたりから画面いっぱいに広がり、真ん中に「**RED win!**」（引き分けは「DRAW」）。次のマップでは、板が**左上の角へ縮んで**消える。メンバーの絵コンテに合わせた**仮の演出**（本番の演出は未定） |

オンラインでは、**ホストが試合を始めると、つないでいる全員の画面で同じ演出が出る。**

## 遊ぶ人から見た動き

| 操作 | 結果 |
| --- | --- |
| ロビーで「ゲームを始める」を押す／全員がチームエリアに入ってカウントダウンが終わる | 操作盤の左上から右下へ視点が移り、マップの紹介が始まる |
| ラウンドが終わり、試合が続く | 結果を見せたあと、色帯で覆って次のマップへ移る |
| 試合が決まり、勝ったチームの紹介が終わる | 操作盤の右下のモニターを拡大し、ロビーへ戻る |
| 演出の途中 | 画面のボタンは押せない（覆っている画面がクリックを受け止める） |

### 検証シーンでの試し方

1. `Assets/Scenes/Test/SceneTransitionTest.unity` を開いて再生する
2. **Space**（コントローラーは **A**）を押すと、演出を出してこのシーンを読み直す。読み直すたびに背景の色が変わる
3. 種類を変えるときは、再生する前に `Assets/Resources/SceneTransition` を選んでプルダウンを変える。
   再生中に変えるなら、Hierarchy の **DontDestroyOnLoad** の中にある `SceneTransition` を選んで変える（再生を止めると元に戻る）

検証シーンを作り直すときは `Tools > StarSweepers > トランジション > 検証シーンを作り直す`。

## 設定できる値（インスペクターの項目）

`Assets/Resources/SceneTransition.prefab` を選ぶと出る。

| 項目名 | 意味 | 実装したときの初期値（目安。調整で変わる） |
| --- | --- | --- |
| Transition Type | 演出の種類（プルダウン） | フェード |
| Cover Seconds | 画面を覆いきるまでの秒数 | 0.5 |
| Hold Seconds | 次のシーンが読み込まれてから、覆ったまま待つ秒数（読み込んだ直後のカクつきを隠す） | 0.2 |
| Reveal Seconds | 画面が開ききるまでの秒数 | 0.5 |
| Max Wait Seconds | 次のシーンが読み込まれないとき、覆ったまま待つ最長の秒数。過ぎたら開く（真っ暗のまま止まらないように） | 15 |
| Color | 画面を覆う色 | 黒 |

## 仕組み（分かる人向け）

1. ホストが試合を始めると（`SpaceJunkSession.ServerStartMatch`）、`SceneTransition.PlayForEveryone(LoadNextMap)` を呼ぶ
2. ホストは自分の画面で覆い始め、同時に参加者全員へ「この種類で覆って」と通信で送る（名前付きのメッセージ。ネットワーク用のプレハブ一覧に入れなくてよい）
3. ホストの画面を覆いきったら `LoadNextMap` が呼ばれ、全員のシーンがマップへ切り替わる
4. それぞれの画面で、マップが読み込まれたら開く

**種類を増やすときは、`SceneTransitionEffect.cs` の一番上の手順どおりに3か所を足す**（新しいファイル1つと2行）。
詳しい流れと、ほかの場面（ラウンドの切り替え・ロビーへ戻る）で使うときの呼び方は `スクリプトの説明/Common/UI/SceneTransition.md`。

プレハブにはしてある（`Resources/SceneTransition.prefab`）が、**シーンに置く必要は無い**。置いても2つ目は自動で消える。

## できていないこと・既知の問題

- **人が遊んでの確認はまだ。** 画面なしの Unity で、検証シーン（フェード・ワイプ）と、タイトル → ホスト → ロビー → 試合開始（ボット1人・STAGE_Simple）を自動で動かし、覆う → マップへ移る → 開く の順に進むこと、エラーが出ないことを確かめた
- **参加者の画面に演出が出るかは、まだ確かめていない**（2台のPC、または検証用のビルドを2つ起動して確かめる）。`リスクリスト.md` に登録した
- 使っているのは**ロビー → 試合の1ラウンド目**と、**ラウンドの切り替え（勝ったチームの色。2026/11/17）**。試合が終わってロビーへ戻るとき・タイトルとロビーの行き来には、まだ付けていない（付けるのは呼ぶ所に1行足すだけ。`スクリプトの説明/Common/UI/SceneTransition.md`）
- 演出の見た目は仮（黒一色）。デザインが決まったら種類を足すか、今の2つを作り直す
- 勝ったチームの色の演出も**仮**。「RED win!」が見えるのは、覆いきってから次のマップが読み込まれて開き始めるまで（読み込みが速いと1秒ほど）。長く見せたいなら Hold Seconds を延ばす（ただし全部の種類に効く）。色は `SpaceJunkTeams.TeamColor`（ゴールやプレイヤーと同じ赤・青）。検証シーン（`SceneTransitionTest`）で試すと、試合が無いので「RED win!」になる
- 勝ったチームの色の演出は、画面なしの Unity で本物の試合（ホスト＋ボット3人・STAGE_Simple・1ラウンド10秒）を動かし、青が1ラウンド目を取る → 「BLUE win!」で覆う → 2ラウンド目が始まって演出が消える、まで確かめた。**参加者の画面と、人が遊んでの確認はまだ**
