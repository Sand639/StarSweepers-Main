## この機能は何か

ロビーから試合のマップへ移るときに、**画面をいったん覆ってから切り替え、マップが読み込まれたら画面を開く**演出。
今までは、ロビーの画面からいきなりマップに切り替わっていた。

演出の種類は、いまは**仮で2つ**。インスペクターのプルダウンで選ぶ。

| 種類 | 見え方 |
| --- | --- |
| フェード | 画面全体がだんだん暗くなり、マップでだんだん明るくなる |
| ワイプ | 左から黒い幕が伸びて画面を覆い、マップでは同じ向きのまま右へ抜けていく |

オンラインでは、**ホストが試合を始めると、つないでいる全員の画面で同じ演出が出る。**

---

## 遊ぶ人から見た動き

| 操作 | 結果 |
| --- | --- |
| ロビーで「ゲームを始める」を押す／全員がチームエリアに入ってカウントダウンが終わる | 画面が約0.5秒で覆われ、そのあいだにマップへ移る。マップが読み込まれたら、少し待って約0.5秒で開く |
| 演出の途中 | 画面のボタンは押せない（覆っている画面がクリックを受け止める） |

**シーンには置いていない。** ゲームが始まると自動で1つ作られ、シーンをまたいで残る（画面のポインターと同じ作り）。
既存のシーン（ロビー・マップ）は変えていない。

### 検証シーンでの試し方

1. `Assets/Scenes/Test/SceneTransitionTest.unity` を開いて再生する
2. **Space**（コントローラーは **A**）を押すと、演出を出してこのシーンを読み直す。読み直すたびに背景の色が変わる
3. 種類を変えるときは、再生する前に `Assets/Resources/SceneTransition` を選んでプルダウンを変える。
   再生中に変えるなら、Hierarchy の **DontDestroyOnLoad** の中にある `SceneTransition` を選んで変える（再生を止めると元に戻る）

検証シーンを作り直すときは `Tools > StarSweepers > トランジション > 検証シーンを作り直す`。

## 設定できる値（インスペクターの項目）

`Assets/Resources/SceneTransition.prefab` を選ぶと出る。

| 項目名 | 意味 | 実装したときの初期値（目安。調整で変わる） |
| --- | --- | --- |
| Transition Type | 演出の種類（プルダウン） | フェード |
| Cover Seconds | 画面を覆いきるまでの秒数 | 0.5 |
| Hold Seconds | 次のシーンが読み込まれてから、覆ったまま待つ秒数（読み込んだ直後のカクつきを隠す） | 0.2 |
| Reveal Seconds | 画面が開ききるまでの秒数 | 0.5 |
| Max Wait Seconds | 次のシーンが読み込まれないとき、覆ったまま待つ最長の秒数。過ぎたら開く（真っ暗のまま止まらないように） | 15 |
| Color | 画面を覆う色 | 黒 |

## 仕組み（分かる人向け）

1. ホストが試合を始めると（`SpaceJunkSession.ServerStartMatch`）、`SceneTransition.PlayForEveryone(LoadNextMap)` を呼ぶ
2. ホストは自分の画面で覆い始め、同時に参加者全員へ「この種類で覆って」と通信で送る（名前付きのメッセージ。ネットワーク用のプレハブ一覧に入れなくてよい）
3. ホストの画面を覆いきったら `LoadNextMap` が呼ばれ、全員のシーンがマップへ切り替わる
4. それぞれの画面で、マップが読み込まれたら開く

**種類を増やすときは、`SceneTransitionEffect.cs` の一番上の手順どおりに3か所を足す**（新しいファイル1つと2行）。
詳しい流れと、ほかの場面（ラウンドの切り替え・ロビーへ戻る）で使うときの呼び方は `スクリプトの説明/Common/UI/SceneTransition.md`。

プレハブにはしてある（`Resources/SceneTransition.prefab`）が、**シーンに置く必要は無い**。置いても2つ目は自動で消える。

## できていないこと・既知の問題

- **人が遊んでの確認はまだ。** 画面なしの Unity で、検証シーン（フェード・ワイプ）と、タイトル → ホスト → ロビー → 試合開始（ボット1人・STAGE_Simple）を自動で動かし、覆う → マップへ移る → 開く の順に進むこと、エラーが出ないことを確かめた
- **参加者の画面に演出が出るかは、まだ確かめていない**（2台のPC、または検証用のビルドを2つ起動して確かめる）。`リスクリスト.md` に登録した
- 使っているのは**ロビー → 試合の1ラウンド目だけ**。ラウンドの切り替え・試合が終わってロビーへ戻るとき・タイトルとロビーの行き来には、まだ付けていない（付けるのは呼ぶ所に1行足すだけ。`スクリプトの説明/Common/UI/SceneTransition.md`）
- 演出の見た目は仮（黒一色）。デザインが決まったら種類を足すか、今の2つを作り直す
