## この機能は何か

**ステージのまわりを囲む、見えない壁。** プレイヤーや物資が、ステージの外へ落ちないようにする。
壁に物が当たると、**当たった所から、黄緑 → 水色 → 黒のグラデーションの輪が、波紋のように何重かに広がって消える。**

- 壁は見えない。当たったときだけ波紋が見える
- 囲む範囲は、**再生を始めたときに、そのシーンの床の当たり判定を測って自動で決める**（ステージごとに大きさを入れなくてよい）
- 囲むのは、床全体の**外まわりの四角**。ステージの内側にある穴やすき間（電車マップの橋の横、ガラスの割れた所、浮島の間など）からは、今までどおり落ちる

## 遊ぶ人から見た動き

| 起きること | 結果 |
| --- | --- |
| ステージの端へ歩いていく | 見えない壁で止まる。当たった所に波紋が出る |
| 列車・爆弾で飛ばされる | ステージの外までは飛ばず、壁に当たって止まる（波紋が出る）。内側の穴の上なら、そこから落ちる |
| 物資を投げて端に当たる | 壁で跳ね返る。波紋が出る |
| 壁に触れたまま動く | 波紋は触れ始めたときだけ出る（離れてまた当たると出る。同じ物は 0.3 秒あけてから） |
| ラウンドの始まりの演出（ゴールエリアがプレイヤーを乗せて奥から飛んでくる） | **波紋は出ない**（飛んでくるときに壁を通り抜けるが、当たりとは数えない） |

- 壁の高さは、いちばん高い床から 12m（投げた物が越えないくらい）。いちばん低い床の下にも 4m 伸びている
- 波紋は、**どのPCでも同じように出る**（物の位置で調べているため。ほかの人のプレイヤーが当たったときも見える）

## 試し方

1. `Assets/Scenes/Test/StageBarrierTest.unity` を開いて再生する
2. 真ん中から玉が 0.7 秒ごとに投げられ、まわりの壁に当たるたびに波紋が出る
3. 試合では、`MainLoop/TitleScene.unity` から始めて、ロビーや好きなステージの端へ行く

検証シーンは、メニュー **`Tools > StarSweepers > ステージを囲むバリアの検証シーンを作る`** で作り直せる。

## 設定できる値（StageBarrier のインスペクター）

ステージごとに変えたいときは、そのステージの `SpaceJunkRound` の子の `StageBarrier` を選んで変える（プレハブの値の上書きになる）。全部のステージで変えたいときは、`StageBarrier.prefab` を変える。

| 項目名 | 意味 | 実装したときの初期値（目安。調整で変わる） |
| --- | --- | --- |
| Auto Fit | ON：床を測って自動で囲む。OFF：下の Center と Size で囲む | ON |
| Margin | 床のふちから壁までのすき間（m） | 0.3 |
| Floor Height Range | 床とみなす当たり判定の上面の高さの範囲（m）。高い所の飾りや、ずっと下の物を測らないため | -4〜4 |
| Center／Size | Auto Fit が OFF のときに囲む四角の真ん中と大きさ（X＝東西、Y＝南北） | (0,0,0)／30×30 |
| Height | 床から上の壁の高さ（m） | 12 |
| Depth Below | 床より下へ伸ばす長さ（m） | 4 |
| Thickness | 壁の厚み（m） | 1 |
| Ripple Material | 波紋の見た目（`BarrierRipple.mat`） | ― |
| Ripple Seconds | 波紋が広がりきって消えるまでの秒数 | 0.9 |
| Ripple Radius | 広がりきったときの半径（m） | 2.5 |
| Ripple Cooldown | 同じ物が続けて当たったとき、次の波紋までの秒数 | 0.3 |
| Touch Distance | 壁からこの距離まで近づいたら「当たった」とみなす（m） | 0.15 |

波紋のマテリアル（`BarrierRipple.mat`）で変えられる値：

| 項目名 | 意味 | 初期値（目安） |
| --- | --- | --- |
| Color Front／Middle／Back | 輪の先頭（黄緑）・まん中（水色）・うしろ（黒）の色 | 黄緑・水色・黒 |
| Band Width | 輪の太さ（半径に対する割合） | 0.22 |
| Rings | 波の数（1〜4） | 3 |
| Ring Gap | 波と波の間隔（半径に対する割合） | 0.26 |
| Middle At | 輪の中で水色になる位置（0＝先頭、1＝うしろ） | 0.4 |
| Intensity | 濃さ | 1 |

## 仕組み（分かる人向け）

- **囲む範囲**：`Start` で、同じシーンの当たり判定のうち「動かない（Rigidbody が無いか Kinematic）・すり抜けない・物資やプレイヤーでない・横が 200m 未満・上面が Floor Height Range の中」の物を全部囲む四角を測る。その外に、厚み 1m の箱の当たり判定（`BoxCollider`）を4枚、子として作る（見た目は無い）
- **当たりの調べ方**：毎フレーム、壁を Touch Distance だけ広げた箱で `Physics.OverlapBox` し、触れた物（物資は Rigidbody、自分のプレイヤーは CharacterController）を数える。ほかの人のプレイヤーは当たり判定が切れているので、`FishingNetPlayer.All` の位置と壁の距離で調べる。**触れ始めたときだけ**波紋を出す
  - 物理の当たりの知らせ（`OnCollisionEnter`）を使わないのは、参加者のPCでは物資が物理で動いていない（位置だけ配られる）ことと、CharacterController では知らせが来ないため。位置で調べるので、通信を足さずに全員のPCで同じように出る
  - **始まりの演出中（`SpaceJunkRound.IsIntro`）は、触れたことだけ控えて波紋を出さない**（演出ではプレイヤーが壁を通り抜けるため）
- くわしい流れと気をつけることは `スクリプトの説明/Game/Gimmick/StageBarrier.md`
- **波紋の描き方**：壁の内側の面に、1m 四方の板を `Graphics.RenderMesh` で描く（シーンに物を作らない）。進み具合（0〜1）は `MaterialPropertyBlock` の `_Progress` で渡す。シーンに Renderer が増えないので、全体を映すカメラ（`SpaceJunkWholeStageCamera`）が測るステージの大きさにも影響しない
- シェーダー（`BarrierRipple.shader`）は板の真ん中からの距離で輪を計算する。先頭の半径は「はじめ速く、だんだんゆっくり」。輪の中は、先頭からうしろへ 黄緑 → 水色 → 黒

## できていないこと・気をつけること

- **見た目は試作**。色・太さ・波の数・広がる速さは、マテリアルとプレハブで調整できる
- **内側の穴は囲まない**（外まわりの四角だけ）。電車マップの橋の横・ガラスの割れた所・浮島の間などからは、今までどおり落ちる
- **ステージの外から物が入ってくる仕掛け**があるステージでは、その物も壁で止まる。測った範囲には外のベルトやスポナーの当たり判定も入るので、STAGE_Conveyor1 では外のスポナーも囲みの中に入っている（遊んで確かめる）
- **プレイヤーの光線（フック）も見えない壁に当たる**ことがある（壁は普通の当たり判定なので）。端の外の物を狙うことはふつう無いが、気になったら、壁を光線が当たらないレイヤーに分ける
- 動く床（浮島の引っ張れる床・回転する床・上下する床）は、**再生を始めたときの位置**で測る。動いた先が囲みの外に出るステージでは、Auto Fit を OFF にして Size を入れる
- 囲む範囲は四角だけ（丸いステージでも四角で囲む）
- 波紋は壁の内側の面に描くので、床より下の部分は床に隠れたり、手前の壁では床の下にのぞいたりする
- **人が遊んでの確認・オンライン（2台以上）での確認はまだ**
