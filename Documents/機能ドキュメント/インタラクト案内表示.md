## この機能は何か

プレイヤーが使える端末やボタンに近づくと、設定に応じて対象の色を変えたり、頭上に操作ボタンの画像を表示したりする機能。画像はプレイヤーが離れると消える。

## 遊ぶ人から見た動き

| 操作 | 結果 |
| --- | --- |
| 対象に近づく | 設定に応じて色が変わる、または頭上にボタン画像が出る |
| 対象から離れる | 色が元に戻り、画像が消える |

## 関係するファイル・シーン

| 種類 | パス |

## 設定できる値（インスペクターの項目）

3つの対象スクリプトにある「Interact Visual」を開いて設定する。

| 項目名 | 意味 | 実装したときの初期値（目安） |
| --- | --- | --- |
| Mode | ColorOnly（色のみ）、PromptOnly（画像のみ）、Both（両方）、None（なし）から選ぶ | Both |
| Prompt Sprite | 頭上に表示する画像 | 未設定 |
| Prompt Offset | 対象から画像を置く位置 | (0, 2, 0) |
| Prompt Size | 画像の大きさ | 0.75 |

画像には `Assets/Art/Sprites/test_interact.png` などのSpriteを指定する。Spriteとして読み込めない場合は画像の Import Settings を Sprite (2D and UI) にする。

## 仕組み（分かる人向け）

対象の近くにいるかを各スクリプトが判定し、共通処理へ結果を渡す。共通処理はSpriteRendererを実行中に作り、カメラへ向ける。ロビー設定端末ではホストが近くにいる場合だけ結果を渡す。リスポーンボタンと名前変更端末は、このPCで操作するプレイヤーの接近を使う。色は共有素材を書き換えず、対象専用の `material` インスタンスに反映する。

## できていないこと・既知の問題

- Unityでの再生確認はまだ行っていない。Spriteの見え方や高さは各オブジェクトのインスペクターで調整する。
- 既存シーンの設定は変更していないため、画像を出す対象では各コンポーネントの Prompt Sprite と Mode を設定する。
