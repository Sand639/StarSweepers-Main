## この機能は何か

いつもの引き寄せ（プレイヤー挙動「3 引っ張る・4 投げる」のパターン A）に、2つの動きを足した。

1. **手前まで来ている物資を押すと、両手で持って、向いている方向へ投げる。**
   投げる強さは、クリティカルプルほどではない「ふつうの引っ張り」くらい。「手前」は、投げるアニメーションをしても違和感のない距離。
   アニメーションはまだ無いが、両手で持って投げる形になる予定（小野田さんの指定）。
2. **押さずに手前まで来たら、ふつうの引っ張りの強さで、そのまま後ろへ引っ張り切る。**
   前は「前へはじく」だった。

---

## 遊ぶ人から見た動き

| 操作 | 結果 |
| --- | --- |
| 物資が遠いうちに押す | 今までどおり、頭を越えて後ろへ投げる（受付中ならクリティカル） |
| 物資が手前（Near Throw Distance。2.4m）より近いときに押す | 物資が胸の前（両手の位置）へ来て、少し溜めてから、**向いている方向へ投げる**（7m 先に落ちる） |
| 押さずに手前（Stop Distance）まで来る | **後ろへ引っ張り切る**（途中で押したときと同じ強さ） |
| 両手で持っている間 | 押しても何も起きない。持っている物がほかの人に触れても、スタンさせない |

- クリティカルの受付中は、近くてもクリティカルが先。
- 重い物は今までどおり引きずるだけ。距離で変わる操作（パターンB）は今までどおり（押さずに着いたら前へはじく）。
- ボットは、前へ投げたいとき・爆弾のときに、手前まで来たら押して両手で投げる。後ろへ投げたいときは押さずに引っ張り切る。

## 設定できる値（インスペクターの項目）

`SweeperReel` の「押さずに手前まで来たとき」「手前で押すと両手で持って投げる」の見出し。

| 項目名 | 意味 | 実装したときの初期値（目安。調整で変わる） |
| --- | --- | --- |
| Arrive Throws Back | 押さずに手前まで来たら後ろへ引っ張り切る。OFF で前の「前へはじく」 | ON |
| Near Throw Distance | この距離（m）より近いときに押すと、両手で持って投げる。0 でしない | 2.4 |
| Carry Forward / Carry Height | 両手で持つ位置（体の前へ m／足元から m） | 0.75 / 0.8 |
| Carry In Seconds | 押してから両手の位置に来るまでの秒数 | 0.1 |
| Carry Windup | 両手の位置に来てから投げるまでの溜め（秒）。アニメーションが来たら合わせる | 0.25 |
| Carry Throw Distance | 落ちる所（プレイヤーから前へ m）。ふつうの引っ張りの Back Distance くらい | 7 |
| Carry Arc Height | 放物線のいちばん高い所（足元から m） | 2.4 |

## アニメーションを付けるとき

- 持ち始めた瞬間に `SweeperReel.CarryStarted`、投げた瞬間に `CarryThrown` が呼ばれる。両手で持っている間は `IsCarrying` が true。
- 投げるタイミングをアニメーションに合わせたいときは、Carry Windup を大きめにしておき、アニメーションの「投げる瞬間」のイベントから `ThrowCarry()` を呼ぶ（呼んだらその場で投げる）。
- 投げるアニメーションは、ほかの人の画面でも出す必要がある（`SweeperNetSync` の「持っている」の値 `carrying` を見る）。

## できていないこと・既知の問題

- 人が遊んでの確認はまだ。特に「手前」の距離（2.4m）と、溜めの長さ。
- 手前に入ってから着くまでの時間は、遠くでつかんだ物ほど短い（12m 先なら約 0.1 秒）。押しにくければ Near Throw Distance を広げる。
- アニメーションが無いので、物資が胸の前に浮いて見える。
