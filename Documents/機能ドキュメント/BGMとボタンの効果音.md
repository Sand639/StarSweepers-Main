## この機能は何か

ゲームに**音楽（BGM）**と、**タイトル画面のボタンの音（効果音）**を付ける機能。

- タイトルとロビーでは、タイトルの曲が流れる
- ラウンド（試合）が始まると、ラウンドの曲に替わる
- タイトル画面のボタンを押すと「決定」の音、戻る・閉じるでは「キャンセル」の音、マウスを重ねたりコントローラーで選んだりすると小さな「カーソル」の音が鳴る

**シーンにもプレハブにも何も置いていない。** 再生を始めると、音の係（`GameAudio`）が自分で1つ作られる。
音のファイルは共有フォルダ `30_音声素材/Game音声＿決定/` から写した。

## 遊ぶ人から見た動き

| 場面・操作 | 鳴る音 |
| --- | --- |
| タイトル画面 | BGM：Time Travel（タイトルの曲）。くり返し流れる |
| タイトル → ロビー | **同じ曲のまま途切れずに続く** |
| ロビー → ラウンド（マップの読み込み〜始まりの演出〜試合） | タイトルの曲が小さくなって消え、ラウンドの曲（contedefees_0064）が大きくなる |
| ラウンド → 次のラウンド | 途切れずに続く（マップを読み込む間も止めない） |
| 試合が終わってロビーへ／タイトルへ戻る | タイトルの曲に戻る |
| タイトルのボタンを押す（クリック・Enter・コントローラーの決定） | 決定の音（魔王魂 system07） |
| 「戻る」「閉じる」ボタン、Escape・コントローラーの B（戻れるときだけ） | キャンセルの音（魔王魂 system08） |
| ボタンにマウスを重ねる・十字キーで選ぶ | カーソルの音（効果音ラボ「決定ボタンを押す32」）。小さめ |
| 部屋の一覧のカードを押す、設定の ＜ ＞ を押す | 決定の音 |

全体の音量は、今までどおりタイトルの設定・ポーズ画面の「音量」で変わる。

## 設定できる値（インスペクターの項目）

インスペクターの項目は無い（シーンに置いていないため）。**大きさなどは `GameAudio.cs` の上のほうの数字で変える。**

| 項目名 | 意味 | 実装したときの初期値（目安。調整で変わる） |
| --- | --- | --- |
| `BgmVolume` | BGM の大きさ（0〜1） | 0.5 |
| `ClickVolume` | 決定・キャンセルの音の大きさ | 0.8 |
| `HoverVolume` | カーソルの音の大きさ | 0.4 |
| `FadeSeconds` | 曲を替えるとき、前の曲を消す秒数・次の曲を大きくする秒数 | 0.6 |

**決まり（変えると鳴らなくなる）**

- 音のファイルは **`Assets/Resources/Audio/BGM/` と `Assets/Resources/Audio/SE/`** に置き、**名前を変えない**（コードが名前で読んでいる）。
  **曲を差し替えるときは、同じ名前で上書きする**（Unity のエディタ上で、ファイルを入れ替える）。
- 新しい曲・効果音を足すときは、`GameAudio.cs` の `BgmTrack`／`UiSound` に種類を足し、ファイルの場所の定数を足す。

## 仕組み（分かる人向け）

- `GameAudio` は `RuntimeInitializeOnLoadMethod(BeforeSceneLoad)` で再生の始めに1つ作られ、`DontDestroyOnLoad` でシーンをまたいで残る。
- BGM は毎フレーム「いま流すべき曲」を決める。
  - アクティブなシーンが `TitleScene` か `Lobby` … Title
  - `SpaceJunkRound.Current` がある … Round
  - どちらでもない（マップの読み込みの途中・検証シーン） … **いまの曲のまま**（途切れさせないため）
- 曲が替わるときは、いまの曲の音量を 0 まで下げてから、次の曲を 0 から上げる（`Time.unscaledDeltaTime` を使うのでポーズ中も進む）。
- 効果音は別の AudioSource で `PlayOneShot`。カーソルの音は、決定・キャンセルの直後（0.2 秒）とシーンを読み込んだ直後（0.4 秒）は鳴らさない（画面が替わって最初のボタンが自動で選ばれたときに、決定の音と重なるのを防ぐ）。
- 音を聞く係（Audio Listener）がシーンに無いと何も聞こえない。読み込んで3秒たっても無ければ、コンソールに1回だけ注意を出す。
- 音のファイルの `.meta` は Unity を開かずに手で書いた（BGM は「Streaming」、効果音は「Decompress On Load」）。最初に Unity で開いたときに、Unity が書き直すことがある（GUID は変わらない）。

## できていないこと・既知の問題

- **Unity で再生しての確認がまだ。** コンパイルが通ることだけ確かめた。音の大きさのつり合いは、聞いて `GameAudio.cs` の数字で直すこと。
- **ロビーの専用の曲は無い**（タイトルの曲のまま）。共有フォルダの「ゲーム中」にあるもう1曲「宇宙語コミュニケーションッ!!」は、まだ使っていない（2026/11/26・小野田さんの指示で、いまはラウンドに contedefees を流すだけ）。
- ロビーの出発の効果音（`scene/ロビー/SE/`）は、まだつないでいない。落ちる音は 2026/11/26 に `ゲーム中の効果音.md` でつないだ。
- ロビーの画面（`SpaceJunkLobbyScreen`）やポーズ画面のボタンには、まだ音が無い（タイトル画面だけ）。
- 結果の画面・勝利演出の間もラウンドの曲が流れ続ける。専用の曲（リザルトの曲など）が決まったら `BgmTrack` に足す。
- **素材のライセンスで確認が要るものがある**（`使用素材とライセンス.md`・`リスクリスト.md`）。
  特に Time Travel は OpenTracks の曲なので、**2027/1/1 以降に公開するならクレジット表示が要る**。contedefees_0064 は**入手元がまだ分からない**。
