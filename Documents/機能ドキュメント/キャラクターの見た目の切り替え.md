## この機能は何か

キャラクターの**服の色**と**顔の表情**を切り替えるための部品（Hans さん作）。
2026/11/18 から、プレイヤーの体（プレハブ2つ）に付いていて、**チームに合わせて服の赤い部分の色が変わる**。

- **赤チーム** … Hans さんが決めた元の色（赤）のまま
- **青チーム** … 赤い部分が**青**になる（緑・黄チームもそれぞれの色になる）
- **表情** … いつもは **Neutral（ふつうの顔）**で、ときどき**まばたき**する

## 遊ぶ人から見た動き

| 場面 | 結果 |
| --- | --- |
| ロビー・試合でチームが決まる／変わる | 服の赤い部分がチームの色になる（赤チームは元の赤、青チームは青）。オンラインでも、全員の画面で同じ色になる |
| 立っている・歩いている | ふつうの顔（Neutral）。2〜5秒おきにまばたきする |
| （ゲームの出来事で表情を変える） | **まだ無い**。どの場面でどの表情にするかが決まっていない（`質問リスト.md`） |

表情は Null（目を閉じた顔）・Neutral・Yes・No・Annoyed・Huh・Excited の7つ。

## 設定できる値（インスペクターの項目）

### `SweeperPlayer`（プレイヤーのまとめ役）

| 項目名 | 意味 |
| --- | --- |
| Red Team Uses Model Color | ON（はじめから）：赤チームは Hans さんの元の色のまま。OFF：赤チームも下の表の色 |
| Suit Colors | チームごとの服の色（0 = 青、1 = 赤、2 = 緑、3 = 黄）。青は、元の赤 (0.808, 0.333, 0.192) の赤と青を入れ替えた色 (0.192, 0.333, 0.808) |

### `CharacterColorController`（服の色。`Model` に付いている）

| 項目名 | 意味 |
| --- | --- |
| Character Renderer | 色を変えるモデル（`SK_Character` の体） |
| Body Material Index | 服のマテリアル `M_Character` の番号 |
| Color Property | 色の項目名（`_SuitColor`） |
| Color Mode・Custom Color | 元の色か、指定した色か。**試合中は `SweeperPlayer` が上書きする** |

### `FaceExpressionController`（表情。`Model` に付いている）

| 項目名 | 意味 |
| --- | --- |
| Character Renderer・Face Material Index | 顔のマテリアル `M_Face` を使うモデルと、その番号 |
| Expression Textures | 7つの表情の画像（色と光る部分の2枚ずつ）。`Art/Textures/Expression/` の画像を入れてある |
| Current Expression | 表示する表情（はじめは Neutral） |
| Enable Blinking・まばたき間隔と時間 | 自動まばたきの有効・無効とタイミング（Neutral・Annoyed・Huh のときだけまばたきする） |

## 仕組み（分かる人向け）

- どちらも `MaterialPropertyBlock` で、モデルのマテリアル番号ごとに色・画像を上書きする（マテリアルそのものは書き換えない）。
- 服の色：`SweeperPlayer.SetProfile` → `Apply` → `ApplySuitColor` が、子の `CharacterColorController` に `ResetToDefault()`（赤チーム）か `SetCustomColor(色)` を呼ぶ。オンラインでは `SweeperNetSync.ApplyProfile` が、ホストの決めたチームが変わるたびに全員の PC で `SetProfile` を呼ぶので、**色そのものは通信で配っていない**。
- 表情：ゲームから変えるときは `FaceExpressionController.SetExpression(表情)` か `SetExpressionByIndex(番号)` を呼ぶ。**いまは誰も呼んでいない**。表情を変えても**通信では配らない**ので、全員に同じ表情を見せたいなら、出来事（スタンなど）が全員に届く所から呼ぶこと。
- スタン中の赤い点滅（`PlayerStun`）はマテリアルの主な色（`_BaseColor`）を変えるので、服の色（`_SuitColor`）とはぶつからない。

## できていないこと・既知の問題

- **ゲームの出来事で表情を変える所はまだ無い**（スタンされたら Annoyed、点を入れたら Excited など）。どの場面でどの表情にするかは企画・デザインの判断なので、`質問リスト.md` に登録した。
- 青・緑・黄の服の色は仮の値。Hans さん（デザイン）に見てもらうこと。
- 人が遊んでの見た目（色の具合・まばたき）の確認はまだ。
- **2026/11/18、2つのスクリプトのファイル名を中のクラス名に合わせた**（`Script_CharacterColor.cs` → `CharacterColorController.cs`、`Script_FacialExpression.cs` → `FaceExpressionController.cs`）。ファイル名とクラス名が違うと Unity はプレハブに付けられないため。**中身は変えておらず**、Unity の機能で名前を変えたので GUID もそのまま。
