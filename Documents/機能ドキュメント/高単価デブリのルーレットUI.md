## この機能は何か

ラウンドイベント「**期間限定高価値デブリ**」（高単価デブリ。`宇宙ごみのラウンドイベント.md`）で、どの種類の物資が高くなったかを、**ルーレット**で見せる。

- イベントが始まると、画面の上の**得点バーと時間の丸の裏から、半円の円盤（ルーレット）が下りてくる**
- 円盤のふちのレールに物資の画像が並んでいて、**レールが回る**。だんだん遅くなり、**ちょうど2秒で、選ばれた種類の物資が真下に止まる**（止まった瞬間、その物資がぽんと大きくなる）
- イベントが続いている間は、止まったまま出ている。イベントが終わると、得点バーの裏へしまわれる

設計図：本人の参考画像（赤と青の帯の真ん中に「時間」の丸、その下に灰色の半円と、ふちに物資の丸が3つ見える）。

## 遊ぶ人から見た動き

| いつ | どうなるか |
| --- | --- |
| イベントの前 | 何も出ない |
| 高単価デブリが始まった瞬間 | 時間の丸の裏から、灰色の半円が 0.25 秒で下りてくる。物資の画像が左から右へ流れる |
| 始まって 2秒 | だんだん遅くなり、**ちょうど2秒**で選ばれた種類の物資が真下で止まって、ぽんと大きくなる |
| イベントが続いている間 | 止まったまま出ている（真下の物資が、高単価の種類） |
| イベントが終わった・ラウンドが終わった | 0.25 秒で得点バーの裏へしまわれる |

- **途中から見え始めた人**（始まってから2秒以上たってから画面に出た人）には、回らずに止まった状態で出る。
- ルーレットは**イベントが始まった時刻（全員で同じ時計）から数える**ので、どのPCでも同じころに止まる。流れる途中の物資は見た目だけなので、PCごとに違ってよい。止まる物資（高単価の種類）は全員同じ。

## 画像の差し替え方（本素材が来たら）

いまは**ツールで描いた仮の画像**が入っている。

| 画像 | ファイル（`StarSweepers/Assets/Art/Sprites/`） | 仮の見た目 |
| --- | --- | --- |
| 物資1〜5 | `DebrisSetItem1.png`〜`DebrisSetItem5.png` | **デブリセットのUIと同じ画像**（素材の色の丸にサイコロの目） |
| ルーレットのフレーム | `HighValueRouletteFrame.png` | 薄い灰色の円盤に、濃い灰色の縁と、物資が乗るレールの線 |

> **物資の画像は、デブリセットのUIと同じファイルを使っている。** `DebrisSetItem1.png` などを本素材で上書きすれば、デブリセットのUIとこのルーレットの**両方が一度に**差し替わる（手順は `デブリセットのUI.md`）。

### フレームを同じ名前で上書きする

1. 本素材の PNG を `HighValueRouletteFrame.png` という名前にする
2. エクスプローラーで `StarSweepers/Assets/Art/Sprites/` に**上書きで**入れる（`.meta` ファイルは消さない・触らない）
3. Unity に戻ると読み込み直される。**ほかに何もしなくてよい**

- **正方形の、円盤まるごとの絵**にする（上半分は得点バーの上で切り取られて見えない。見えるのは下の半分くらい）
- 背景は透明に
- 仮の画像のレールの線は、半径の 77％（`Rail Radius` 200 ÷ 円盤の半径 260）の所に引いてある。本素材にレールの溝を描くときは、この位置に合わせるか、絵に合わせて `Rail Radius` を変える

### 別の名前の画像を使うとき

プレハブ `StarSweepers/Assets/Resources/HighValueRouletteUI.prefab` を開き、一番上の `HighValueRouletteUI` の「**素材**」の欄に画像を入れる。

| 欄 | 入れる物 |
| --- | --- |
| Item Sprites | 物資の画像。上から 物資1〜物資5 |
| Frame Sprite | ルーレットのフレームの画像 |

画像は、インスペクターで **Texture Type を `Sprite (2D and UI)`** にしておく。

- プレハブ・検証シーンは、メニュー `Tools > StarSweepers > 高単価デブリのルーレットUIの検証シーンを作る` で**作り直せる**（`高単価デブリのルーレットUIのプレハブを更新` はプレハブだけ）。**手で直した部分は消える**ので、見た目を手で整えるようになったら、このメニューは使わないこと。

### 検証シーンの使い方

`Assets/Scenes/Test/HighValueRouletteUITest.unity` を開いて再生する。

- 再生するとすぐ、得点バーの時間の丸の下からルーレットが出て、2秒で止まる
- 5秒たつとしまわれ、1.5秒後にまた別の種類で始まる（くり返す）
- 再生中に `HighValueRouletteUI` の右クリックメニュー（歯車）の「**テスト：もう一度回す**」で、いつでも最初から見られる

## 設定できる値（インスペクターの項目）

`Assets/Resources/HighValueRouletteUI.prefab` の `HighValueRouletteUI`。

| 項目名 | 意味 | 実装したときの初期値（目安。調整で変わる） |
| --- | --- | --- |
| Item Sprites / Frame Sprite | 画像（上の「画像の差し替え方」） | 仮の画像 |
| **Spin Seconds** | **イベントが始まってから、物資が決まる（真下で止まる）までの秒数** | 2 |
| Spin Start Speed | 回り始めの速さ（1秒に何個の物資が真下を通るか）。決まる時刻に向けて、だんだん遅くなる | 14 |
| Rail Radius | フレームの中心から物資の中心までの距離（レールの半径） | 200 |
| Item Angle | レールの上の、となりの物資との角度（度） | 45 |
| Slide Seconds | 出てくるとき・しまわれるときに動く秒数 | 0.25 |
| Test Mode / Test Event Seconds | ラウンドが無くてもイベントをくり返す。**本番のプレハブではオフ**（検証シーンだけオン） | オフ / 5 |

円盤の大きさ・置き場所は、プレハブの `Clip`（切り抜き）と `Wheel`（円盤）で変えられる。初期値（1920×1080 の画面での大きさ）：

- `Clip` … 画面の上から 48（得点バーの上の端）より下だけを見せる。幅 800・高さ 420
- `Wheel` … 半径 260。中心は画面の上の端より 40 上（見えるのは、得点バーの下から画面の上から 220 まで）
- 物資の画像 … 64×64

**決まり**：

- `Item0`〜`Item6`（レールの物資の画像）は、スクリプトの Rail Items の欄に割り当ててある。**消したり減らしたりしない**（真下と左右3個ずつを回して使うため）
- 物資の画像の欄（Item Sprites）は **5つ**（物資の種類の数）

## 仕組み（分かる人向け）

> スクリプトの詳しい説明は `スクリプトの説明/Game/UI/HighValueRouletteUI.md`。

- **表示するだけ。** 高単価の種類は、ホストが決めて全員へ配っている `SpaceJunkRound` の値（`TryGetHighValueKind`）を毎フレーム読む。何も送らない
- ゲームの開始時に `Resources/HighValueRouletteUI.prefab` から1つ作り、シーンをまたいで残す（デブリセットのUIと同じやり方）
- 並び順は 9。得点バー（10）のすぐ奥なので、**円盤の上の部分は得点バーと時間の丸の裏に隠れる**
- 回り方は、デブリセットのスロットと同じ `1 − (1 − t)²`（`DebrisSetUI.ReelPosition` を使っている）。決まる時刻に、選ばれた物資がちょうど真下（角度 0）に来る

## できていないこと・既知の問題

- **画像は仮。** 本素材が来たら上の手順で差し替える
- 今の仮の画面（`SpaceJunkMatchUI`）は、ラウンド数の見出しとイベントの一行（「イベント：〜　残り ○ 秒　紫（回路基板）のデブリが +2点」）を時間の丸のすぐ下の真ん中に出していて、ルーレットと重なっていた。**ルーレットが出ている間は、この2行をルーレットの下へずらす**ようにした（左のチームの行はそのまま）。また、始まった合図（画面の上から3割の大きな文字）の「紫（回路基板）のデブリが +2点」は、**ルーレットが止まってから（2秒後から）出す**ようにした（回っている間に答えが見えないように）。仮の画面は画面なしの Unity では写らないので、**文字の位置は画面では確かめていない**（試合で、ルーレットの下の端の高さと「回っているか」の値が正しく出ることは確認）
- 得点バーが置かれていないステージでは、仮の画面が残り時間の大きな数字を画面の上の真ん中に出すので、ルーレットの上の端と重なる
- 得点バーが置かれていないステージ（`STAGE_Conveyor2`・`STAGE_GlassChecker`・`STAGE_GlassChecker2`・`STAGE_GlassFull`・`STAGE_GlassLattice`）では、円盤の上の端を隠す物が無いので、画面の上から 48 の所でまっすぐ切れた半円に見える
- **別のPC（参加者）の画面では、まだ確かめていない。** 値は全員に配られている物を読むだけなので同じになるはず
- 出る物資が1種類しかないマップでは、同じ物資が並んで回る（流れて見えにくい）
