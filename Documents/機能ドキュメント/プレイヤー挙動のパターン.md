## この機能は何か

プレイヤーが物資をつかんで投げるまでの操作を **4つの段階** に分けて、段階ごとに「どのパターンで動くか」を
**ロビーコンソールでホストが選べる**ようにしたもの。選んだパターンは**部屋にいる全員（ボットも）**に効く。

| 段階 | 中身 |
| --- | --- |
| **1 狙う** | 光線を出す向き・長さを決める |
| **2 発射** | 光線を出す |
| **3 引っ張る** | つかんだ物資を引き寄せる（しならせる部分） |
| **4 投げる** | もう一度押して投げる／押さずにはじき飛ぶ |

### いまあるパターン

| 段階 | A | B | C | D |
| --- | --- | --- | --- | --- |
| 1 狙う・2 発射 | **鞭**：押した瞬間に狙った向きへ光線が出て、体を振るとしなる。どこかが物資に触れたらつかむ（`鞭のように曲がる光線.md`） | **溜め**：押して長さを決め（矢印の帯）、離すとまっすぐ伸びる（前からの撃ち方） | **曲げ撃ち**：体はあまり回らず、飛んでいく光線の先が**すぐ**狙いの向きへ進路を変える（下の「曲げ撃ち（C・D）」） | **曲げ撃ち（遅れ）**：C と同じ作りで、先の進路が**少し遅れて**狙いの向きへ変わる |
| 3 引っ張る・4 投げる | **しなって引き寄せ、押せば後ろへ投げる／押さなければ前へはじき飛ぶ**（いまの引き寄せ。`プレイヤーの本実装.md`） | （まだ無い） | （まだ無い） | （まだ無い） |

- **A は「いまの作り」**（2026/11/18・小野田さんの指定）。狙う・発射の A は鞭、引っ張る・投げるの A はいまの引き寄せ。
- B（溜め）は、前からあった撃ち方をそのままパターン B にしたもの（前はポーズ画面の「撃ち方」で選んでいた）。
- C・D（曲げ撃ち）は 2026/11/18 に小野田さんの絵をもとに足した。**C と D は作りが同じで、インスペクターの値をパターンごとに別に持つ**（「中身が同じでも、パラメータを残したいのでパターンにする」という指定）。初期値の違いは「先がすぐ向く（C）／遅れて付いていく（D）」だけ。

### 曲げ撃ち（C・D）

小野田さんの絵（1：プレイヤーと物資 → 2：正面へ撃つ → 3：体は少しだけ回り、光線は上へ出てから右へ曲がって物資へ）のとおり。

| 操作 | 結果 |
| --- | --- |
| 押す | 体が狙った向きを向き、光線の先がその向きへ**飛び出す**（初期値 15m/秒） |
| 押したまま、狙い（右スティック／マウス）を動かす | **体は撃った向きから 30° までしか回らない。** 光線の先は狙いの向きへ進路を変えて進む（C はすぐ、D は少し遅れて）。光線は手元から体の向きにまっすぐ出て、曲がって先へつながる |
| 光線のどこかが物資に触れる | つかむ。そこからは引っ張る・投げるのパターン（いまは A）と同じ |
| 先が飛んだ道のりが最長（12m）になる | 先はそこで止まる（光線は出たまま。体を少し回すと、まだ当たることはある） |
| 離す／1 秒たつ | 光線が戻る |
| 先が壁に当たる | 先はそこで止まる。進路を変えれば、また進める |

- 狙いを動かさなければ、ふつうのまっすぐな光線と同じ（まっすぐの所から外れた物資には届かない）。
- ボットは、素材を指し続けるので、先が素材の方へ曲がっていく。

### 固定の組

- **「狙う」と「発射」は、同じパターンで固定。** 鞭は狙うと発射が1つの流れなので、片方を A にするともう片方も A になる。溜め（B）も同じ。
- **「引っ張る」と「投げる」も、同じパターンで固定。** いまの引き寄せは、引っ張って投げ飛ばすまでが1つの流れのため。
- 将来、段階ごとに別々に選べるパターン（例：狙うは A のまま、発射だけ C）を足すときは、そのパターンだけ「組にしない」にできる（下の「パターンを足すとき」）。

## 遊ぶ人から見た動き

| 操作 | 結果 |
| --- | --- |
| ロビーで、右側の小窓「**ロビーコンソール**」を見る | 「プレイヤー挙動」の欄に 1〜4 の段階と、いまのパターン（A／B）が出る |
| **ホスト**が段階の「＜」「＞」を押す | その段階のパターンが変わる。**固定の組の相手も一緒に変わる**（例：「1 狙う」を B にすると「2 発射」も B） |
| 参加者（ホスト以外） | 見るだけ（ボタンは押せない） |
| パターンが変わったあと、光線のボタンを押す | **次に押したときから**新しいパターンで動く（撃っている途中では変わらない） |
| 次にホストをしたとき | 前回選んだパターンから始まる（ホストのPCに保存） |

- ロビーコンソールは、ロビーにいる間だけ出る（ゲーム設定の画面を開いている間・タイトル画面の間は隠れる）。つかんで動かせる。
- 選べるパターンが1つしかない段階（いまは 3・4）は、ボタンが押せない（灰色）。
- パターンは**ロビーにいる間しか変えられない**（試合中は変わらない）。
- **ボットも同じパターンで動く**（ボットの頭は鞭・溜めの両方に対応している）。
- 通信なしの検証シーン（`SweeperWhipTest` など）では、このPCに保存されたパターン（最後にホストをしたときの選び方）で動く。

## 設定できる値（インスペクターの項目）

パターンはロビーコンソールで選ぶ。曲げ撃ちの値は、`SweeperShooter` の「曲げ撃ち」の欄に **Steer Snap（＝C）** と **Steer Lag（＝D）** の2組ある（中身の項目は同じ）。

| 項目名 | 意味 | 実装したときの初期値（目安）C／D |
| --- | --- | --- |
| Seconds | 光線を出し続けられる秒数 | 1／1 |
| Head Speed | 光線の先が飛ぶ速さ（m/秒）。遅いほど、伸びきるまで長く曲げられる | 15／15 |
| Hold To Keep | ON：押している間だけ出る。OFF：1回押せば Seconds 秒出る | ON／ON |
| Tip Snaps | ON：先の進路がすぐ狙いへ向く。OFF：ばねで遅れる | **ON／OFF** |
| Tip Stiffness・Tip Damping | 遅れるときの、追いつく速さと止まりやすさ（Tip Snaps が OFF のとき） | 8・0.6／8・0.6 |
| Max Tip Angle | 先の進路が、体の向きから曲がれる最大の角度 | 120／120 |
| Max Body Turn | 光線を出している間に、体が撃った向きから回れる最大の角度。0 で回らない | 30／30 |
| Body Turn Speed | そのときに体が回る速さ（度／秒） | 120／120 |
| Curve Strength | 曲がり方（0 で手元から先までまっすぐ、1 で絵のように角ばって曲がる） | 1／1 |
| Move Scale | 光線を出している間に歩ける速さ。0 で歩けない | 0／0 |

伸びる最長の長さ（Max Reach）と、戻る速さ（Retract Speed）・当たりの太さ（Hit Radius）は、ほかの撃ち方と共通。

**決まり（変えると壊れる）**：`PlayerBehaviorStep`（Aim＝0・Fire＝1・Pull＝2・Throw＝3）と `PlayerBehaviorPattern`（A＝0・B＝1）の数字は、
保存（`StarSweepers.PlayerBehavior.0`〜`3`）と通信に使っているので、途中の番号を変えないこと。足すときは後ろに足す。

## 仕組み（分かる人向け）

- 段階・パターン・固定の組の決まりは `PlayerBehavior`（静的クラス）にまとめてある。
  - `PlayerBehavior.Get(段階)`：部屋（`SpaceJunkSession`）があればホストが配った値、無ければこのPCに保存した値。**動きを分けるスクリプトは、これを見る。**
  - `PlayerBehavior.Assign(値の並び, 段階, パターン)`：固定の組なら、組の相手も同じパターンにする。
  - `PlayerBehavior.Normalize`：読み込んだ値・届いた値を決まりに合わせる（選べないパターンは A、組が食い違っていたら前の段階＝狙う・引っ張るに合わせる）。
- `SpaceJunkSession` に `NetworkVariable<int>` を4つ（`behaviorAim`・`behaviorFire`・`behaviorPull`・`behaviorThrow`）足した。ホストだけが書く。
  **通信の項目が増えたので、2026/11/18 より前に作ったビルドとはつながらない。**
- `SweeperShooter` は、起きたとき（Awake）と、**押した瞬間に「狙う」のパターンが前回から変わっていたら**だけ、撃ち方（Shot Style）を合わせ直す（前はポーズ画面の設定を見ていた所）。インスペクターの `Follow Settings` を OFF にすると、いつも Shot Style のまま。
- ほかの人の画面での光線の形は、前と同じく `SweeperNetSync` が本人の撃ち方を配って描く（変えていない）。曲げ撃ちは、配っている「光線の向き」に**先の進む向き**を入れ、ほかの人の画面ではそれと光線の先・体の向きから同じ曲線を描く。
- **曲げ撃ちの仕組み**：光線の先は「位置」と「進む向き」を持ち、毎フレーム進む向きを狙いへ寄せて（C はすぐ、D はばね）、その向きへ Head Speed で進む。体は撃った向きから Max Body Turn 度までしか回さない（その間は `SweeperMover.TurnLocked` で、歩く部品に体を回させない）。
  光線の形は2次ベジェで、真ん中の目印は「手元から体の向きへ延ばした線」と「先から進んできた向きを逆にたどった線」の交わる所（`SteerControl`）。だから手元からはまっすぐ出て、先へは進んできた向きから入る。当たりも同じ曲線で見る（鞭と同じく 16 点・前のフレームからの動きも見る）。つかんだら、体の向きはふだんの巻き取りに戻す。

### パターンを足すとき

1. `PlayerBehaviorPattern` に `C = 2` などを足す（途中の番号は変えない）
2. `PlayerBehavior.Available` の、その段階の行にパターンを足す
3. `PlayerBehavior.Describe` に、ロビーコンソールに出す短い説明を書く
4. 組にしない（段階ごとに別々に選べる）パターンなら、`PlayerBehavior.IsFixedPair` でそのパターンに false を返す
5. その段階を動かすスクリプトで `PlayerBehavior.Get(段階)` を見て分ける
   （狙う・発射＝`SweeperShooter`、引っ張る＝`SweeperShooter` の巻き取り中のしなり・`SweeperReel` の引き寄せ、投げる＝`SweeperReel` の投げ）
6. ボットが新しいパターンでも動けるか確かめる（`SweeperBot`）

## できていないこと・既知の問題

- **人がロビーで触っての確認はまだ。** 小窓の文字の並び（説明が長いと折り返す）は、見て直す必要があるかもしれない。
- 引っ張る・投げるは A しか無いので、いまは選べない（ボタンは灰色）。B を作るときは上の「パターンを足すとき」。
- **曲げ撃ち：光線の先が伸びきる（12m）と、先はそこで止まり、それ以上は曲げられない。** 先が飛んできた道（くねくね）はそのまま残らず、いつも「手元からまっすぐ → 1回曲がって先へ」の形で描く（狙いを何度も左右に振っても、曲がりは1つ）。
- 曲げ撃ち：曲線の途中が壁に当たったときは、先をその場所まで戻すので、形が急に変わることがある。
- 曲げ撃ち：通信なしの検証シーンで試すときは、このPCに保存されたパターン（最後にホストをしたときの選び方）で動く。C／D を試すには、一度ホストしてロビーコンソールで C／D にするか、インスペクターの `Follow Settings` を OFF にして `Shot Style` を SteerSnap／SteerLag にする。
- ポーズ画面の「撃ち方」をやめたので、**遊ぶ人が自分だけ撃ち方を変えることはできなくなった**（ホストが全員ぶん決める）。前に「溜め」を選んで保存していた人も、ロビーのパターンで動く。
- ロビーの左上の案内（全員に見える）には、パターンを出していない。参加者はロビーコンソールで見る。
