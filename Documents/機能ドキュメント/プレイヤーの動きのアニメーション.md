## この機能は何か

プレイヤーの体が、している動きに合わせてアニメーションする。体（`SK_Character.fbx`）を、デザイナーさんがリグ（骨組み）を直した版に差し替え、同じリグで作られたアニメーション10個を付けた。割り当ては小野田さんの指定。

---

## 遊ぶ人から見た動き

上にあるものほど優先。2つが同時に起きたら、上のほうが流れる。

| いまの様子 | 流れるアニメーション（素材） |
| --- | --- |
| ガラスなどの足場から落ちている | **落ちる瞬間**（`AN_Drop`）→ **落ちている間**（`AN_DropLoot`。くり返し） |
| スタンしている | **倒れる**（`AN_Fall`。倒れたポーズのまま止まる）。**スタンが解けたら起き上がる**（`AN_Rise`。最後まで流す） |
| 手前の物資を押して、両手で持っている | **両手で頭の上へ持ち上げて、前へ振り下ろして投げる**（`AN_Throw`）。持った物も手と一緒に上がる。投げたあとも振り切るまで流れる |
| 物資をつかんで巻き取っている | **引っ張る**（`AN_Pull`。くり返し） |
| 光線を撃った瞬間 | **撃つ**（`AN_Shoot`。終わったら狙い歩きへ戻る） |
| 押して狙っている（溜め中） | **狙いながら歩く**（`AN_AimWalk`）。歩く速さに合わせて足が動き、**止まっていると止まったポーズ** |
| それ以外 | 止まっていると **Idle**（`AN_Idle`）、歩くと **歩き**（`AN_Move`） |

- 両手で投げる「溜め」の長さを、アニメーションの振り下ろす瞬間に合わせた（**押してから約 0.73 秒で物が飛ぶ**。前は約 0.35 秒）。
- ほかの人の体（オンライン）も同じように切り替わる（落ちるは届いた位置、スタンは配られたスタン、両手で持つは「持っている」の知らせから決める）。

## 設定できる値（インスペクターの項目）

**体のプレハブ `SweeperPlayer` の `SweeperAnimation`**

| 項目名 | 意味 | 実装したときの初期値（目安。調整で変わる） |
| --- | --- | --- |
| Shoot / Aim / Idle / Pull / Throw / Drop / Stun / Rise State | Animator の中の状態の名前。**Animator の状態の名前と同じでないと流れない**（決まり） | Shoot / AimWalk / Idle / Pull / Throw / Drop / Fall / Rise |
| Speed Parameter / Aim Speed Parameter | 歩く速さ・狙い歩きの再生の速さを渡すパラメーターの名前（決まり：Animator と同じ名前） | Speed / AimSpeed |
| Cross Fade | 切り替えのつなぎの秒数 | 0.05 |
| Fall Depth / Fall Speed / Land Seconds | 「足場から落ちている」の判定（最後に立っていた高さより何 m 下・下向きの速さ m/秒・着いたとみなす秒数） | 1 / 3 / 0.15 |
| Left / Right Hand Bone | 両手の骨。名前か、途中の骨からのたどり方（決まり：体の骨と合っていること）。**新しいリグは右手も `JNT_Hand_L` という名前**なので、右手は `JNT_Shoulder_L2/JNT_Arm_L/JNT_Hand_L` と肩から書く | `JNT_Shoulder_L/JNT_Arm_L/JNT_Hand_L` / `JNT_Shoulder_L2/JNT_Arm_L/JNT_Hand_L` |

**同じプレハブの `SweeperReel`（両手で投げる）**

| 項目名 | 意味 | 実装したときの初期値（目安） |
| --- | --- | --- |
| Carry Windup | 両手の位置に来てから投げるまでの秒数。**Carry In Seconds と足して、投げるアニメーションの振り下ろす瞬間（約 0.73 秒）に合わせる** | 0.63（Carry In Seconds 0.1 と合わせて 0.73） |
| Carry With Hands / Carry Hands Forward | 投げるアニメーションの間、持った物を両手の真ん中（から前へ何 m）に合わせる | ON / 0.3 |

- 投げる動きを速く・遅くしたいときは、Animator の Throw の Speed を変えて、**Carry Windup も同じ割合で変える**（ずれると、振り下ろす前・後に物が飛ぶ）。

## 仕組み（分かる人向け）

### 素材と Animator

- 体とアニメーション10個は、どれも同じリグ（いちばん上が `GRP_ExportScale_DO_NOT_TOUCH/CTRL_Global/JNT_Tool`、右腕が `JNT_Shoulder_L2/JNT_Arm_L/JNT_Hand_L`）。全部の骨が体に当たることを、画面なしの Unity で確かめた（当たらないのは Throw・DropLoot に入っている銃 `SM_Gun_01` だけ。体に銃は無い）。
- **いちばん上の `GRP_ExportScale_DO_NOT_TOUCH` の大きさは 3.3**（体とアニメーションで同じでないといけない）。2026/11/26 に一度、Idle・歩きが 1.0 で書き出されて体が約 1/3 に縮んだので、書き出し直してもらった。新しいアニメーションが来たら、まず大きさが変わらないかを見る。
- `AC_SweeperPlayer` は道具 `SweeperAnimationSetup` が作る。状態をいったん全部消して、10個を並べ直す（Idle ⇔ Walk は Speed 0.1 で切り替え、AimWalk は AimSpeed で再生の速さ、Drop → DropLoot は Drop が終わったら）。
  FBX の Loop Time は OFF のまま（デザイナーさんの素材の取り込みの設定は変えない）なので、**くり返すもの（Idle・Walk・AimWalk・Pull・DropLoot）は、終わったら頭へ戻す移り変わり**で作っている。どれも最初と最後のコマが同じ形なので、つなぎ目は出ない。
- **デザイナーさんが FBX を書き出し直したら、`Assets/Art/Animation/` に上書きして、メニューを1回押す。** 新しい動きを足すときは、道具の `States` の表に1行足す。

### どのアニメーションを流すか（SweeperAnimation）

- 撃つ側（`SweeperShooter`）が、狙う（`PlayAim`）・撃つ（`PlayShoot`）・巻き取り始め（`PlayPull`）・やめる（`PlayIdle`）を呼ぶ。ほかの人の体では、通信で届いた光線の段階が変わったときに同じものを呼ぶ。
- それとは別に毎フレーム、**落ちているか・スタンしているか・両手で持っているか**を調べ、優先の順で1つ選ぶ。変わったときだけ `CrossFade` する。
- 落ちているか：位置の上下の動きだけで決める（ほかの人の体でも同じに働くように）。「最後に立っていた高さより Fall Depth 下」かつ「下向きに Fall Speed より速い」。上下が Land Seconds 止まったら着いた。1フレームで 2m より大きく動いたら瞬間移動とみなす。
- スタン：`PlayerStun.IsStunned`（ほかの人の体でも、配られたスタンの見た目の間は true）。解けたら Rise を流し切る。Fall（2.1 秒）より短いスタンなら、倒れる途中で起き上がりに移る。
- 両手で持っているか：自分で動かしている体は `SweeperReel.IsCarrying`、ほかの人の体は `SweeperNetSync.IsCarrying`。
- 狙い歩き：Animator の `AimSpeed` に「いまの歩く速さ ÷ ふだんの歩く速さ」を渡す。止まっていると 0 で、止まったポーズになる。

### 持った物を両手に合わせる（SweeperReel）

`SweeperAnimation.TryGetHandsCenter` が、Throw を流している間だけ両手の骨の真ん中を返す。`SweeperReel` の両手で持つ位置は、それがあれば「両手の真ん中＋体の前へ Carry Hands Forward」、無ければ「体の前・胸の高さ」。自動テストでは、物が約 0.81m まで手と一緒に上がり、振り下ろす瞬間に飛んだ。

## できていないこと・既知の問題

- **人が遊んでの見た目の確認がまだ**（画面なしの Unity の自動テストと、ポーズの画像でだけ確かめた）。
- **Hans さんのシーンのキャラクターが動かなくなった**：`HansStage01_Ver01`・`STAGE_Train2` に置かれた `SK_Character` は、Animator `AC_Idle`（中身は古いリグの `AN_Character_Idle`）で動いていたので、体を新しいリグにしたら骨が当たらず止まって見える（`HansStage02_Ver01` は Animator 無し）。`AC_Idle` の中身を新しい `AN_Idle` に替えれば直るが、**Hans さんの物なので了承待ち**（`質問リスト.md`）。古いリグの `AN_Character_Idle`・`Move`・`Aimwalk` と `AC_Idle`・`AC_Move`・`AC_AimWalk` は消していない。
- 引っ張る（Pull）は1回引く動きを巻き取りの間くり返すので、約 2.1 秒ごとに引き直して見える。巻き取り中に歩いても足は滑る。
- 落ちる瞬間（Drop）は、物を持っていないときにも流している（デザイナーさんの説明は「特に物を持っている時」）。
- 体が画面に映っていないと Animator が骨を動かさないので、そのとき両手で投げると、持った物は止まった手の位置に合わせて動く。
- ほかの人の体の「落ちている」は届いた位置の上下から決めるので、速く下がる床・運ばれている間に落ちるアニメーションが流れることがある。
- 投げるまでが約 0.35 秒 → 約 0.73 秒に延びた。手触りが重ければ、Throw の Speed と Carry Windup を一緒に変える。
