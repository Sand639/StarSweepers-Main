## この機能は何か

プレイヤーの体が、している動きに合わせてアニメーションするようになった。
今までは「止まっている（Idle）」と「歩く（Walk）」だけだった。Hans さんが作った動きのアニメーション6つを、どの場面で流すかを決めて付けた（割り当ては小野田さんの指定）。

---

## 遊ぶ人から見た動き

上にあるものほど優先。2つが同時に起きたら、上のほうが流れる。

| いまの様子 | 流れるアニメーション | 元の素材（Hans） |
| --- | --- | --- |
| ガラスなどの足場から落ちている | **落ちる瞬間**（両手を上げる）→ **落ちている間**（くり返し） | `AN_Drop.fbx` → `AN DropLoot.fbx` |
| 手前の物資を押して、両手で持っている | **両手で頭の上へ持ち上げて、前へ振り下ろして投げる**。持った物も手と一緒に上がる。投げたあとも振り切るまで流れる | `AN_Throw.fbx` |
| 物資をつかんで巻き取っている | **引っ張る**（大きく引く動き。くり返し） | `AN_Pull.fbx` |
| 光線を撃った瞬間 | **撃つ**（終わったら狙い歩きへ戻る） | `AN_Shoot.fbx` |
| 押して狙っている（溜め中） | **狙いながら歩く**。歩く速さに合わせて足が動き、**止まっていると止まったポーズ**になる | `AN_Character_Aimwalk.fbx` |
| それ以外 | 今までどおり **Idle と歩き** | `AN_Character_Idle.fbx`・`AN_Character_Move.fbx` |

- 両手で投げる「溜め」の長さを、アニメーションの振り下ろす瞬間に合わせた（**押してから約 0.73 秒で物が飛ぶ**。前は約 0.35 秒）。
- ほかの人の体（オンライン）も、同じように切り替わる（落ちる・両手で持つは、届いた位置と「持っている」の知らせから決める）。

## 設定できる値（インスペクターの項目）

**体のプレハブ `SweeperPlayer` の `SweeperAnimation`**

| 項目名 | 意味 | 実装したときの初期値（目安。調整で変わる） |
| --- | --- | --- |
| Shoot / Aim / Idle / Pull / Throw / Drop State | Animator の中の状態の名前。**Animator の状態の名前と同じでないと流れない**（決まり） | Shoot / AimWalk / Idle / Pull / Throw / Drop |
| Speed Parameter / Aim Speed Parameter | 歩く速さ・狙い歩きの再生の速さを渡すパラメーターの名前（決まり：Animator と同じ名前） | Speed / AimSpeed |
| Cross Fade | 切り替えのつなぎの秒数 | 0.05 |
| Fall Depth | 最後に立っていた高さより何 m 下へ落ちたら「落ちている」にするか | 1 |
| Fall Speed | 下向きにこの速さ（m/秒）より速いときだけ「落ちている」にする（ゆっくり下がる床で誤って流さない） | 3 |
| Land Seconds | 上下の動きがこの秒数止まったら「着いた」にする | 0.15 |
| Left / Right Hand Bone | 両手の骨の名前（決まり：体のモデルの骨と同じ名前） | JNT_Hand_L / JNT_Hand_R |

**同じプレハブの `SweeperReel`（両手で投げる）**

| 項目名 | 意味 | 実装したときの初期値（目安） |
| --- | --- | --- |
| Carry Windup | 両手の位置に来てから投げるまでの秒数。**Carry In Seconds と足して、投げるアニメーションの振り下ろす瞬間（約 0.73 秒）に合わせる** | 0.63（Carry In Seconds 0.1 と合わせて 0.73） |
| Carry With Hands | 投げるアニメーションの間、持った物を両手の真ん中に合わせて動かす | ON |
| Carry Hands Forward | 両手の真ん中から、さらに体の前へ何 m ずらすか | 0.3 |

**Animator `AC_SweeperPlayer`**

- 投げる動きを速く・遅くしたいときは、Throw の状態の Speed を変えて、**Carry Windup も同じ割合で変える**（ずれると、振り下ろす前・後に物が飛ぶ）。
- Drop → DropLoot は Animator の中でつながっている（Drop が終わったら DropLoot）。

## 仕組み（分かる人向け）

### 骨の名前が違うので、複製のクリップを作っている（**体のモデルが新しくなるまでの仮のやり方**）

> **2026/11/25 に分かったこと（小野田さんがデザイナーさんに確認）：正しいのは新しい5つのほう。**
> 新しい5つは、`SK_Character.fbx` のリグ（骨組み）が未完成だったのを直した版に付けたアニメーション。**`Assets/` の `SK_Character.fbx` が直す前の古い版のまま**なのが原因。デザイナーさんに情報を渡したので、直った体のモデルが来たら、このアニメーションは元の FBX のまま使う形に戻す。
> 下の表の「右腕が左の名前」も、新しいリグではこれが正しい名前（体の側が古い）。
>
> **体のモデルが新しくなったら、やること**
> 1. 新しい `SK_Character.fbx` を `Assets/Art/Models/` に上書きする（同じファイル名なら `.meta` の番号が変わらず、プレハブの参照は外れない）。
> 2. **メニュー「プレイヤーの動きのアニメーションを取り込む」は押さない**（押すと、正しい骨の名前を古い名前へ置き換えてしまい、体が動かなくなる）。Animator `AC_SweeperPlayer` の Shoot・Pull・Throw・Drop・DropLoot の中身を、`AN_〇〇_SK.anim` から元の FBX のクリップに差し替える。くり返すもの（Pull・DropLoot）は Loop Time が要る（FBX の取り込みの設定を変えるので、デザイナーさんに確認するか、Walk と同じように Animator の側でくり返す）。
> 3. **Idle・Move（歩き）・Aimwalk は古いリグの骨の名前で作られている**ので、体を新しくすると、今度はこの3つが動かなくなる。新しいリグで書き出し直した版をもらう（それまでの間は、この道具を逆向きの置き換えに直して使う手もある）。
>    - **新しいリグの歩き `共有フォルダ/…/02_Character/CHAR_Re2_walking_new.fbx` が来た（2026/11/25。まだ Git に入っていない）。** 使い捨ての Unity で調べた結果：骨の名前は新しい5つ（Throw など）と**85本すべて同じ**（Throw にだけ `SM_Gun_01` がある）。いまの `Assets/` の体には1本しか当たらない。1.1 秒（30fps で 33 コマ）で、**最後のコマが最初のコマと同じ形なので、そのままきれいにくり返せる**（前の歩き AN_Move のような「後半が止まっている」所は無い）。取り込みの設定の Loop Time は初期値の OFF。中に直したリグの体のモデル（頂点 3422・骨 62。いまの体は 3421）も入っている。ポーズを画像にして、歩きとして自然に見えることを確かめた。
>    - **2026/11/26 に、新しいリグの Idle（`CHAR_Re2_idle_new.fbx`）と狙い歩き（`CHAR_Re2_aim_walking_new.fbx`）も来た（共有フォルダ。まだ Git に入っていない）。** どちらも骨の名前は新しい5つと同じで、いまの体には当たらない。Idle は 1.1 秒（33 コマ）の小さな揺れ（いちばん動く骨で約 8 度）、狙い歩きは 1.1 秒の歩き。どちらも最後のコマが最初とほぼ同じ形（0.2〜0.3 度差）で、そのままくり返せる。狙い歩きは、動いていない骨（胸・頭・左肩・両手・バッグなど）の動きのデータが省かれている（ほかは 85 本、狙い歩きは 51 本）。Animator の Write Defaults が ON なら、その骨は体の元の形になるので問題ない見込み。なお、このとき `CHAR_Re2_walking_new.fbx` は共有フォルダから無くなっていた。develop に入った Hans さんの `AN_Fall.fbx`（2.1 秒）・`AN_Rise.fbx`（1.0 秒）も新しいリグ。
>    - **共有フォルダと `Assets/` の `SK_Character.fbx`（2026/11/11 の版。2つは同じ中身）は古いリグのまま**で、新しいアニメーションは1つも当たらない。新しいリグの体は、上の CHAR_Re2_〇〇 や AN_〇〇 の FBX の中に入っている（頂点 3422・骨 62）。
> 4. 3つとも新しくなったら、道具 `SweeperAnimationSetup.cs` と `AN_*_SK.anim` は消してよい。`SweeperAnimation` の手の骨の名前（Left / Right Hand Bone。今は `JNT_Hand_L` / `JNT_Hand_R`）も、新しいリグの名前に合わせる（右手が `JNT_Shoulder_L2` の下の `JNT_Hand_L` なら、名前で探すと左手と同じ名前が2つになるので、探し方を直す必要がある）。

2026/11/19 に来た動きの FBX（Shoot・Pull・Throw・Drop・DropLoot）は、体のモデル `SK_Character.fbx`（と Idle・Move・Aimwalk）と**骨の名前が2か所違う**。そのまま Animator に入れると、体が1本も動かない（Unity はアニメーションを骨の名前のつながりで当てるため）。

| 違う所 | 動きの FBX | 体のモデル |
| --- | --- | --- |
| いちばん上 | `GRP_ExportScale_DO_NOT_TOUCH/CTRL_Global/JNT_Tool/…` | `SCL_Root/JNT_Root/…` |
| 右腕 | `JNT_Shoulder_L2/JNT_Arm_L/JNT_Hand_L`（左の名前になっている） | `JNT_Shoulder_R/JNT_Arm_R/JNT_Hand_R` |

そこで道具 `SweeperAnimationSetup` が、**動きはそのまま・骨の名前だけ体に合わせた複製（`AN_〇〇_SK.anim`）**を作り、Animator にはその複製を入れている。Hans さんの FBX と取り込みの設定は変えていない。いちばん上の3つの骨（GRP・CTRL_Global・JNT_Tool）は動いていない入れ物なので捨て、体の側の値をそのまま使う。体に無い骨（`SM_Gun_01` など）の動きも捨てる。くり返すもの（AimWalk・Pull・DropLoot）は複製の側で Loop Time を ON にしている。
画面なしの Unity で6つとも全部の骨が当たること（当たらない骨 0）と、ポーズを画像にして腕がねじれていないことを確かめた。

**Hans さんが FBX を直した・新しく足したときは、FBX を `Assets/Art/Animation/` に置き直して、メニューの「プレイヤーの動きのアニメーションを取り込む」を1回押す**（複製が作り直され、Animator の中身も入れ替わる。Idle・Walk は触らない）。**ただし、これは体のモデルが古いままの間だけ。** 体のモデルが新しくなったら押さないこと（上の囲み）。

### どのアニメーションを流すか（SweeperAnimation）

- 撃つ側（`SweeperShooter`）が、狙う（`PlayAim`）・撃つ（`PlayShoot`）・巻き取り始め（`PlayPull`）・やめる（`PlayIdle`）を呼ぶ。ほかの人の体では、通信で届いた光線の段階が変わったときに同じものを呼ぶ。
- それとは別に毎フレーム、**落ちているか**と**両手で持っているか**を調べ、優先の順（落ちる → 投げる → 撃つ側の指定）で1つ選ぶ。変わったときだけ `CrossFade` する。
- 落ちているか：**位置の上下の動きだけ**で決める（ほかの人の体でも同じに働くように）。「最後に立っていた高さより Fall Depth 下」かつ「下向きに Fall Speed より速い」で落ちている、上下が Land Seconds 止まったら着いた。1フレームで 2m より大きく動いたら瞬間移動（出てくる場所へ戻された等）とみなして、落ちたことにしない。吹き飛ばされて跳ねたときは、元の高さより下へは行かないので流れない。
- 両手で持っているか：自分で動かしている体は `SweeperReel.IsCarrying`、ほかの人の体は `SweeperNetSync.IsCarrying`（本人が書く通信の値）。
- 狙い歩き：Animator の `AimSpeed` に「いまの歩く速さ ÷ ふだんの歩く速さ」を渡し、AimWalk の状態の再生の速さに使っている。止まっていると 0 で、止まったポーズになる。

### 持った物を両手に合わせる（SweeperReel）

`SweeperAnimation.TryGetHandsCenter` が、Throw を流している間だけ両手の骨の真ん中を返す。`SweeperReel` の両手で持つ位置（`CarryPoint`）は、それがあれば「両手の真ん中＋体の前へ Carry Hands Forward」、無ければ今までどおり「体の前・胸の高さ」。自動テストでは、物が 0.5m から約 0.81m まで手と一緒に上がり、振り下ろす瞬間（Throw の約 0.70 秒）に飛んだ。

## できていないこと・既知の問題

- **人が遊んでの見た目の確認がまだ**（画面なしの Unity の自動テストと、ポーズの画像でだけ確かめた）。
- **引っ張る（Pull）は「大きく引く」1回の動きを、巻き取っている間くり返している。** 約 2.1 秒ごとに引き直して見える。巻き取り中にゆっくり歩いても、足は引っ張るポーズのまま滑る。
- **落ちる瞬間（Drop）は、物を持っていないときにも流している。** Hans さんの説明は「落ちる瞬間、特に物を持っている時」。持っていないときは別の動きにするか、流さないかは未確認（`質問リスト.md`）。
- **狙い歩きを止まって流すと、歩きの1コマ目（足を開いたポーズ）で止まる**（小野田さんの指定どおり「速さ 0 の狙い歩き」）。
- **体が画面に映っていないと、骨が動かない**（Animator の Culling Mode が「見えていないときは骨を動かさない」）。その間に両手で投げると、持った物は止まった手の位置（胸より少し下）に合わせて動く。遊びには影響しない見込み。
- **ほかの人の体の「落ちている」は、届いた位置から決める**ので、上下する床・始まりの演出で運ばれている間に速く下がると、落ちるアニメーションが流れることがある。
- 投げるまでの時間が約 0.35 秒 → 約 0.73 秒に延びた（アニメーションに合わせたため）。手触りが重ければ、Throw の Speed と Carry Windup を一緒に変える。
