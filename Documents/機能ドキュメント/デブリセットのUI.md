## この機能は何か

ラウンドイベント「**デブリセット**」（`宇宙ごみのラウンドイベント.md`）のお題を、**腕が画面の外から持ってくる枠**に、**物資のカードを横に並べて**出す。

- 枠はチームごとに1つ。お題の物資の数（いまは3個）だけカードが並ぶ。**そのチームのゴールが画面の左に見えれば左上、右に見えれば右上**に出す（右上の枠は、腕が右から入ってくる左右反対の形）。3・4チーム目はその下の段
- 枠の左上に「**特注依頼...**」の文字。後ろの点が **1個から6個まで増えて、また減る**のをくり返す
- カードの地は、**その物資の色**（ゲームの中の物資と同じ色）に染めてある。物資の画像の本素材が来るまでの目印
- 自分のチームが入れた物資のカードには、**白いカードがかぶさり、チェックが大きく出てから元の大きさに落ち着く**
- お題をそろえると、**チェックの付いたカードが下へ流れ、次のお題のカードが上から落ちてくる**（スロット）

設計図：デザイナーさんの「【イベント『セット』のUI_演出流れ】」（腕だけ → 枠が開いてカードが並ぶ → チェック → カードが下へ流れる、と、腕が画面の外から入ってくる絵）。

## 遊ぶ人から見た動き

| いつ | どうなるか |
| --- | --- |
| イベントの前 | 何も出ない |
| デブリセットが始まった瞬間〜0.7秒 | 腕が**閉じた形**（腕のかっこ・細い枠・反対側のかっこ）のまま、**上の端を画面の外の側へ25度傾けて**入ってくる。**棒は下へ垂れている**。0.3秒ごろに腕がまっすぐに起き上がり、棒は水平（画面の外へのびる向き）になる。そのあと勢いで**腕が反対側へ20度揺れて**、0.7秒でまっすぐに落ち着く（大槻さんの4枚の絵のとおり）。棒と腕は別の画像で、オレンジの金具を中心にそれぞれ回る |
| 0.7〜0.95秒 | 反対側のかっこが外へ動き、それに合わせて枠が伸びる。開ききると「特注依頼...」の文字が出る |
| 0.95〜1.95秒 | カードが**上から下へ流れて**、左から順に止まる。いちばん右は**ちょうど1秒**で止まる（始まりから 1.95 秒）。止まったカードがお題 |
| お題の物資をゴールに入れた | そのカードに白いカードがかぶさり、チェックがポンと出る。同じ物資が2つあるときは**左から**付く。順番どおりの設定（Debris Set Ordered）なら左から順に付く |
| お題をそろえた（お題の3個を全部入れた） | 3個ともチェックの付いたカードが下へ流れ出て、次のお題が上から落ちてくる（左から順に止まり、いちばん右が1秒） |
| イベントが終わった | カードが 0.15 秒で消え、枠が閉じて、腕が画面の外へ出ていく |
| ラウンドごと終わった（シーンが変わった） | すぐ消える |

- **途中から見え始めた人**（イベントの開始から 1.95 秒以上たってから画面に出た人）には、開いて止まった状態で出る。
- 出てくる演出とスロットは**イベントが始まった時刻（全員で同じ時計）から数える**ので、どのPCでも同じころに止まる。流れる途中のカードは見た目だけなので、PCごとに違ってよい。止まるカード（お題）は全員同じ。

届いたら、フォントのファイル（.ttf / .otf）を入れて、プレハブの `DebrisSetUI` の **Title Font** に入れる。

### 検証シーンの使い方

`Assets/Scenes/Test/EventUI_SetDebris.unity` を開いて再生する。

- 再生するとすぐ、2チームぶんの腕が左右から入り、枠が開いてお題が落ちてくる
- お題は3個（本番と同じ）。0.8秒ごとに、どこかのチームが物資を1個入れたことになる（チェックが付く）。3個そろうと、カードが下へ流れて次のお題が来る
- 再生中に、Hierarchy の `DebrisSetUI` を選んで、インスペクターの **Test Event Running** のチェックを外すと**しまう演出**、付け直すと**最初から出てくる演出**が見られる（右クリックメニュー（歯車）の「テスト：しまう／出す を切り替える」でも同じ）
- 「テスト：全チームのお題を引き直す」で、いつでもスロットをもう一度見られる
- テスト用の値（チーム数・お題の数・順番どおり など）は、インスペクターの「テスト用」の欄で変えられる

**大きさ・置き場所**：チームごとの表示 `Panel0`〜`Panel3` の **Scale**（初期値 0.825。2026/11/19 に 0.75 の 1.1 倍にした）と位置（左上の枠は画面の左上から (-20, 150)。**横がマイナスなのは、腕の付け根を画面の外に出すため**。右上は右上から。2段目は 176 下）で変える。

**決まり**：

- `Panel0`〜`3` と、その中の `Slot0`〜`7`（マス）は、スクリプトの Panels の欄に割り当ててある。**消したり減らしたりしない**（チームの最大数が4、お題の最大数が8のため）
- 枠の横幅は「Card Margin ＋ Card Pitch × お題の数」。3個のときにちょうど素材の幅（347）になる。お題の数を変えると、枠の画像が横に伸び縮みする

## 仕組み（分かる人向け）

> スクリプトの詳しい説明は `スクリプトの説明/Game/UI/DebrisSetUI.md`。

- **表示するだけ。** お題・入れた数・そろえた回数は、ホストが決めて全員へ配っている `SpaceJunkRound` の値を毎フレーム読む。何も送らない
- ゲームの開始時に `Resources/DebrisSetUI.prefab` から1つ作り、シーンをまたいで残す。デブリセットが起きていないときは隠れている
- 腕・枠・金具・文字・カードは、チームごとの `Body` の下にまとめてあり、入ってくるときは `Body` ごと**つなぎ目（Arm Joint）を中心に**、起き上がる → 反対側へ揺れる → 落ち着く、と回す。**棒（`Rod`）は `Body` の外**（`Body` より奥）に置き、同じつなぎ目を中心に、腕とは別の角度（下へ垂れた向き → 水平）で回す。それぞれの位置は、毎フレーム「出てきてからの秒数」と「並べ方」の値から決める。右の枠は x を反転し、腕と金具の画像だけ左右反転する（文字・カードは反転しない）。枠は Image の Filled（横）で、腕の側から開く
- スロット：マスごとに「流れるカードの並び」を作る。**最初が前のお題のカード（そろえたならチェック付き）、最後が新しいお題のカード**。止まる時刻に向けて `1 − (1 − t)²` で遅くなる
- チェック：順不同なら、種類ごとの「入れた数」だけ、その種類のマスを左から埋める。順番どおりなら左から「何個目まで入れたか」の数だけ

## できていないこと・既知の問題

- **物資の画像は仮。** 本素材がまた来る予定。それまでは、カードの地を物資の色に染めて見分ける
- **文字のフォントは仮**（デザイナーさん指定のフォント待ち。`質問リスト.md`）
- **作り替えたあと、本物の試合・参加者側の画面・人が遊んでの確認はまだ**（テストモードを画面なしの Unity で画像にして確かめただけ）
- 設計図のいちばん下の絵（カードが上下にずれて、矢印が下向き）は、「**お題をそろえたら、チェック付きのカードが下へ流れて、次のお題が上から来る**」と読んで作った。違っていたら直す（`質問リスト.md`）
- 流れるカードは、枠の外（上下）にもはみ出して見える（設計図のいちばん下の絵に合わせて切り抜いていない）
- お題をそろえた瞬間、ホストはすぐ次のお題を引くので、**3個目のチェックがポンと出る所は見えない**（3個ともチェックの付いたカードが下へ流れていくのは見える）
- イベントの始まりの 0.95 秒は腕と枠の演出なので、**お題が分かるのは始まりから 1.95 秒**（2026/11/26 に腕の揺れを足して 0.2 秒のびた）
- **腕と棒の新しい動きは、画面なしの Unity で場面ごとの画像にして確かめただけ**（動いているところを人の目で見ていない）
- 左右は、ゴールが画面のどちらに見えるかで決める。**カメラを切り替えて左右が入れ替わる場面は、まだ人の目で確かめていない**
- 3・4チームのときの置き場所（2段目）は、見た目を確かめていない
- 前の仮のフレームの画像 `Art/Sprites/DebrisSetFrame.png` と、前の仮のチェック `Art/Sprites/DebrisSetCheck.png` は、もう使っていない（消すときは Unity の中で消す）
