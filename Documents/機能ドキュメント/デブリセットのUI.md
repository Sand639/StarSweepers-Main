## この機能は何か

ラウンドイベント「**デブリセット**」（`宇宙ごみのラウンドイベント.md`）のお題を、**物資の画像を横に並べた枠**で画面に出す。

- 枠はチームごとに1つ。**左上が青チーム、右上が赤チーム**（3・4チーム目はその下の段）
- イベントが始まると、**1秒間スロットの演出**をする。マスごとに物資の画像が下から上へ流れ、**だんだん遅くなって左から右へ順に止まり、いちばん右がちょうど1秒で止まる**
- 自分のチームがゴールに入れて**お題に数えられた物資には、画像の右下にチェックマーク**が付き、**画像が少し灰色**になる
- お題をそろえて次のお題が出たときも、もう一度スロットを回す

設計図：本人のSVG（`UI仮の設計.svg`。黄緑の角丸の枠に、物資の丸が5つ）と、試合の画面に重ねた参考画像。

## 遊ぶ人から見た動き

| いつ | どうなるか |
| --- | --- |
| イベントの前 | 何も出ない |
| デブリセットが始まった瞬間 | 両チームの枠が出て、マスの中を物資が下から上へ流れる（スロット） |
| 始まって 0.5〜1秒 | 左のマスから順に止まる。いちばん右は**ちょうど1秒**で止まる。止まった物資がお題 |
| お題の物資をゴールに入れた | その物資の右下にチェックが付き、画像が灰色っぽくなる。同じ物資が2つあるときは**左から**付く。順番どおりの設定（Debris Set Ordered）なら左から順に付く |
| お題をそろえた（初期値は3個） | 次のお題が出て、またスロットが回る |
| イベントが終わった・ラウンドが終わった | 枠が消える |

- **途中から見え始めた人**（イベントの開始から1秒以上たってから画面に出た人）には、スロットは回らず止まった状態で出る。
- スロットは**イベントが始まった時刻（全員で同じ時計）から数える**ので、どのPCでも同じころに止まる。流れる途中の物資は見た目だけなので、PCごとに違ってよい。止まる物資（お題）は全員同じ。

## 画像の差し替え方（本素材が来たら）

いまは**ツールで描いた仮の画像**が入っている。

| 画像 | ファイル（`StarSweepers/Assets/Art/Sprites/`） | 仮の見た目 |
| --- | --- | --- |
| 物資1（装甲板） | `DebrisSetItem1.png` | 白い丸に点1つ |
| 物資2（回路基板） | `DebrisSetItem2.png` | 紫の丸に点2つ |
| 物資3（燃料タンク） | `DebrisSetItem3.png` | 橙の丸に点3つ |
| 物資4（アンテナ） | `DebrisSetItem4.png` | ピンクの丸に点4つ |
| 物資5（エンジン） | `DebrisSetItem5.png` | 灰色の丸に点5つ |
| フレーム | `DebrisSetFrame.png` | 黄緑の角丸の四角に黒い縁 |
| チェックマーク | `DebrisSetCheck.png` | 緑のチェック |

> 物資の番号と種類の対応は、ゲームの中の素材の種類（`SpaceJunkMaterialKind`）の並び順と同じ。色は、ゲームの中の物資の色に合わせてある。

### いちばん簡単なやり方：同じ名前で上書きする

1. 本素材の PNG を、上の表と**同じファイル名**にする（例：物資1の画像を `DebrisSetItem1.png` に）
2. エクスプローラーで `StarSweepers/Assets/Art/Sprites/` に**上書きで**入れる（`.meta` ファイルは消さない・触らない）
3. Unity に戻ると読み込み直される。**ほかに何もしなくてよい**

- 正方形の画像がおすすめ（物資とチェックは、形を保ったままマスに収まる。横長・縦長でもつぶれない）
- 背景は透明に

### 別の名前の画像を使うとき

プレハブ `StarSweepers/Assets/Resources/DebrisSetUI.prefab` を開き、一番上の `DebrisSetUI` の「**素材**」の欄に画像を入れる。

| 欄 | 入れる物 |
| --- | --- |
| Item Sprites | 物資の画像。上から 物資1〜物資5 |
| Frame Sprite | フレームの画像 |
| Check Sprite | チェックマークの画像 |

画像は、インスペクターで **Texture Type を `Sprite (2D and UI)`** にしておく。

### フレームの画像についての注意（9スライス）

お題の物資の数は**4〜6個で変わる**ので、枠の横幅も変わる。そのまま伸ばすと、角の丸みが横につぶれる。
画像を選んで **Sprite Editor** を開き、**Border（緑の線）を角の丸みの内側に**合わせておくと、角はそのままで真ん中だけ伸びる（9スライス）。
Border を決めていない画像は、そのまま引き伸ばして出す。

- 仮の画像は、上書きしても前の Border の値（26 ピクセル）が残る。本素材の大きさに合わせて Sprite Editor で直すこと

> **ステージのシーンも、ほかの人のプレハブも変更していない**（スクリプトは、仮の画面 `SpaceJunkMatchUI.cs` に数行足しただけ）。 ラウンドイベントの作りと同じく、ステージに部品を足さずに済むようにした。

- プレハブ・検証シーンは、メニュー `Tools > StarSweepers > デブリセットUIの検証シーンを作る` で**作り直せる**（`デブリセットUIのプレハブを更新` はプレハブだけ）。**手で直した部分は消える**ので、見た目を手で整えるようになったら、このメニューは使わないこと。
- 仮の画像は**ファイルが無いときだけ**描いて作る。上書きした本素材が、メニューで消されることはない。

### 検証シーンの使い方

`Assets/Scenes/Test/DebrisSetUITest.unity` を開いて再生する。

- 再生するとすぐ、2チームぶんのお題がスロットで出る
- 0.8秒ごとに、どこかのチームが物資を1個入れたことになる（チェックが付く）。3個そろうと次のお題が出て、またスロットが回る
- 再生中に `DebrisSetUI` の右クリックメニュー（歯車）の「**テスト：全チームのお題を引き直す**」で、いつでもスロットをもう一度見られる
- テスト用の値（チーム数・お題の数・順番どおり など）は、インスペクターの「テスト用」の欄で変えられる

## 設定できる値（インスペクターの項目）

`Assets/Resources/DebrisSetUI.prefab` の `DebrisSetUI`。

| 項目名 | 意味 | 実装したときの初期値（目安。調整で変わる） |
| --- | --- | --- |
| Item Sprites / Frame Sprite / Check Sprite | 画像（上の「画像の差し替え方」） | 仮の画像 |
| Collected Tint | 入れた物資の画像にかける色。白ならそのまま、灰色に近いほど暗く灰色っぽくなる | 灰色（0.55） |
| Swap Left Right | オンにすると、青チームと赤チームの左右を入れ替える（得点バーは 左＝赤・右＝青 なので、そろえたいときに使う） | オフ（左＝青・右＝赤） |
| **Spin Seconds** | **いちばん右のマスが止まるまでの秒数。スロットは、ちょうどこの秒数で全部止まる** | 1 |
| First Stop Ratio | いちばん左のマスが止まる時刻（Spin Seconds に対する割合）。そこから右へ、等しい間隔で順に止まる | 0.5（1秒なら 0.5秒） |
| Spin Start Speed | 回り始めの速さ（1秒に何個の物資が流れるか）。止まる時刻に向けて、だんだん遅くなる | 24 |
| Spin On New Set | お題をそろえて次のお題が出たときにも、スロットを回すか | オン |
| Test Mode ほか「テスト用」 | ラウンドが無くてもテストの値で出す。**本番のプレハブではオフ**（検証シーンだけオン） | オフ |

枠の大きさ・マスの間隔・置く場所は、プレハブの `Panel0`〜`Panel3`（`Horizontal Layout Group` の Padding・Spacing と、位置）で変えられる。初期値は、マス 58×58・間隔 9・枠の内側の余白 左右12／上下10、左上の枠は画面の左上から（90, 190）。

**決まり**：

- `Panel0`〜`3`（枠）と、その中の `Slot0`〜`7`（マス）は、スクリプトの Panels の欄に割り当ててある。**消したり減らしたりしない**（チームの最大数が4、お題の最大数が8のため）
- 物資の画像の欄（Item Sprites）は **5つ**（物資の種類の数）

## 仕組み（分かる人向け）

> スクリプトの詳しい説明は `スクリプトの説明/Game/UI/DebrisSetUI.md`。

- **表示するだけ。** お題・入れた数・そろえた回数は、ホストが決めて全員へ配っている `SpaceJunkRound` の値を毎フレーム読む。何も送らない
- ゲームの開始時に `Resources/DebrisSetUI.prefab` から1つ作り、シーンをまたいで残す（トランジションの `SceneTransition` と同じやり方）。デブリセットが起きていないときは隠れている
- スロット：マスごとに「流れる物資の並び」を作り、最後をお題の物資にする。止まる時刻に向けて `1 − (1 − t)²` で遅くなる。いちばん右のマスの止まる時刻は、計算上 Spin Seconds ちょうど（自動テストで確認）
- チェック：順不同なら、種類ごとの「入れた数」だけ、その種類のマスを左から埋める。順番どおりなら左から「何個目まで入れたか」の数だけ

## できていないこと・既知の問題

- **画像は仮。** 本素材が来たら上の手順で差し替える
- 今の仮の画面（`SpaceJunkMatchUI`）の「お題 1/3 → +10 ■□…」の行は、**この枠が出ている間は出さない**ようにした（大槻さんの了承。`SpaceJunkMatchUI.cs` に数行足した）。仮の画面は画面なしの Unity では写らないので、**行が消えたことは画面では確かめていない**（コンパイルと、枠が出ている間 `DebrisSetUI.IsShowing` が true になることは確認）。また、仮の画面の左のチームの行（赤チームの行など）と左の枠が重なることがある
- お題をそろえた瞬間、ホストはすぐ次のお題を引くので、**3個目のチェックは見えずに**次のスロットが始まる
- 左右（左＝青・右＝赤）は、参考画像の色付きの文字に合わせた。得点バーは 左＝赤・右＝青 なので、逆がよければ Swap Left Right をオンにする
- 入れた物資は色を掛けて暗くしているだけで、白黒にはしていない（白黒にするには専用のシェーダーが要る）
- **別のPC（参加者）の画面では、まだ確かめていない。** 値は全員に配られている物を読むだけなので同じになるはず
- 3・4チームのときの置き場所（2段目）は、見た目を確かめていない
