## この機能は何か

**試合の勝ち星を取り切ったチームの、メンバー紹介の場面。** 対戦ゲームでよくある「勝ったあとの決めの場面」を参考に作った。

最後のラウンドの結果画面（星の結果画面）が終わると、宇宙に浮かぶ台の上に**勝ったチームのメンバーが一列に並ぶ**。
カメラが1人ずつ寄って**名前の帯**を出し、紹介された人はジャンプして一回転する。
全員の紹介が終わると、引きの画で**全員が跳ねて「WIN!」と「〇チームの勝利！」**、紙吹雪が降る。そのあとロビーへ戻る。

---

## 遊ぶ人から見た動き

| 時間の目安（4人のとき） | 見えるもの |
| --- | --- |
| 0〜1.3秒 | チームの色で覆われた画面が晴れ、カメラが上から台へ降りてくる。後ろではチームの色の放射状のしまがゆっくり回る |
| 1.3〜5.3秒 | 1人1秒ずつ、カメラが寄って左下に名前の帯（「MEMBER 1 / 4」と名前）。その人がジャンプして一回転 |
| 5.6〜8.8秒 | 白く光って「WIN!」がドンと出る。全員が少しずつずれて跳ね続け、紙吹雪が降る |
| そのあと | 全員の画面で見終わったら、いつもの色帯でロビーへ戻る |

- メンバーの体は、**そのプレイヤーの今の見た目（服の色）をそのまま写したもの**。ボットも並ぶ。
- 5人以上のときは、1人あたりの紹介を短くする（0.75秒）。
- 並び順は参加番号の順で、どのPCでも同じ。

### 検証シーンでの試し方

`Assets/Scenes/Test/MatchVictoryShowcaseTest.unity` を開いて再生。仮の名前の4人で流れ、終わると繰り返す。

| キー | 動き |
| --- | --- |
| スペース | 最初から流し直す |
| 1 / 2 / 3 / 4 | 青 / 赤 / 緑 / 黄 のチームが勝ったとして流し直す |

## 設定できる値（インスペクターの項目）

演出は試合中にスクリプトから作るので、試合では下の初期値が使われる（値を変えるときは `MatchVictoryShowcase.cs` の初期値を直す）。検証シーンでは、再生中にできる `MatchVictoryShowcase` の物で触れる。

| 項目名 | 意味 | 実装したときの初期値（目安。調整で変わる） |
| --- | --- | --- |
| Intro Seconds | 始まりの、カメラが降りてくる時間 | 1.3秒 |
| Per Member Seconds | 1人を紹介する時間 | 1秒 |
| Finale Seconds | 最後の「WIN!」を見せる時間 | 3.2秒 |
| Member Spacing | メンバーの間隔 | 1.35m |
| Member Height | 体の写しの背の高さ（モデルの大きさにかかわらずそろえる） | 1.6m |
| Hop Height | 紹介のときのジャンプの高さ | 0.55m |

検証シーンの `MatchVictoryShowcaseTester` では、勝ったチーム・メンバーの名前（並ぶ人数）・繰り返すかを変えられる。

## 仕組み（分かる人向け）

1. ホストが最後のラウンドで勝ち星を取り切ると、`ReturnToLobbyAfterDelay` が結果画面（`PresentRoundResult`）を待ったあと `PresentMatchVictory` を呼ぶ。
2. `ShowVictoryShowcaseClientRpc` で全員のPCに「〇チームが勝った」とだけ送る。各PCは自分のシーンにいる `SweeperPlayer` からそのチームの人を集め（`CollectTeam`）、体のモデル（Animator の付いた物）を写して並べる。
3. 台・背景・明かりは、マップから離れた所（高さ3000m）に層 29 で作り、専用のカメラでテクスチャに描く。そのテクスチャを、結果画面の色帯（並び順 30000）より手前の画面（30001）に貼る。試合中の表示の上に出て、場面の切り替え（`SceneTransition`）よりは奥。
4. 終わると各PCがホストへ知らせ、全員がそろったら（または25秒たったら）いつもの色帯でロビーへ。演出はマップのシーンに作るので、ロビーへ切り替わると一緒に消える。

時刻ごとの見た目は `DrawAt(秒)` 1つで決まるので、再生しなくても好きな時刻の絵を撮れる。

## できていないこと・既知の問題

- **実際の試合・2台のオンラインでは、まだ流していない。** 検証シーンの絵（画面なしの Unity で時刻ごとに撮った画像）でだけ確かめた。
- **勝ちのポーズのアニメーションが無い。** いまは待機のアニメーションのまま、体ごとジャンプ・一回転させている。勝ちポーズのモーションができたら差し替えたい。
- 負けたチームは出していない（参考にした場面では、負けたチームの様子も短く映る）。
- 音（ファンファーレなど）はまだ無い。
- 文字はOSの日本語フォント（`UiFont`）の仮。「WIN!」のロゴはデザイナーさんの素材に替えたい。
- 3・4チームの試合でも流れる（結果画面のほうは2チームのときだけ）。
