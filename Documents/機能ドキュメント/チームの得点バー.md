## この機能は何か

画面の上の真ん中に、**チームの色の帯を横に並べたバー**を出す。
**得点の多いチームほど帯が太くなる**（2チームなら、左の赤と右の青の境目が、得点の差に合わせて左右に動く）。
得点が入ると、帯の幅は**なめらかに**新しい比率へ動く。

バーの真ん中には**丸**があり、その中に**残り時間**（「1:23」のような分:秒）を出す。残り10秒を切ると赤い文字になる。

デザイン案（11月）の「上の赤と青のバー」と「真ん中の時間の丸」にあたる。
**チームの帯は、まるごと炎になっている。** 帯の中は根元（下）ほど明るい炎がゆらめき、帯の上の端からはチームの色の炎の舌が立ちのぼる。
得点が入ると、**そのチームの帯の炎が高く・明るく燃え上がり**、得点の数字がポンと大きくなってから元に戻る（デザイン案の2枚目の方向。**画像は使わず、シェーダーで炎を作っている**）。

## 遊ぶ人から見た動き

| 操作 | 結果 |
| --- | --- |
| 検証シーンを再生する | 赤と青が半分ずつのバーが出て、2分から時間が減っていく。1.5秒ごとにどちらかのチームに1点入り、帯の幅が動く |
| 再生中にインスペクターの Test Scores を書き換える | その得点の比率へ帯が動く |
| 再生中に Test Team Count を 3 や 4 にする | 帯が3本・4本に増える |
| 宇宙ごみの対戦中（このバーを置いたステージ） | 本当のチームの得点と残り時間を出す |

- 全チーム0点のときは**等分**。
- 0点のチームも、**細い帯は残る**（Min Share。0にすると完全に消える）。

## 設定できる値（インスペクターの項目）

| 項目名 | 意味 | 実装したときの初期値（目安。調整で変わる） |
| --- | --- | --- |
| Smooth Speed | 帯の幅が新しい比率に追いつく速さ。0 ならすぐ切り替わる | 6 |
| Min Share | 0点のチームにも残す最低の幅（バー全体を1とした割合） | 0.05 |
| Reverse Order | オンなら、チーム番号の大きい順に左から並べる（2チームなら 左＝赤・右＝青。デザイン案の並び） | オン |
| Show Score Numbers | 帯の上に得点の数字を出すか | オン |
| Use Custom Colors / Custom Team Colors | オンなら、ここで決めた色を使う。オフなら、ゴールやプレイヤーと同じチームの色 | オフ |
| Warn Seconds / Time Color / Warn Time Color | 時間の文字を警告の色にする残り秒数と、その色 | 10秒・白・赤 |
| Test Mode | オンなら、ラウンドが無くても下のテスト用の値で出す。**本番のステージではオフ** | プレハブはオフ・検証シーンはオン |
| Test Team Count / Test Scores / Test Round Seconds | テスト用のチーム数・得点・制限時間 | 2・全部0・120秒 |
| Test Auto Score / Test Auto Score Interval | 一定の間隔でランダムなチームに1点足すか、その間隔 | オン・1.5秒 |

**炎の演出（`TeamScoreFlameEffect`）**

| 項目名 | 意味 | 実装したときの初期値（目安。調整で変わる） |
| --- | --- | --- |
| Boost Seconds | 炎が燃え上がってから戻るまでの秒数 | 1秒 |
| Punch Scale / Punch Seconds | 数字がポンと大きくなる量と、戻るまでの秒数 | 0.6（1.6倍）・0.35秒 |

**炎の形・色（マテリアル `TeamScoreBarFire.mat`）**：炎の舌の高さ・太さ（ピクセル）・ゆれの強さ・流れる速さ、根元ほど明るくする強さ、3段の塗り分け（明るい部分の始まりと白さ）、ふちの線の太さと暗さ、得点が入ったときに増える高さ・明るさ。炎の外側の色は**チームの色**で、内側（根元）ほど白くなる。

**決まり**：
- Segment Images と Score Texts は**4つずつ**（チームの最大数が4のため）。減らすと、そのチーム数のときに帯が出ない。
- 帯（`Segment0`〜`3`）の Image は、**帯の高さより上に 44 だけ高く**してある（炎の舌が立ちのぼる所）。マテリアルの **Bar Ratio**（Image の下から何割が帯か）はこの高さで決まるので、**手で変えない**。帯や炎の高さを変えたいときは、`TeamScoreBarUISetup.cs` の `BarSize`・`FireRise` を変えてメニューで作り直す。
- 得点の数字（`Score`）は、上の 44 を除いた帯の高さの中に置いてある。
- 数字の文字のマテリアルは **`OUTLINE_ON` のキーワードが入っていないと縁取りが出ない**（TextMeshPro の Mobile のシェーダーのため）。マテリアルを作り直すときは、インスペクターの Outline の欄にチェックを入れる。

## 仕組み（分かる人向け）

> スクリプトごとの詳しい説明は `スクリプトの説明/Game/UI/TeamScoreBarUI.md`（バーとメニュー）と `スクリプトの説明/Game/UI/TeamScoreFlameEffect.md`（炎）。

- 毎フレーム、`SpaceJunkRound.Current` があれば `ScoreOf(team)`・`RemainingSeconds`・`SpaceJunkSession.Current.TeamCount` を読む。**得点制（Rule = Score）のときだけ**出す。ラウンドが無く Test Mode がオンならテスト用の値を使う。どちらでもなければ子の `Content` を非表示にする。
- 目標の幅 = `Min Share + (1 - Min Share × チーム数) × 得点 / 合計`。表示中の幅を `1 - exp(-Smooth Speed × 経過時間)` で目標へ近づける（`unscaledDeltaTime` なのでポーズ中も動く）。
- 帯は `Segments` の子の Image で、`anchorMin.x`・`anchorMax.x` を左から順に割り当てて幅を変える（縦の余白はプレハブのまま残す。炎の舌の所のため）。得点の数字は帯の子なので一緒に動く。
- 得点が変わると `ScoreChanged(チーム番号, 新しい得点, 増えた量)` を呼ぶ。`TeamScoreFlameEffect` がこれを受けて、そのチームの演出を最初から始める（減ったときは何もしない）。
- `TeamScoreFlameEffect` は、帯ごとにマテリアルを複製して `_Boost`（燃え上がりの強さ）を渡す。帯の色（チームの色）は得点バーが Image の Color に入れていて、シェーダーはそれを炎の色に使う。数字の拡大は `fontSize` を変えている（`localScale` だと、帯いっぱいに広がった文字の枠ごと大きくなり、数字がずれるため）。
- 炎のシェーダー：横は Canvas の中のピクセル座標で計算する（帯の幅が変わっても炎の舌の太さがそろい、隣の帯とも模様がつながる）。横に細かく縦にゆっくり変わるノイズを上へ流して縦長の炎の舌を作り、帯の中は根元ほど「炎の濃さ」が増える。濃さのしきい値で 3 段に塗り分けてアニメ風にし、舌のふちにはチームの色を暗くした線を引く。四角の上の端に近づくと必ず細らせて消す（燃え上がっても先が平らに切れない）。UI 標準シェーダーと同じステンシル・切り抜きに対応。
- 表示するだけで、得点の計算や通信はしていない（得点は `SpaceJunkRound` の NetworkList なので、どのPCでも同じ値が読める）。

### オンラインで気をつけたこと

- **値はすべて、すでに全員へ配られているものを読むだけ。** 得点＝`SpaceJunkRound` の NetworkList、残り時間＝ホストが決めた終わりの時刻とサーバーの時刻、チーム数＝`SpaceJunkSession` の NetworkVariable。なので**ホストも参加者も同じ数字**になり、バーは何も送らない。
- `SpaceJunkRound.Current` は、どのPCでも `OnNetworkSpawn` で入り、`OnNetworkDespawn` で消える。ラウンドごとにステージのシーンが読み直されるので、バーもラウンドごとに新しく生まれる。
- **出し始めの1フレームは、得点を覚えるだけで燃え上がりは起こさない。** 途中から入った人・シーンを読み込んだ直後の人の画面で、いきなり「得点が入った」演出が出ないようにするため。
- 得点制（Rule = Score）でないとき（3種類ルール）は出さない。そのときは仮の画面がいつもどおり残り時間を出す。
- 始まりの演出（`SpaceJunkRoundIntro` など、並び順 85）とポーズ画面（100）はバー（10）より手前に出る。レーダーは右下なので重ならない。

### 仮の画面（`SpaceJunkMatchUI`）との分担

- バーは、画面の上から何ピクセルを使っているか（時間の丸の下の端まで）を `TeamScoreBarUI.OccupiedScreenHeight` に出す（出していなければ 0）。
- `SpaceJunkMatchUI` はそれが 0 より大きいとき、**残り時間を出さず**、「第 N ラウンド」の見出しとイベントの一行をバーの下へ、左のチームの行もその下へずらす。0 のとき（バーの無いマップ）は前と同じ位置。

## できていないこと・既知の問題

- 炎はシェーダーで作った仮の形。デザイン案の手描きの炎（赤い炎・青い水しぶき）とは形が違う。青チームも炎（青い炎）にしている。
- 炎の舌はバーの上へはみ出すので、**画面の上の端から少し離して置いている**（近すぎると炎の先が画面の外で切れる）。
- **別のPC（参加者）の画面では、まだ確かめていない。** 値は全員に配られている物を読むだけなので同じになるはずだが、2台（またはビルド2つ）での確認が要る。
- 得点の比率でそのまま幅を決めるので、**序盤は1点で大きく動く**（1対0 だと青がほぼ全部・赤は細い帯だけになる）。気になるなら Min Share を大きくする。
- 自動の試合の確認では、ボットが全員同じチームに入り、もう片方のチームには点が入らなかった（**誰もいないチームには点が入らない**というゲームの決まりのため。バーの問題ではない）。
- `SpaceJunkMatchUI`（大槻さんの仮の画面）に、バーがあるときの分担のための数行を足した（2026/11/10）。
- 真ん中の丸は仮の画像。デザインが決まったら差し替える。
- 時間の丸は、鈴木さんのタイマーUI（`GameTimerUI`。円形のゲージ）とは別に作った。ゲージ付きの丸にするなら、あちらを使う形も考えられる。
