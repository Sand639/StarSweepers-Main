## この機能は何か

`Assets/Scenes/Test/LobbyTestVersion.unity` を Unity で開いて再生すると、自動でホストになる。今のロビーを複製し、赤と青の輸送機で準備完了から出発までを試せる。

| 操作 | 結果 |
| --- | --- |
| 赤か青の床の上で1秒待つ | そのチームに入り、プレイヤーの色が変わる |
| 自分のチームの床で Enter かコントローラーの B を押す | 頭上に √ が出る。移動や床から離れることはできる |
| 準備完了のあと別のチームに入る | √ が消え、新しいチームの床で準備完了にできる |
| 全員が準備完了になる | 各プレイヤーが自分のチームの輸送機に乗る。赤は画面左へ回って右下へ、青は画面右へ回って左下へ飛び、出発後にステージへ移る |

同じPCで複数人で試すときは「このPCで遊ぶ人数」を増やしてから操作する。1人の場合は自分の準備完了で出発する。デバッグ用ボットは人がそろった時点で自動的に乗る。

## 関係するファイル・シーン

| 種類 | パス |
| --- | --- |
| シーン | `Assets/Scenes/Test/LobbyTestVersion.unity` |

| 準備完了の共有・試合開始 | `Assets/Scripts/Game/Match/SpaceJunkSession.LobbyTest.cs` |

出発の部品は、複製シーンの二つの輸送機につないである。製品のビルドには検証シーンを入れない。

## 設定できる値

| 項目名 | 意味 | 実装したときの初期値（目安） |
| --- | --- | --- |
| Blue Deck / Red Deck | チームの色と乗る場所を決める床 | 複製したロビーの青・赤の床 |
| Default Stage | マップ選択が空のときの行き先 | STAGE_Simple |

## 検証項目

2人で再生し、1人目が準備完了したあと床から離れ、移動できることと √ が残ることを確認する。2人目は床の外で押しても開始せず、自分の色の床で押すと、両方が元の位置から各輸送機に乗り直すことを確認する。そのあと輸送機が動き、ステージへ移ることを確認する。
