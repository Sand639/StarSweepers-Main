## この機能は何か

**画像を使わずに、計算で星空を描く背景（スカイボックス）。** 大槻さんの依頼「現実の星みたいに、いろんな色で光らせたい」で作った。

- 星ごとに、**色・大きさ・明るさ・瞬きのリズム**がばらばらに決まる
- 色は現実の星と同じく、**赤 → オレンジ → 黄 → 白 → 青白 → 青**（星の温度の違い）。色の濃さは調整できる
- 星は**ゆっくり瞬く**（星ごとにリズムが違う）
- 小さくて暗い星がたくさんの層と、大きくて明るい星が少しの層を重ねている。明るい星は、まわりが少しにじむ
- 画像を使わないので、どれだけ近づいても（カメラの視野を狭めても）ぼやけない。継ぎ目も無い
- 今の画像の空にある「真下のあたりで星が放射状に引き伸ばされる」問題（`宇宙ごみのマップの星空の背景.md`）も起きない

**試合のマップの空に使っている**（2026/11/17、大槻さんの依頼「試合のマップにこの星空を適用して大丈夫」）。マップが始まると空をこれに替える仕組みは `宇宙ごみのマップの星空の背景.md`。それまでの空は Hans さんの星空の画像だったが、大槻さんが試しに入れていたものなので替えてよいとのこと。

## 試し方

1. Unity で `Assets/Scenes/Test/ProceduralStarrySkyTest.unity` を開いて再生する
   - シーンが無いときや作り直したいときは、メニュー `Tools > StarSweepers > 計算で作る星空の検証シーンを作る`
2. 星の色・数・瞬きは、`Assets/Resources/SpaceJunkSkybox.mat` を選んで Inspector の数値を動かすと、その場で変わる。**試合の空と同じ素材なので、ここで変えると試合の空も変わる**
   - 再生していないときも、シーンビューの空に出る。瞬きの動きをシーンビューで見たいときは、シーンビュー上部の効果（Effects）のボタンの横の ▼ から「Always Refresh（常に更新）」を入れる

試合で見るとき：`Assets/Scenes/MainLoop/StarSweepersTitle.unity` から遊び、ロビーで好きなマップを選んで試合を始める。

## 設定できる値（インスペクターの項目）

マテリアル `Assets/Resources/SpaceJunkSkybox.mat` の Inspector で変える。

| 項目名 | 意味 | 実装したときの初期値（目安。調整で変わる） |
| --- | --- | --- |
| Background | 空の地の色（星のないところ） | ほぼ黒の紺 |
| Density | 小さい星の細かさ。大きいほど数が増える（星の大きさも小さくなる） | 90 |
| Small Star Amount | 小さい星の量。1＝升目すべてに星、0＝小さい星なし。**画面のにぎやかさは、まずこれで調整する** | 0.35（2026/11/17 に「画面が騒がしい」で 1 相当から減らした） |
| Big Star Density | 明るい星の細かさ。大きいほど数が増える | 20 |
| Star Size | 星の大きさ | 0.05 |
| Brightness | 星の明るさ | 2 |
| Brightness Curve | 大きいほど暗い星が増え、明るい星がまれになる | 4 |
| Color Amount | 星の色の濃さ。0＝白だけ、1＝現実の星くらい、2以上＝はっきり | 0.8（2026/11/17 に「色が強すぎる」で 1.6 から下げた） |
| Glow | 明るい星のまわりのにじみ | 0.3 |
| Twinkle Min | 瞬きでいちばん暗くなるときの明るさ（いちばん明るいときが 1）。1 で瞬かない | 0.2（明るさが 0.2〜1.0 の間で揺れる。大槻さんの指定） |
| Twinkle Speed | 瞬きの速さ | 2.5 |
| Exposure | 全体の明るさ | 1 |

- 星の並び方そのものは、数値を変えない限り毎回同じ（乱数の元が固定）。Density を変えると並びも変わる

## 仕組み（分かる人向け）

- 空の向き（長さ1の向き）に Density を掛けて、立方体の升目の空間に置く。升目ごとに1つ、升目の中のどこかに星を置く（位置は升目の番号から作る乱数）
- **球の表面の近く（厚さ1升）にある星だけを描く。** こうすると、まわり 3×3×3 の升目を調べるだけで、星が升目の境目で欠けない。立方体の面に貼る方式と違い、継ぎ目も出ない
- 星までの向きの差から、星の形（中心が明るいぼかし＋にじみ）を計算する
- **画面の1ドットより小さい星は、1ドットの大きさに広げて、そのぶん暗くする。** こうしないと、遠くの小さい星がカメラを少し動かすだけで消えたり出たりしてちらつく
- 瞬きは、星ごとに速さと始まりのずれが違う2つの波を重ねて、明るさを Twinkle Min〜1 の間で揺らす（`_Time` を使う）。2つの波の山と谷がそろったときだけ端まで行くので、ふだんは真ん中寄り
- 小さい星の層は、升目ごとの乱数で Small Star Amount の割合の升目にだけ星を置く
- 小さい星の層（Density・Small Star Amount）と明るい星の層（Big Star Density。升目すべてに星）の2回、同じ計算をして足している
- URP（このプロジェクトの描き方）用。シーンの空の設定（Lighting の Skybox Material、または `RenderSettings.skybox`）にこのマテリアルを入れると使える

## できていないこと・既知の問題

- 瞬きは静止画では確かめられないので、**動きはまだ見ていない**。Unity で再生して確かめること
- 広く見ると星がかなり多くにぎやか。遊びのじゃまになるようなら Density や Brightness を下げる（試合のカメラの静止画では、床の外に星が見える程度で、じゃまには見えなかった。人の目での判断はまだ）
- 天の川のような、ぼんやりした光の帯は入れていない（必要になったら足せる）
- 空から環境光（ステージの明るさ）を作ると、星空はほとんど黒なので真っ暗になる。検証シーンでは環境光を一色にしている。試合で使うときも、今のマップの環境光の設定のままにすること
