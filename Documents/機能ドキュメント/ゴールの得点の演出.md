## この機能は何か

**物資がゴールに入って得点が入った瞬間、そのゴールのまわりが、そのゴールのチームの色で光る。**
よくある「獲得の演出」で、1.3 秒ほどで、すっと消える。

光は3つの部品でできている。

| 部品 | 見た目 |
| --- | --- |
| 光の壁 | ゴールのまわりを四角く囲む、チームの色の光の壁。下から上へ伸びて出てきて、下ほど明るく、上へ向かって消える。縦の筋が上へ流れる。**上ほど外へ開いている**ので、上から見下ろすカメラ（全体カメラ）でも光の帯として見える |
| 光の輪 | ゴールの床の高さで、ゴールのふちから外へ広がっていく輪（角は広がるほど丸くなる）。出た直後は、ふちのすぐ外の床もにじむように光る |
| 光の粒 | ゴールのふちから、小さな光の粒が時間差で立ちのぼって消える |

- **どのステージのゴールでも、ゴールの大きさに合わせて出る。** 色を塗る床のゴール（5m×4m）でも、Hans さんの輸送機のゴール（約 3m 四方）でも、見た目の大きさを測って囲む。
- **オンラインでは、どのPCでも同じ瞬間に出る**（得点を決めるのはホストで、ホストが全員に「このゴールに得点が入った」と知らせている。その知らせで出す）。
- 光の下の床は少し暗くなるので、明るい床（白い板・灰色の床）の上でもチームの色が白に飛びにくい。

## 遊ぶ人から見た動き

| 操作 | 結果 |
| --- | --- |
| 検証シーン `Test/GoalScoreEffectTest.unity` を再生する | 左の床のゴール（青）と右の輸送機のゴール（赤）に、1.2 秒ごとに交互に得点が入ったことになり、光る |
| 試合で、物資を自分のチームのゴールに入れて得点が入る | そのゴールのまわりが、自分のチームの色で光る |
| 3種類ルールで、まだ持っていない種類の物資を入れる | 得点と同じように光る（もう持っている種類のときは光らない＝何も起きない） |
| 続けて何個も入れる | 1つ入るたびに光る（1つのゴールで同時に光るのは3つまで。超えたら古い光から消える） |

- 得点が入らなかったとき（閉ざされたゴール・誰もいないチーム・フックで引きずり込んだ物資）は光らない。
- **ゴールの床が一瞬白くなる、もとからある光（下の「もとからある床の光との関係」）は、そのまま残してある。**

## 設定できる値（インスペクターの項目）

**演出（進行役のプレハブの子 `SpaceJunkGoalScoreEffect`。プレハブ `Prefabs/Effect/SpaceJunkGoalScoreEffect.prefab` を直せば全ステージに効く）**

| 項目名 | 意味 | 実装したときの初期値（目安。調整で変わる） |
| --- | --- | --- |
| Glow Material | 光の見た目（`Art/Materials/GoalScoreGlow`） | `GoalScoreGlow` |
| Duration | 光ってから消えるまでの秒数 | 1.3 秒 |
| Brightness | 全体の明るさ | 1.3 |
| Wall Height | 光の壁の高さ（m） | 3m |
| Wall Outset | ゴールのふちから、光の壁までのすき間（m） | 0.12m |
| Wall Flare | 光の壁の上の端が、外へ開く距離（m）。0 なら真っすぐ立つ | 0.8m |
| Wall Rise Seconds | 光の壁が伸びきるまでの秒数 | 0.2 秒 |
| Ring Spread | 光の輪が、ゴールのふちから外へ広がる距離（m） | 2.2m |
| Spark Count / Spark Rise / Spark Size / Spark Spread | 光の粒の数・のぼる高さ・大きさ・外へ広がる距離 | 64 個・3.2m・0.2m・0.7m |
| Max Per Goal | 1つのゴールで同時に出す光の数の上限 | 3 |

**光の見た目（マテリアル `GoalScoreGlow.mat`）**：White Core（いちばん明るい所を白に寄せる量）・Streaks（壁の縦の筋の濃さ）・Ring Width（輪の太さ）・Edge Glow（ふちのすぐ外のにじみ）・Cover（光の下の床を暗くする強さ。大きいほどチームの色がはっきりする）。
Color・Intensity・Progress・Part・Size・Spark は**スクリプトが毎回入れる**ので、マテリアルで変えても効かない。

**決まり**：

- **色はチームの色**（`SpaceJunkTeams.TeamColor`。ゴールの床やプレイヤーのリングと同じ色）。演出の側で色を決める項目は無い。
- 演出は**進行役と同じシーンのゴールだけ**を光らせる。進行役のプレハブの子から外して別のシーンに置くと、そのシーンのゴールしか光らない。

## もとからある床の光との関係

`SpaceJunkGoal` には、もとから「得点が入ったら、ゴールの色を塗る床（Pad Renderer）を Flash Color（白）で Flash Seconds（0.4 秒）だけ光らせる」仕組みがある。
ホストが得点を数えたときに、全員のPCへ `FlashClientRpc` で知らせて光らせている。

- 新しい演出は、**この同じ知らせから出している**（`FlashClientRpc` → `ShowScored` → 床を白くする＋ `Scored` を出す → 演出が受け取る）。なので、**2つの光が別々の時刻に出たり、片方だけ出たりすることは無い**。得点を数える処理には手を入れていない。
- 新しい演出は**床（Pad Renderer）の色には触らない。** 床の色はこれまでどおり `SpaceJunkGoal` だけが決める（2つの仕組みが同じ床の色を取り合わない）。光の壁と輪は、ゴールのふちの外側に出る。
- 見た目としては「床が一瞬白く光る ＋ まわりがチームの色で光る」になる。**白い光をやめてチームの色の光だけにしたいときは、各ステージのゴールの Flash Seconds を 0 にする**（シーンの変更になる。どちらにするかは大槻さんの判断待ち。`質問リスト.md`）。
- 電車マップ2・ガラスマップでは、色を塗る床が Hans さんの輸送機なので、もとからの白い光は輸送機ごと白くなる（今回の変更の前から同じ。モデルのファイルは変わらない）。

## 仕組み（分かる人向け）

> スクリプトの詳しい説明は `スクリプトの説明/Game/Effect/SpaceJunkGoalScoreEffect.md`。

- 得点の知らせ：ホストの `SpaceJunkGoal.TryCollect` → `SpaceJunkRound.ServerCollect` が true（数えた）なら `FlashClientRpc`（全員）→ 各PCで `ShowScored` → `SpaceJunkGoal.Scored`（static の event）→ `SpaceJunkGoalScoreEffect.Play`。
- 大きさ：ゴールの見た目（`IntroVisual`。無ければ Pad Renderer）の形（メッシュ）の箱を、ゴールの向き（左右の回転だけ）で測り直す。見た目が無ければ判定の箱。足もとの高さは判定の箱の底で、**まわりの動かない床の上面がそれより少し高い・低いときは床に合わせる**（電車マップ2は床が 0.25m 高い）。
- 描き方：`Graphics.RenderMesh` でシーンに物を作らずに描く。**Renderer を作らないので、全体カメラ（`SpaceJunkWholeStageCamera`）が測るステージの大きさに入らない。** 影は落とさない。
- 時間は各PCの `Time.time` で進める（知らせが届いた瞬間から 1.3 秒）。途中から入った人には、入る前の光は出ない。

## 確かめたこと

- 本物の試合（画面なしの Unity でホスト＋ボット3人）を電車マップ2で60秒動かし、**点が入った回数（11回）・得点の知らせの回数・光った回数がすべて一致**することを確認。全体カメラの画像でも、得点したゴールのまわりが光っていた。ゲームのコードからのエラー・Exception は出なかった（Unity エディタ自身の検索機能の Exception が起動時に1件出たが、ゲームとは関係ない）。
- はじめは光の壁が真っすぐ立っていて、全体カメラ（真上寄り）からは細い線にしか見えなかったので、上ほど外へ開く形にした（Wall Flare）。
- 検証シーンを、時刻ごとの画像（0.05〜1.2 秒）で確認。青と赤のチームの色で、床のゴールと輸送機のゴールのまわりが光り、1.2 秒で消える。
- 本物のステージ（シンプル・電車マップ2・ガラスマップ チェック）に置いて画像で確認。どれもゴールの大きさに合って囲む。電車マップ2は、はじめ光の根元と輪が床（0.25m 高い）に埋もれていたので、床の高さに合わせるように直した。
- 全ステージ（14）のゴールの大きさを測り、どれも測れることを確認（床のゴール 5m×4m、輸送機のゴール 3.08m 四方）。

## できていないこと・既知の問題

- **人が遊んでの見え方（明るさ・長さ・派手さ）は未確認。** 値は一旦作ってみたもの。
- **別のPC（参加者）での見え方は、実際の2台では確かめていない。** 知らせは Netcode の ClientRpc（ホストから全員へ送る）なので、参加者のPCでも同じように届くはず。
- 床が一瞬白くなる、もとからの光を残すかどうかは未定（上の「もとからある床の光との関係」）。
- 色を塗る床のまわりを壁で囲んだゴール（シンプルなど）では、光の壁の下のほうがゴールの壁に隠れる（上の開いた部分と、床に広がる輪は見える）。
