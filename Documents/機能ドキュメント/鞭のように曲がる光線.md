## この機能は何か

プレイヤー（本実装の体）が物資をつかむときの、**新しい撃ち方の案**。

- これまで：ボタンを押して溜めて届く長さを決め（矢印の帯）、離すと光線がまっすぐ伸び、先が物資に当たったらつかむ。
- この案：**溜めない。** ボタンを押した瞬間に、狙った向きへ光線が出て、**最長 1 秒間出し続けられる**。
  出している間に向きを変えると、光線が**鞭のようにしなって**ついてくる（先が少し遅れる）。**光線のどこかが物資に触れたら、つかむ。**
  つかんだあと（引き寄せ・投げ・クリティカル）は今までと同じ。

**今までの撃ち方は消していない。** 2026/11/18 から、**ロビーコンソールのプレイヤー挙動「1 狙う・2 発射」で、ホストが全員ぶん選ぶ**（A＝鞭＝この案、B＝溜め）。初期値は A（鞭）。詳しくは `プレイヤー挙動のパターン.md`。
（11/17 の間は、ポーズ画面の「設定」→「撃ち方」で一人ひとりが選ぶ形だった。ロビーに移したので、ポーズ画面の項目はやめた）

## 遊ぶ人から見た動き

| 操作（コントローラー／キーボード・マウス） | 結果 |
| --- | --- |
| RT／左クリックを押す | 溜めずに、すぐ**狙った向き**へ光線が出る（体もその向きを向く）。矢印の帯は出ない |
| 押している間（最長 1 秒） | 光線が伸びて、いちばん長い所（12m）で出たままになる。**歩けない**（向きは変えられる） |
| 出している間に右スティック／マウスで向きを変える | **光線が鞭のようにしなる。** 手元は体の向きに出て、先は少し遅れてついてくる（行き過ぎてからビヨンと戻る） |
| 光線の**どこか**（先でなくてもよい）が物資に触れる | つかむ。曲がったまま引き寄せが始まり、物資は**前の側へ回り込みながら**寄ってくる（今の「引き寄せ中のしなり」と同じ） |
| 離す／1 秒たつ | 光線が戻る。戻りきったら歩ける |
| 光線が壁に当たる | 光線はそこで止まる（壁の向こうへは伸びない）。戻りはしないので、出している間は振り続けられる |
| つかんだあと | 今までと同じ（押すと後ろへ投げる／押さないと前へ／クリティカル／重い物は引きずるだけ） |

- 「押している間だけ出る」か「1回押せば 1 秒出る」かは、インスペクターの `Whip Hold To Keep` で選べる（初期値は押している間だけ）。
- ロビーコンソールでパターンを変えると、**次に押したときから**変わる（撃っている途中では変わらない）。
- **ボット**も、ロビーコンソールのパターンに従う（2026/11/18。前は体のプレハブの撃ち方のままだった）。鞭のときは、光線が出ている間ボタンを押し続ける（素材のほうを向いたまま、まっすぐ当てる。振ってはつかまない）。

### 試し方

1. Unity のメニュー `Tools > StarSweepers > 鞭の光線の検証シーンを作る` を押す（`Assets/Scenes/Test/SweeperWhipTest.unity` ができて開く）
2. 再生する。**まず Game ビューを1回クリック**（マウスが届くようになる）
3. まわりに物資が2重の輪（4m・9m）で並んでいる。東西の柱は「壁で光線が止まる」のを見る用
4. 今までの撃ち方と比べるときは、インスペクターの `SweeperShooter` の `Shot Style` を Aim に変える（このシーンは通信なしなので、ロビーコンソールは出ない。
   最初の撃ち方は、このPCに保存されたプレイヤー挙動＝最後にホストをしたときの選び方で決まる）

本番の流れ（タイトル → ロビー → マップ）でも、新しい体はみんなこの撃ち方になっている（オンライン・ボットも）。

## 設定できる値（インスペクターの項目）

`SweeperShooter` に足した項目。数値は**実装したときの初期値（目安）**。

| 項目名 | 意味 | 実装したときの初期値（目安） |
| --- | --- | --- |
| Shot Style | 撃ち方。Whip（この案）／Aim（今まで：溜めて撃つ） | Whip |
| Follow Settings | ON：ロビーコンソールのプレイヤー挙動「1 狙う・2 発射」に合わせる（A＝Whip、B＝Aim。変わったら、次に押したときから）。OFF：いつも Shot Style のまま | ON |
| Whip Seconds | 光線を出し続けられる秒数 | 1 |
| Whip Hold To Keep | ON：押している間だけ出る（最長 Whip Seconds）。OFF：1回押せば Whip Seconds 秒出る | ON |
| Whip Stiffness | 光線の先が体の向きに追いつく速さ。小さいほど遅れて大きくしなる | 7 |
| Whip Damping | しなりの止まりやすさ。小さいほど行き過ぎてビヨンと戻る | 0.35 |
| Max Whip Angle | 光線の先が体の向きから遅れられる最大の角度（度） | 120 |
| Whip Move Scale | 光線を出している間に歩ける速さ（ふだんの何倍か）。0 で歩けない | 0 |

今までの項目のうち、Whip でも使うもの：`Max Reach`（伸びる長さ）・`Extend Speed`（伸びる速さ）・`Retract Speed`（戻る速さ）・`Hit Radius`（当たりの太さ）・`Stop At Walls`・`Bend Strength`（曲がり方の強さ。引き寄せ中のしなりと共通）。
`Min Reach`・`Charge Seconds` は Aim のときだけ使う。

## 仕組み（分かる人向け）

- 光線の形は、今の「引き寄せ中のしなり」と同じ**2次ベジェ曲線**（`LiquidBeam.Follow(根元, 先, 根元の向き, 曲げる強さ)`）。
  引き寄せ中は「先（物資）が決まっていて、根元の向きが遅れる」。鞭は逆で、**根元は体の向き、先の向きがばねで遅れて体の向きを追う**。
- 先の向きは「減衰するばね」で動かす（`whipTipYaw`・`whipTipYawSpeed`）。体は `SweeperMover` が狙いの向きへ最大 900°/秒 で回すので、振る速さはそこで決まる。
- 当たりは、曲線を 16 等分した点を使って見る：
  ①曲線に沿って根元から順に（壁に当たったら、光線の長さをそこまでに縮めて、その先は見ない）
  ②点ごとに「前のフレームの位置 → いまの位置」（速く振ったときに物資を飛び越さないため。こちらは物資だけを見る）
- 物資に触れたら、そのときの体の向きを「しなりの向き」として引き寄せに渡す（`bendActive`／`bendYaw`）。曲がった見た目のまま引き寄せが始まり、物資は前の側へ回り込む。
- 段階（`ShotPhase`）は今までと同じものを使う（鞭を出している間は Extending、戻る間は Retracting）。ほかの人の画面では、届いた光線の先と体の向きから同じ曲線を描く。
- **撃ち方は人ごとに違うので、通信で配る**（`SweeperNetSync` の `shotStyle`。本人が書き、全員が読む。2026/11/17）。ほかの人の画面では、届いた撃ち方を毎フレームその人の体の `SweeperShooter.Style` に入れてから描く。
  **通信の項目が1つ増えたので、2026/11/17 より前に作ったビルドとはつながらない。** 検証用のビルドは作り直すこと。
- プレイヤー挙動との関係：体は起きたとき（Awake）に「狙う」のパターンを読み、そのあとは**押した瞬間に「パターンが前回から変わっていたら」だけ**合わせ直す。だから、インスペクターで Shot Style を手で変えても、パターンが変わるまでは上書きされない（2026/11/18。前はポーズ画面の設定を見ていた）。
- テストなどから `BeginCharge` → `Fire` を呼ぶと、Shot Style に関係なく今までの撃ち方になる（今までのテストはそのまま使える）。

## できていないこと・既知の問題

- **人が遊んでの確認はまだ。** 手触り（しなりの強さ・1 秒の長さ・歩けないこと）は、遊んで調整が要る。
- 壁で光線を短くするとき、曲がった光線の途中で当たっても「根元から当たった所までのまっすぐの距離」に縮めるので、強く曲がっているときは止まる位置が少しずれる。
- 速く振ったときの当たり（②）は壁を見ないので、細い柱の向こうの物資を、振った勢いでつかめることがある。
- ボットは振らない（まっすぐ当てるだけ）。
