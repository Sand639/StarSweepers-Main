# SpaceJunkSpawner（素材のスポナー）

| 項目 | 内容 |
| --- | --- |
| スクリプト | `StarSweepers/Assets/Scripts/Game/Item/` の `SpaceJunkSpawner.cs` と、分けたファイル（下の表） |

## 何をするスクリプトか

**宇宙船の素材（と爆弾）を、マップ上に次々と落とすスポナー。** 決まった間隔ごとに、出す物を出やすさで選び、範囲の中の何も無い場所の少し上から落とす。

## ファイルの分け方（2026/11/6 から）

長かったので、**1つのクラスのまま、ファイルだけを機能ごとに分けた**（C# の partial という書き方）。
どのファイルも同じクラスの一部なので、ほかのファイルの変数や関数をそのまま使える。プレハブ・シーン・通信の動きは、分ける前と同じ。

| ファイル | 中身 |
| --- | --- |
| `SpaceJunkSpawner.cs` | **入口**（設定の値・状態・出入り・Unity から呼ばれる関数・共通の補助） |
| `SpaceJunkSpawner.Legacy.cs` | 古い書き方からの移し替え |
| `SpaceJunkSpawner.Place.cs` | 出す場所を決める（1巡法・床の確認） |
| `SpaceJunkSpawner.Spawn.cs` | 出す物を選んで出す |

## 変数の置き場所

**変数・定数は、すべて入口のファイル（`SpaceJunkSpawner.cs`）にある。** 分けたファイルには関数だけが入っている。

## 気をつけること

- **新しい処理は、その機能のファイルに書く。** どれにも当てはまらなければ、入口のファイル（`SpaceJunkSpawner.cs`）に書く。
- Unity から呼ばれる関数（`Awake`・`Update` など）は、入口のファイルにまとめてある。
- 変数がどのファイルにあるかは、上の「変数の置き場所」を見る。**新しい変数は、使う機能のファイルに置き、上の表にも足す。**
- クラスの説明（`///` のコメント）は、入口のファイルの先頭にある。
