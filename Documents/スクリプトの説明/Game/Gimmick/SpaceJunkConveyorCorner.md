## 何をするスクリプトか

ベルトコンベアの 90 度の角。上に乗った物資と人を、**内側の角を中心にした円に沿って**運ぶ。
まっすぐのベルト（`SpaceJunkConveyor`）だけで角を作ると、境目で流れる向きがカクッと変わるので、角はこれに任せる。

## 置き方

- **置く場所は、内側の角（カーブの中心）**。高さはベルトの上面（まっすぐのベルトと同じ）
- **向き 0 の右曲がり（Turn Right が ON）**：東から入って西へ進み、北へ出る。範囲は中心の南西の4分の1の円
- **向き 0 の左曲がり（Turn Right が OFF）**：東から入って西へ進み、南へ出る。範囲は中心の北西の4分の1の円
- 曲がる向きは Transform の向きで回す（コンベアのモデル `SM_Conveyor_Turn_R`／`L` と同じ向きにすればよい）
- **つながるまっすぐのベルトは、角のマスにはみ出させない**（角の中で両方が押し合うと、物資の道がずれる）
- Speed はつながるまっすぐのベルトと同じにする。Radius は外側の縁までの距離（ロビーの曲がる部品は 2.75）

## 流れ

| いつ | 何をするか |
| --- | --- |
| `Awake` | 上面の当たり判定（扇形の板。上面が置いた高さ、厚みは Thickness）を作る。**摩擦なし**にして、物資が転がらずに流れるようにする |
| `Update` | 角の上に立っている、自分のPCで動かしているプレイヤーを、中心から見た位置を回す形で動かす（円からずれない） |
| `FixedUpdate` | 物資（物理を動かしているPCだけ）を運ぶ。①円に沿って進んだ角度の分だけ速さの向きを回す ②流れの速さとの差を Item Grip で縮める ③角に入ったときの中心からの距離（レーン）へ戻す |

主な関数：`TryGetFlowVelocity(場所, out 速さ)`（その場所で流れる速さ。範囲の外なら false。テストでも使う）。

## 気をつけること

- **向きが一定時間ごとに逆になる働き（まっすぐのベルトの Reverse Interval Seconds）は無い。** 逆向きにしたいときは Speed をマイナスにする。逆になるベルトとつなぐと、逆になった間は角だけ向きが合わない
- 通信はしない（まっすぐのベルトと同じ。物資は物理を動かしているPC、プレイヤーは自分のPCが動かす）
- 当たり判定は再生したときに作る（エディタで止まっている間は無い）。範囲と流れる向きは、シーンビューの黄色い弧と矢印で見える
- Lane Keeping を 0 にすると、入口・出口でとなりのまっすぐのベルトに押されて、1つの角で外へ約 0.2m ずれる（2026/11/11 に画面なしの Unity で確かめた。3 なら 0.1m 以内）
