# GravityGlassFloor（重い重力で割れるガラスの床）

| 項目 | 内容 |
| --- | --- |
| スクリプト | `StarSweepers/Assets/Scripts/Game/Gimmick/` の `GravityGlassFloor.cs` と、分けたファイル（下の表） |

## 何をするスクリプトか

**重力・踏んだ回数・乗っている時間で割れるガラスの床。** 踏まれるとヒビが伸び、決まった条件で割れて破片になり、しばらくすると元に戻る。STAGE_07 に置かれている。

## ファイルの分け方（2026/11/6 から）

長かったので、**1つのクラスのまま、ファイルだけを機能ごとに分けた**（C# の partial という書き方）。
どのファイルも同じクラスの一部なので、ほかのファイルの変数や関数をそのまま使える。プレハブ・シーン・通信の動きは、分ける前と同じ。

| ファイル | 行数 | 中身 |
| --- | ---: | --- |
| `GravityGlassFloor.cs` | 361 | **入口**（設定の値・状態・出入り・Unity から呼ばれる関数・共通の補助） |
| `GravityGlassFloor.Break.cs` | 259 | 割れる・戻る（破片） |
| `GravityGlassFloor.Cracks.cs` | 317 | ヒビ |
| `GravityGlassFloor.Stepping.cs` | 92 | 踏まれたかを調べる |
| `GlassFractureGeometry.cs` | 261 | 割れた破片の形の計算（別のクラス） |

割れた破片の形の計算（多角形を作る・三角形に分ける・厚みを付ける）は、別のクラス `GlassFractureGeometry`（`GlassFractureGeometry.cs`）にある。

## 気をつけること

- **新しい処理は、その機能のファイルに書く。** どれにも当てはまらなければ、入口のファイル（`GravityGlassFloor.cs`）に書く。
- Unity から呼ばれる関数（`Awake`・`Update` など）は、入口のファイルにまとめてある。
- インスペクターに出る値は、ほとんど入口のファイルにある。
- クラスの説明（`///` のコメント）は、入口のファイルの先頭にある。
