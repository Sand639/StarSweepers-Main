# PauseMenu（ポーズ画面）

| 項目 | 内容 |
| --- | --- |
| スクリプト | `StarSweepers/Assets/Scripts/Common/Settings/` の `PauseMenu.cs` と、分けたファイル（下の表） |

## 何をするスクリプトか

**Esc で開くポーズ画面。** ゲームをつづける・設定・ロビーに戻る・タイトルに戻る・ゲームをやめる。画面はコードで組み立てる（プレハブは使わない）。再生を始めたときに自分で生まれる。

## ファイルの分け方（2026/11/6 から）

長かったので、**1つのクラスのまま、ファイルだけを機能ごとに分けた**（C# の partial という書き方）。
どのファイルも同じクラスの一部なので、ほかのファイルの変数や関数をそのまま使える。プレハブ・シーン・通信の動きは、分ける前と同じ。

| ファイル | 行数 | 中身 |
| --- | ---: | --- |
| `PauseMenu.cs` | 416 | **入口**（設定の値・状態・出入り・Unity から呼ばれる関数・共通の補助） |
| `PauseMenu.Build.cs` | 204 | 画面を組み立てる（メイン・設定のページ） |
| `PauseMenu.Confirm.cs` | 134 | 確かめる画面（ロビー・タイトルに戻る、ゲームをやめる） |
| `PauseMenu.Widgets.cs` | 160 | 部品づくり（項目・スライダー・文字・画像） |

## 気をつけること

- **新しい処理は、その機能のファイルに書く。** どれにも当てはまらなければ、入口のファイル（`PauseMenu.cs`）に書く。
- Unity から呼ばれる関数（`Awake`・`Update` など）は、入口のファイルにまとめてある。
- インスペクターに出る値は、ほとんど入口のファイルにある。
- クラスの説明（`///` のコメント）は、入口のファイルの先頭にある。
