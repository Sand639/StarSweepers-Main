# タスクリスト

**「やると決めたこと」を、担当と期限つきで並べる場所。**

「いま誰が何をやっていて、次に何をやるか」を全員が同じ表で見られるようにするためのもの。
やるかどうか未定のことは、ここではなく `やりたいことリスト.md` に書く。

## 書き方のルール

- **1行に1つのタスク**を書く。大きすぎるものは、数日で終わる大きさに分ける。
- 誰でも書いてよい。AIが代わりに書き足してもよい。
- **やったら行を消さずに、状態を「完了」に変える。** いつ何をやったかが残る。
- 担当が決まっていないときは「未定」と書く。期限が無いときは「―」でよい。
- **他のリストとの使い分け**
  - やるかどうか未定のこと → `やりたいことリスト.md`
  - 不具合・あとで問題になりそうな箇所 → `リスクリスト.md`
  - 誰かに判断してほしいこと → `質問リスト.md`
  - **やると決まったこと → このファイル**
- 完了したタスクが増えて表が長くなったら、「完了したタスク」の表へ行を移す。

### 状態の意味

| 状態 | 意味 |
| --- | --- |
| `未着手` | まだ手を付けていない |
| `作業中` | 誰かがやっている。**誰がいつから**を続けて書く |
| `確認待ち` | 作業は終わっていて、誰かの確認・判断を待っている。**誰の確認か**を続けて書く |
| `完了` | やった。**いつ・何をしたか**を続けて書く |
| `中止` | やらないことにした。**理由**を続けて書く |

### 優先度の意味

| 優先度 | 意味 |
| --- | --- |
| `高` | これが終わらないと、他の作業や次の区切りに進めない |
| `中` | 次の区切りまでにはやりたい |
| `低` | 余裕があればやる |
